## 1. 修正的上帝視角
| 舊行為（v13 以前） | 新行為（v14） |
|---|---|
| `routeTo()` 用完整路網求最短路：知道地點 ID 就自動知道最短路，包括從沒走過的捷徑 | 只在自己**走過的路段**上找路；沒走過就不能直接前往 |
| 探索候選＝蟻群旗標 `presence==='potential'` 且與已知地點相鄰的地點，再用全圖最短路前往 | 走到一個自己知道的節點，**在那裡**感知出口，走一條沒走過的路段，到了才知道那裡有什麼 |
| 「已知為空」是蟻群旗標，一隻發現、全巢立即知道 | 每隻工蟻自己記得哪個地點的寄主已死 |
| 探索後同一天又以分鐘 0 出發覓食（同一時間在兩處，v12 的舊時間錯誤） | 探索就是當天的那一趟；找到食物就在那裡覓食 |

## 2. 個體記憶與探索流程
1. **記憶內容**：
   - 走過的路段：取得方式（`walked`／`trail_followed`／`recruit_followed`／`explored`／`day14_history`）、首次與最近使用日；
   - 已死寄主的地點；
   - 來源（`origin`）。
   
   **抽象化限制（遊戲假設）**：
   - 走一次就記住；
   - 沒有遺忘；
   - 雙向可用；
   - 不記距離。
2. **出發前**：從自己知道、而且有走過路線的地點中，依原本的評分（記憶中的收穫、需求、卸貨回饋）選一個，沿自己記得的路線前往。
3. **沒有可用地點**：
   - 先在巢口感知費洛蒙；有可追蹤的訊號就逐段跟隨，每到一個節點才感知下一段；
   - 沒有訊號就以 `scout_discovery_probability` 的機率出去探索。
4. **自己的地點都沒收穫**（原規則：收穫 < 門檻，且以 `scout_search_when_route_unproductive_probability` 的機率）：改去探索。
5. **探索**：
   - 隨機選一個自己能走到的已知節點（含巢）；
   - 走到那裡，感知該節點沒走過的出口，隨機走一條；
   - 到達後：
     - 有可感知的食物（存量、活昆蟲、活寄主上的蚜蟲／介殼蟲）→ 在那裡覓食；
     - 已死的寄主 → 記住；
     - 什麼都沒有 → 空手回巢。
6. **招募**：被招募者沿招募者實際走過的路線前往，必須有可追蹤訊號；走過後才學到。到了現場才知道還有沒有食物。
7. **Day14 遷移**：只採用 Day1～14 正式紀錄證明該工蟻確實走過的路段，每筆附出處（見下表）。

## 5. 測試（`tests/navigation.test.ts`，其餘既有測試全數通過）
- **反上帝視角**：只知道 F04 的工蟻，到 F05 一定經 F04，從不經它沒走過的 F08（60 個種子強制探索）；沒走過的地點沒有路線。
- **局部探索**：每次探索都從已知節點出發，到起點的路全是已知路段，只多學到一段。
- **記憶隔離**：每隻工蟻的記憶都是自己原本的或自己走過的；沒出門的工蟻什麼都沒學到。
- **費洛蒙追蹤**：沒走過的工蟻能逐段跟隨訊號，走過後記錄為 `trail_followed`。
- **訊號消失**：訊號消失後，走過的工蟻憑記憶回去；沒走過、也沒被招募的工蟻找不到。
- **20 種子 × 60 日逐日稽核**（1200 天）：
  - 每段步行都在當天之前已知，或有探索、局部費洛蒙選擇、跟隨招募者等依據；
  - 記憶只因走過而增加；
  - 每隻工蟻一天是從巢出發、回到巢的連續路徑，時間嚴格遞增（沒有瞬移、沒有同時在兩處）。
- **生態一致性**：30 日內，植物、蚜蟲／介殼蟲、花蜜的產量與天氣，開關開或關完全相同。
- **開關關閉**：不產生任何路線記憶或探索事件。

## 6. 限制與待決定
- **路網與歷史紀錄不一致**：紀錄中 W016 走的是 U00→U01，但路網只有 N00–U01，沒有 U00–U01。要改路網（世界參數），還是維持現況？
- **W015 的 N00–U00**：日誌寫「踏入U00的外緣」，但存檔當天沒有登錄這段。本 PR 依日誌採計，可改為不採計。
- **記憶模型是第一版**：
  - 沒有遺忘，也沒有記憶與費洛蒙衝突時的權重，因為本種沒有資料；
  - 費洛蒙只用於沒有可用地點的工蟻；有經驗的工蟻依自己的記憶（R134 跨物種方向）；
  - 本種的沿跡偏離（R133）尚未模擬。
- **單一費洛蒙是建模簡化**：R102 只說明資料不需要兩種；R21／R96 只讀到摘要。
- **找到的錯誤**：
  - v12 探索後同一天又以分鐘 0 出發（同時在兩處）：v14 已不再發生；v13 模型保留原樣作為隔離對照。
