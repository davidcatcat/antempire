# 《螞蟻帝國》PR #1 v2-review.5a：20 組固定種子冬季 120 日隔離試跑

> **未合併 PR，未推進正式 Day15。** 權威遊戲仍在 Day14／336 小時（2026-11-13）；所有 Day15～134 與昆蟲 Day365 結果都只是 `sim/day14-projection.json` 的**獨立診斷分支**，並非真實世界氣象／蟻群量測。

## 最重要結果

- 2026-12-01～2027-02-28 完全滅巢 **0/20（0.0%）**；Day134 前全滅 **0/20**。20 種子均有活蟻后。因此不存在可分析的滅巢個案；不可編造個別死亡原因。
- Day74 工蟻最小／中位／最大 **9/16/21**；Day134 **7/15/22**。人口並非全部單調衰退，也無法宣稱春季必然回升。
- 20 種子 × 120 日共 2400 筆合成天氣，對各日內插臺中平年日均溫的平均距平 **-0.06°C**；此樣本沒有長期整體偏冷跡象，但 11 月偏冷約 0.55°C。每個種子及單月都可能有距平。
- **預期季節樣貌未完全達到：** 11 月工蟻出勤比例 45.7%，2 月 42.4%（僅下降約 3.3 個百分點）；日均產卵數 11 月 0.232、1 月 0.239，沒有穩定下降。平均產卵機率 11 月 0.191→1 月 0.157，代表溫度機制運作，但與實際產卵數不同；3 月只涵蓋 13 天，不能斷言春季恢復。
- **鄰近昆蟲未能證明必定長期穩定：** 8 種子延伸 Day365，1 組（15032033）鄰近昆蟲為 0。該局部封閉棲地一旦 0 隻即無法由自身出生恢復；這是本版模型尚未涵蓋外界新殖入的結構限制，不能為了讓蟻群活下去事後憑空增加蟲源。

## 逐項變更與證據性質

| 變更 | 證據類型 | 機制、參數、解釋 |
|---|---|---|
| 巢內糖與蛋白維持耗依巢溫改變 | **一般生理學 + 遊戲假設 `assumption:true`** | `Q10=2.0`、25°C 基準；`2^((Tnest-25)/10)`。PMC11750369 使用此值做*其他蟻種*代謝標準化，**不是熱帶大頭家蟻實測**；外勤每趟額外耗糖不使用此基礎代謝係數。 |
| 月均高／低溫與日最高氣溫代理 | **氣象測站平年值 + 文獻支持方向 + 遊戲假設** | 臺中站 1991～2020 月平均日最高／最低氣溫；日最高氣溫和日均溫共享合成距平，僅作白天覓食代理，**不是園地地表溫度實測**。日本鹿兒島（Harada et al. 2021, Nature of Kagoshima 48:99–108）與 JCU 研究支持日間、季節與地表溫度影響方向；係數非量測。 |
| 冷抑制只作用一次 | **建模邏輯** | 先抽選外勤任務，再以一次活動閘門依**白天最高氣溫**決定是否真的出勤；採集成功與招募不再乘同一曲線。過去把係數乘在相對抽籤權重也不是精確活動倍率，故改為事後門檻。 |
| 沒有工蟻時幼蟲不能自行消耗庫存 | **基本生物學 + 遊戲假設 `assumption:true`** | 不能直接由巢庫存扣幼蟲餵食量；無工蟻幼蟲停止發育，最多 4 天，卵／蛹最多 10 天（**日數非物種實測**）。零工蟻蟻后額外死亡風險按連續零工蟻日數。回歸檢查通過。 |
| 冬季蟻后繁殖 | **遊戲假設 `assumption:true`** | 25°C 產卵參照、Q10=2.5 模擬溫度抑制；既有 `max_eggs_per_day=2` 由程式真正使用，第二顆卵附加 0.2 機率；原幼體發育 Q10=1.55 完全不改。 |
| 工蟻自然死亡 | **遊戲假設，未修改** | 基礎 0.003/日，28 日後 hazard 每日 +0.00075；無飢餓受傷時推估平均壽命約 64.3 日，相較 R94 minor 工蟻實驗室平均 26.25 日，**差距仍在，沒有宣稱校準完成**。 |
| 昆蟲繁殖、蜜露來源 | **遊戲假設，未修改** | 沒有為了提高過冬存活率追加糖、蛋白、螞蟻或昆蟲。F04/F05 仍明記「第一輪 v2 失敗後才補列」的花園清冊，絕非 Day1～14 實測。 |

## 可重現性與檔案

- `node sim/test_naturalism.cjs`：214 項測試通過，包括幽靈幼蟲、無工蟻倉庫不扣食、自然食物事件與昆蟲守恆。
- `node sim/test_winter_multiseed.cjs`：20 個固定種子，每個 120 日與前後端點 deterministic replay、昆蟲出生死亡守恆、地點承載量與巢糧無關的生態檢查；另 8 組延伸檢視 Day365 鄰地昆蟲。
- `node sim/test_120_days.cjs`：保留原先指定種子 15032026 的逐日／逐週／JSON 報告，並依新引擎重新產生。
- `reports/day15-134-v5-20seeds-daily.csv`：2400 列，每日糖蛋白攝食需求與實耗、出勤率、蟻群、溫度、昆蟲生態。
- `reports/day15-134-v5-20seeds-weekly.csv`：360 列（20×18 週），**包含白天溫度、日均溫、每日平均消耗量、出勤人數、糖與蛋白收支、F07/F11/鄰地昆蟲數**。
- `reports/day15-134-v5-20seeds-analysis.json`：機器可讀統計與種子表。
- `reports/day15-134-review.md` 是**前一版歷史滅巢試跑**，不等於本版結果。

本次重新產生的 20 種子報告是在連結 GitHub 檔案後，以 JavaScript 模組相容執行器運行；**沒有實際啟動 GitHub Actions 或標準 Node CI**。測試結果不能冒充已通過正式 CI。

**最終判讀：** 修正後不再是「冬季注定滅亡」，也不能反推「冬季模型已真實」。冬季活動下降幅度及相鄰昆蟲的零族群吸收態仍待更好文獻／實地觀測支撐，**不可為了通過存活率驗收而回頭修改環境數值**。
