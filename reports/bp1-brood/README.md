> **地位：研究候選，隔離、預設關閉；非正式實驗世界，不屬於正式遊戲歷史。** 這裡沒有任何數字是目標。28°C 重現 28.73 日只是**校準**，不是驗證；所有參數都是候選檔或 `bp1-variants.json` 的假設值（`assumption: true`）。沒有為了結果調整參數、種子或情境。
> 設計與實作紀錄：[`docs/p0a2-brood-physiology-design.md`](../../docs/p0a2-brood-physiology-design.md) §5.4；程式：`prototypes/p0a2-24h/brood/`；測試：`tests/bp1-brood.test.ts`。

## 怎麼跑（可重現）

```

node prototypes/brood-physiology/bp1-report.ts summarize        # results.json、tables.md
```

- 世界：P0-A2（30 隻工蟻、8 隻幼蟲、一個蜜露情境源、合成天氣 `taichung-march-ref`、參考變體 `ft-flat`），開啟 `WorldOptions.brood`。
- 種子 1～20 與時間長度在執行前就固定：P0-A2 食物 30 日、零供給 35 日、反事實蛋白 40 日。22 個變體 × 20 個種子 = **440 次執行，全部列出**（`tables.md` 的「每個種子」表、`results.json` 的 `per_seed`、`runs/*.json` 的每隻幼蟲）。
- 每次執行每天檢查守恆（工蟻嗉囊、幼蟲換算出去的 µP、食源存量的 µP 帳，加上每隻幼蟲的糖／蛋白／能量整數帳）：**440 次全部守恆**。
- 8 隻幼蟲在 t = 0 是剛孵化的 L1（模型假設；原型沒有齡期資料、沒有蟻后產卵）。巢溫是情境常數（巢溫動態尚未模擬）。

## 觀察（不調參，只記錄）

1. **P0-A2 目前沒有任何蛋白來源**，所以候選下沒有一隻幼蟲能長過 L1。這是如實結果，不是要修補的缺陷；在 RU-5（獵物生物量）／RU-7（P0-A2 供給接生態模組）之前，育幼發育在 P0-A2 中不可能出現。矩陣 M16 維持「未接入」。
2. **糖橋係數幾乎不影響糖攝入**（0.0162／0.03／0.08812 mg／份：每隻 30 日餵入 123.9／124.2／125.5 µg）。原因是照護者依幼蟲自己的腸內飽足度餵食，而腸容量也經同一座橋換算；攝入由幼蟲的吸收能力（候選檔推得）決定，不是由係數決定。
3. **照護負擔改變**：候選下幼蟲腸道由吸收清空（比原型的 0.025 份／日快），照護餵食次數每種子 7 046～7 184 次／30 日；參考世界（無候選，種子 1）30 日只有 782 次。這是候選改變工蟻行為的一個後果，記錄於此。
4. **糖儲備沒有上限**：只有糖、沒有蛋白時，糖在儲備中無限累積（約 112 µg，是 L1 自身鮮重的 7 倍）。設計沒有儲存容量或脂肪體上限；這是已知缺口，不在 BP-1 補值。
5. **高溫（32°C）**：linear_dd_A 在 28°C 以上沒有上限（外推），維持與吸收按 Q10 增加，糖攝入 163 µg／30 日；這不是本種在 32°C 的實測行為。
6. **反事實蛋白 28°C**：受蛋白限制約 6.2 日，主要在 L1（L1→L2 在第 3.9 日，任食時 1.85 日）。原因是每口 0.025 份的液體在 0.01 mg／份下只帶 250 ng 蛋白，而 L1 腸容量（同一座橋）限制每次可給的量；這是反事實情境的性質，不是對 P0-A2 的預測。
7. 危險函數 H1／H2／H3 只在零供給極端情境下才有死亡；在 P0-A2 食物下沒有任何維持虧損，所以這些候選在目前的世界裡不會觸發。H 參數全部是掃描值或測試格點，不是候選值。
