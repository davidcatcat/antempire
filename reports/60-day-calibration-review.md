# 《螞蟻帝國》v2.1 生態獨立供糖＋局部感知校準審閱報告

**狀態：PR 待審、未合併、未推進Day15、未修改正式Day14存檔。** 隔離投影從 Day14（2026-11-13；336h）開始，測試 Day15～74（60日）。所有份數、個體危險率、花園植株/半翅目昆蟲初始數量為 `assumption:true` 的遊戲假設，**非實地統計或科學實測**。固定原種子 15032026。不能把通過當成必然生存，也不能為通過而改個體結果。

## 主要修正與約束

1. **供應不依蟻群需求**：F01 既有2株寄主／4群蚜蟲，F04 隱藏既存2株／3群介殼蟲，F05 隱藏既存1株／2群蚜蟲。F10本次遷移情境不存活。各族群的自然分泌、雨水沖刷、寄主死亡、半翅目群數變化都依環境與固定種子計算。F04有既有異巢採集者分走22%蜜露；未發現 F04/F05 前主巢不能取得。這些是**一次性假設的花園生態盤點，並非為補救蟻群而臨時生成**。F07/F11死蟲保持唯一來源前因和跨日腐敗。
2. **工蟻局部感知**：不讀取全巢糖/蛋白總庫存或能撐幾天。每隻有自己的嗉囊飽度、碰到的巢友飢餓回饋、實際卸貨易度、親身知道的路線；只有育幼工蟻實際觸碰飢餓幼蟲才取得求食訊號，並可能在後續局部接觸傳播。當日巢內總食物僅用於真實物質守恆結算，**不廣播給工蟻做決策**。
3. **蛋白需求與蟻后風險**：幼蟲蛋白0.2→0.08份/日；0工蟻、持續缺糧會讓蟻后死亡機率明顯增加。其他既有自然死亡及產卵率沒有為符合驗收而調整。
4. **驗收純診斷**：不把70%存活、L001/L002羽化、Day30前產卵、新卵完成生命週期當目標。結果不佳時報告機制瓶頸，不再回頭隨意增食物或降低死亡率。

## 獨立花園生態的產量與採集瓶頸

一般情境：60日平均蜜露環境產量 **3.069 份/日**，全巢平均糖需求 **2.045 份/日**，兩者事後比值 **1.501**；但平均**實際帶回巢內**只有 **2.096 份/日**，收入／需求 **1.025**。這些數字是跑完之後觀察的**結果**，不是在引擎內用需求直接生成蜜露。蜜露在未探索點存在、被別的蟻群取走、雨水沖走、超出可攜量，都不會變成主巢收入。

一般情境的期末仍有**蛋白存量 0 份、連續缺蛋白 3 日**，雖達成診斷條件，**長期蛋白供應仍是明確弱點，不能宣稱模型已獲物種學的校準**。12組固定種子的額外敏感度測試只有 **11/12** 完全符合診斷條件；失敗種子 `15041999` 於 **Day26 L001因連續蛋白不足死亡**，當日死亡機率遊戲假設為10.5%。**不能隱藏這個反例。** 12種子有 11 組發生過缺糖，說明糖供應並非保證永不缺。

## 品質、可重播及正式狀態

- 所有60日結果同一輸入與種子完整重播一致，資源、人口、食源自然死亡來源及事件白名單由引擎驗證。自然生態無上帝視角額外測試：203項通過；局部資訊與環境獨立性130項通過（其中零工蟻且斷糧蟻后風險160組固定種子的測試，新增風險條件死亡39次、對照僅1次）；一次性遷移測試21/21通過。
- 審閱包檔案僅在本地隔離產出；主 GitHub `main` 的 Day14 仍是唯一正式存檔，沒有 Commit、沒有引擎熱更新、沒有推進 Day15。
- 生態初始盤點、溫度係數、嗉囊訊號模型、昆蟲族群日出生/死亡率都是**尚待日後校準的假設**。不同研究物種的嗉囊機制只能提供可用的機制線索，不能當作 *P. megacephala* 每日每工蟻的實測機率。
