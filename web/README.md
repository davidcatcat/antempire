# web/ — 螞蟻帝國 觀察器（唯讀可視化 MVP）

規則見 [CLAUDE.md](../CLAUDE.md) §8：
- 網頁**只讀取**結果，**不產生正式歷史**，也不寫回 `saves/`、`journal/`；
- 正式推進只在 Node（`npm run advance`）執行。

## 開啟
```
npm run web:export   # 由正式存檔（唯讀）與模擬引擎產生 web/data/*.json
npm run web          # 編譯 web/src → web/dist，並在 http://localhost:8780/ 提供網頁
```
手機與電腦瀏覽器都可使用：拖曳平移、滾輪或雙指縮放、點選工蟻查看資料。

## 看得到什麼
| 世界 | 內容 | 時間 |
|---|---|---|
| **正式遊戲 Day14（唯讀快照）** | 來自 `saves/main.json`、`saves/world-state.json`：地點、紀錄的路線、每隻工蟻的狀態與當日的紀錄活動、蟻后、幼體、死亡個體與死因 | **靜態**：正式 Day1～14 沒有逐分鐘的引擎時間軸，所以不播放動畫 |
| **實驗世界（Day0，非正式）** | 由目前的模擬引擎以固定情境與種子產生（A1、A5、A4，秋季，種子 20270001，各 30 日）：每隻工蟻的行動片段、路線、採集、卸貨、交哺、招募、捕獵、產卵、羽化、死亡；花園食物存量、費洛蒙、天氣 | 日與分鐘的時間軸，可播放 |

**視角**：
- 花園地表：地點、路線、工蟻、食物存量、費洛蒙、已探索路段等疊加圖層；
- 巢內：**非空間名冊**。引擎目前沒有巢室與通道結構，所以只畫出實際存在的蟻后、工蟻、卵、幼蟲、蛹，不畫虛構的巢室；
- 個體：點選工蟻（或用下拉選單）查看年齡、任務、目前行動、位置、嗉囊、記得的地點與路段、今日到目前為止的行動與事件。

## V3：個體追蹤與事件跳轉（Issue #99）
- **追蹤個體**：播放時鏡頭跟著所選工蟻（暫停、播放、倍速都保持追蹤，跨日繼續）。按鈕或拖曳地圖取消；雙指縮放不取消。
  - 跟隨的是畫面上的位置；兩個紀錄點之間是**顯示插值**，面板與地圖左上都會標示。
  - 死亡：在死亡日的日終結算時結束追蹤（引擎沒有死亡時刻）。羽化：日終結算之後才存在。沒有座標的地點：顯示「位置未知」，鏡頭不動。
- **事件時間軸**：列出當天全部引擎事件（未到的事件淡色）。點選後：
  - 跳到引擎記錄的分鐘（精確值，分鐘滑桿 `step="any"`）；沒有時刻的事件只跳到當日「日終結算」；
  - 地點只取事件中**記錄發生地點的欄位**（`EVENT_PLACE_FIELD`：`location`／`site`／`node`／探索的 `to`）。例如招募的 `site` 是招募的目標食源、卸貨的 `site` 是食物來源，都不是發生地點，所以不用；沒有地點或地點沒有座標時顯示「位置未知」；
  - 事件涉及的工蟻（`worker`、`by`／`to`、`from`／`to`、`team` 等欄位）可以點選。
- 手機：地圖與時間控制固定在畫面上方，面板在下方捲動。
- 預覽：CI 的 `antempire-viewer-preview` artifact，說明見 [`PREVIEW.md`](PREVIEW.md)。

## V4：每日生態統計與推得的速度
- `model.dailySeries`：Day0 加上每個模擬日的日終狀態與日摘要，原樣複製，不平滑、不內插；Day0 沒有每日流量（顯示為 —，不填 0）。
- `web/src/charts.ts`：小倍數圖，每張一個量、一個 y 軸，不用雙軸。
  - 圖例與末端標籤，不只靠顏色辨識；顏色經 dataviz 驗證器檢查；淺色主題對比不足的部分以標籤與表格補足。
  - 虛線是目前日子；滑過或輕觸讀值；點一下跳日；另有表格檢視。
- `model.walkSpeedAt`：路段長度（遊戲假設的約距離）÷ 引擎記錄的走完時間；長度未記錄時是 `null`（速度未知）。
  - `tests/web-v4-stats.test.ts` 檢查 1,556 個推得的速度都等於引擎的沿跡速度 17 mm/s 或離跡速度 8.5 mm/s，這是重播一致性檢查。
- `tests/browser/web-stats.check.cjs`：桌面與 Android 觸控。

## 誠實標示
- **地圖座標**：世界設定只有「方位文字＋約距離」（敘事近似值，非測量），座標由這兩者推得，並標示為示意比例。沒有記錄位置的地點（U00、U01、N01、N02）放在「位置未記錄」區，不放進地圖比例。
- **移動**：兩個引擎紀錄點之間（引擎的 `route_step` 到達時刻與行動片段邊界）的位置是**畫面插值**，被選取時會標示。插值不寫回引擎，也不產生任何事件。
- **個體與事件**：畫出的工蟻＝該日開始時引擎狀態中的工蟻；事件清單＝引擎事件（只刪除 `assumption`／`hazards`／`sampling` 欄位，不新增任何東西）。由 `tests/web.test.ts` 驗證。

## 架構
| 層 | 位置 | 責任 |
|---|---|---|
| 模擬引擎 | `engine/` | 世界演化、行為、事件、守恆（不知道網頁存在） |
| 資料匯出（Node，唯讀） | `cli/web-export.ts` → `web/data/` | 讀存檔與執行引擎，輸出世界狀態與事件時間軸 |
| 資料模型（純函式） | `web/src/model.ts` | 位置插值、查詢；沒有 DOM，Node 可測試 |
| 畫面與介面 | `web/src/main.ts`、`web/index.html` | Canvas 2D 繪圖、鏡頭、選取、時間軸；不匯入 `engine/`、不執行模擬 |

## 時間語意（Issue #43 審查後）
- 活動時窗內畫的是**本日開始時**的蟻群名冊；工蟻位置來自引擎的行動片段與 `route_step`（兩點之間為標示的顯示插值）。
- 死亡、羽化、產卵、發育與生態事件在引擎中**沒有時刻**（日終結算）。時間軸在時窗之後多一格「日終結算後」，此時才套用這些事件並畫出引擎的日終狀態；不把它們偽裝成某個分鐘。
- 「今日紀錄任務」是引擎的**日摘要**，不是逐分鐘的目前任務。
- 伺服器：錯誤編碼的網址回 400，不會讓伺服器停止（`tests/web-serve.test.ts`）。

## 測試
- `tests/web.test.ts`（CI）：匯出可重現、已提交資料＝重新匯出、正式快照的個體與存檔一致、事件都來自引擎、插值只在紀錄點之間且不產生事件、畫面不匯入引擎、不寫入存檔。
- `tests/web.test.ts` 另外檢查（所有實驗情境）：每個顯示的事件都來自引擎；羽化的工蟻從下一日起才畫出、死亡的工蟻死亡日之後不再畫出、人口只因紀錄的羽化與死亡改變；日界＝引擎的日終狀態；時窗外與重播範圍外不外推；正式與實驗資料各自宣告類型、載入時檢查，實驗檔不含正式世界的蟻群資料（只讀花園地理）。
- `tests/browser/web-viewer.check.cjs`（**CI 的 viewer-smoke 工作**，也可本機執行）：桌面與手機視窗；正式快照＝存檔的存活工蟻；每個實驗世界標示「非正式」；移動中的工蟻被選取時**必須**顯示「位置為顯示插值」，缺少就失敗；跨日、死亡、羽化與引擎資料一致；重播最後一刻與播放到底會停止；切回正式快照後不殘留實驗資料；無頁面錯誤。
- `tests/web-v3-follow.test.ts`（Node，CI）：所有實驗的每一筆事件，跳轉時間＝紀錄的分鐘或日終結算、地點只來自發生地點欄位、相關工蟻都是重播中的工蟻；事件時刻工蟻畫在紀錄的地點；死亡、羽化、位置未知的追蹤狀態；資料凍結下執行（不寫入）。
- `tests/browser/web-follow.check.cjs`（CI，Playwright）：桌面滑鼠與 Android Pixel 7 觸控的追蹤、取消、跨日、死亡、羽化、位置未知、事件跳轉、篩選與正式／實驗隔離。
- 實驗世界：A1、A5、A4（蟻后＋帶來的蛹；涵蓋羽化），秋季，種子 20270001，各 30 日。

引擎規則變更後，要重新執行 `npm run web:export` 並提交 `web/data/`，否則 `tests/web.test.ts` 會失敗。
