# 螞蟻帝國 觀察器：靜態預覽（GitHub Actions artifact `antempire-viewer-preview`）

這是 CI 由該次 commit 建置的**唯讀觀察器**。畫面上的個體、行動與事件全部來自模擬引擎的輸出（`web/data/`）；觀察器不執行模擬、不寫入任何東西。

> **不是公開網站。** 公開部署需要 Owner 另外授權。這個 artifact 只供下載後在自己的電腦上觀看。

## 內容
| 路徑 | 內容 |
|---|---|
| `site/` | 完整靜態網頁：`index.html`、`dist/main.js`（由 `web/src` 編譯）、`data/`（正式 Day14 唯讀快照、三個 30 日實驗重播） |
| `screenshots/` | 桌面（1280×800）與 Android 手機尺寸（Pixel 7 設定：412×915、觸控）截圖 |
| `test-results/` | 瀏覽器 smoke test、V3 追蹤與事件跳轉 E2E、Node 端 V3 測試的結果 |
| `BUILD.txt` | 建置的 commit 與時間 |

## 打開方式
網頁用 `fetch` 讀 `data/*.json`，所以要經由 HTTP 開啟，直接雙擊 `index.html`（`file://`）會載入失敗。在 `site/` 目錄執行任一個：
```
python3 -m http.server 8780        # 然後開 http://localhost:8780/
npx --yes http-server -p 8780      # 或
```
同一個區網的手機可以開 `http://<電腦的 IP>:8780/`。

從 repo 執行：`npm ci && npm run web`（http://localhost:8780/）。

## 怎麼看
1. 左上選世界：**正式遊戲 Day14**（唯讀靜態快照，沒有逐分鐘紀錄，不能播放或追蹤），或三個**實驗世界 Day0（非正式）**：A1、A5、A4，秋季，種子 20270001，各 30 日。
2. **時間**：「日」與「分鐘」滑桿；播放／暫停；速度 1、5、20、60 分／秒。活動時窗之後多一格「日終結算」：死亡、羽化、產卵、發育在引擎中沒有時刻，只在這一格套用。
3. **選取個體**：點或輕觸地圖上的工蟻，或用「個體」區的下拉選單（巢口附近的工蟻擠在一起時用它）。面板顯示 ID、今日紀錄任務、目前行動、位置。
4. **追蹤個體**：按「追蹤個體」，播放時鏡頭會跟著這隻工蟻；地圖左上顯示「追蹤 Wxxx」。
   - 取消：再按一次按鈕，或拖曳地圖。雙指縮放不會取消。
   - 兩個引擎紀錄點之間的位置是**顯示插值**，會標示出來，不是量到的位置。
   - 地圖座標由「方位＋約距離」推得，是示意，不是測量。
   - 工蟻死亡（日終結算）時追蹤結束；還沒羽化的工蟻不能追蹤；在沒有座標的地點（U00、U01 等）顯示「位置未知」，鏡頭不動。
5. **速度**：選取正在行走的工蟻時，面板顯示該路段的平均速度 = 路段長度 ÷ 引擎記錄的走完時間。
   - 路段長度是世界設定的約距離（遊戲假設，實際路徑長度的下限），所以這是整段平均，不是瞬時速度。
   - 長度未記錄的路段顯示「速度未知」。
   - 這些值等於引擎自己的步行速度：沿費洛蒙 17 mm/s（本種文獻 Vázquez et al. 2020），無費洛蒙 ×0.5（遊戲假設）。
6. **生態統計**：五張每日小圖（工蟻數；卵、幼蟲、蛹；巢內存糧；花園食源存量；氣溫與巢溫），每張只有一個 y 軸。
   - 虛線是地圖上目前的日子；滑過或輕觸可讀那天的引擎數值；點一下地圖就跳到那一天。
   - 「表格」列出每天的全部數字。
   - 花園食源總量是觀察者視角，螞蟻不知道。
7. **事件時間軸**：列出當天所有引擎事件。點一筆就跳到：
   - 引擎記錄的分鐘（精確值）；沒有記錄時刻的事件，跳到當日「日終結算」，不顯示分鐘；
   - 事件記錄的地點（若該地點有座標）；沒有地點或沒有座標時顯示「位置未知」，鏡頭不動；
   - 事件涉及的工蟻可以點選。
   - 「只看所選個體」只列出這隻工蟻的事件。

## 測試涵蓋（見 `test-results/`）
- `web-viewer-results.json`：正式／實驗隔離、插值標示、跨日、死亡、羽化、重播邊界（桌面＋手機）。
- `web-follow-results.json`：選取、追蹤、播放與倍速時鏡頭置中、拖曳與按鈕取消、跨日、死亡結束追蹤、羽化、位置未知、事件跳轉（有時刻、日終、無地點、無座標）、播放中點選事件、篩選、正式快照不可追蹤、切換世界後清空（桌面 1280×800 滑鼠；Android Pixel 7 設定、CDP 觸控事件）。
- `web-stats-results.json`：每日圖表、點選跳日、表格、推得的速度（桌面＋Android 觸控）。
- `web-v4-stats-node.json`：每日序列等於引擎日終紀錄；每個推得的速度都等於引擎的步行速度（沿跡或離跡）。
- `web-v3-follow-node.json`：每一筆事件的跳轉時間、地點、相關工蟻都等於引擎紀錄；事件時刻工蟻畫在紀錄的地點；死亡與羽化的追蹤狀態。

**限制**：手機測試是 Chromium 的 Android 尺寸與觸控模擬，不是實體手機。
