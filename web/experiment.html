這個畫面是什麼


    

  • 非正式實驗世界／不屬於正式遊戲歷史。這是一個合成的小世界（6 隻個體、半徑 60 cm 場地、巢在中心），所有數值都是遊戲假設（assumption: true），不是螞蟻科學模型，不得引用為本種行為。它不讀取正式存檔、Day14 或 web/data，也不寫入任何東西。
    • 

  • 引擎事件：模擬只在 Web Worker 內執行；畫面上的狀態（每隻個體目前線段的起點、終點、起訖時刻、活動）與「引擎事件」列表都是 Worker 送來的原樣資料。
    • 

  • 顯示插值：螞蟻在目前線段兩個引擎紀錄點之間的畫面位置是直線插值；在紀錄時刻（線段起點與終點）畫面位置就是引擎位置。兩個 Worker 狀態之間，畫面時鐘最多超前 0.05 秒真實時間的推進量。腳的擺動、轉身、鏡頭、縮放都只是畫面，不回寫、不產生事件。
    • 

  • 示意：地面紋理（與可選的落葉石塊）、固定光源都是示意；合成世界中沒有障礙物，所以落葉石塊預設關閉。螞蟻放大顯示（畫面左下角 ×N）。虛線圓是合成場地邊界（引擎參數）。
    • 

  • 只觀察：暫停、速度、追蹤個體、縮放、拖曳、畫面幀率上限只改變排程或畫面，不改變同一世界時間的模擬結果（瀏覽器測試比對事件流與完整狀態雜湊）。沒有任何干預功能。
    • 

  • 世界時間：自實驗第 0 天 00:00 起的秒數，顯示為「實驗第 D 天 HH:MM:SS」。光照狀態由一般方法（太陽位置公式）計算；氣溫是合成剖面（synthetic: true），世界中沒有個體讀取它們。
    •
