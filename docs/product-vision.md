# 《螞蟻帝國》產品願景（Owner 2026-11-02 確認）

> 這是 Owner 對專案長期目標的正式確認。它**不放寬** CLAUDE.md、GM 規則卡與存檔規則中的任何限制。若有需要修訂，另開獨立 PR 交 Owner 審核。

## 1. 遊戲定位
《螞蟻帝國》是一款**以科學為基礎、有可視化世界、可以長期遊玩的螞蟻生態養成模擬遊戲**。
- 它不是只輸出文字報告的研究工具。
- 玩家的體驗應該像養了一群真正的螞蟻：打開畫面，就看到自己的螞蟻正在生活，牠們自己覓食、築巢、照顧幼蟲、成長、繁殖，也可能遭遇危險甚至滅亡。
- 玩家不需要指揮工蟻做什麼。

> **科學決定螞蟻如何生活，模擬引擎決定發生什麼事，可視化系統讓玩家看見這一切。**

科學真實性是遊戲品質的基礎，但專案不能永遠停留在研究與參數調整。可視化與科學研究並行發展，不排在「科學全部完成」之後。

## 2. 玩家體驗（目標）
玩家可以看到：
- 螞蟻從巢出發，尋找未知的食物；發現後進食、採集、搬運、回巢；
- 費洛蒙、接觸與其他訊號招募同伴；
- 工蟻自主分工：照顧幼蟲、清理、挖掘新巢室；
- 蟻后產卵，卵發育成幼蟲、蛹、成蟻；
- 大小工蟻不同的身體與行為；
- 螞蟻因年老、疾病、飢餓、受傷、戰鬥等原因死亡；
- 遇到其他蟻群、蜘蛛、其他昆蟲；
- 花園隨天氣、季節與生態自行變化；
- 蟻群成長、分巢、遷巢、競爭，也可能自然滅亡。

**這些都必須由模擬引擎的狀態與事件產生，不能為了畫面好看由介面編造。** 引擎還沒有的機制（例如巢的空間結構、掠食者），畫面就如實不顯示或標示「尚未模擬」。

## 3. 兩種視角必須分開
### 3.1 螞蟻沒有上帝視角（不變）
- 工蟻只能依自己的感官、局部環境、實際接觸、費洛蒙與個體記憶決策（CLAUDE.md §2.1）。
- 牠們不能讀取全世界地圖、全巢營養需求、未發現的食物位置、其他螞蟻的完整內部狀態，也不能讀取玩家或引擎才知道的資訊。
- 世界生態不依蟻群需要調整（§2.2）。

### 3.2 玩家可以有觀察用的上帝視角
- 玩家的**觀察權限**與螞蟻的**認知能力**是兩回事。
- 玩家可以：
  - 看整座花園、巢內、單一工蟻、蟻后與幼體、食物來源與物種分布；
  - 看只有玩家才看得到的統計；
  - 在科學觀察模式中看到費洛蒙、個體路線與生態關係。
- 觀察器只**讀取**引擎的狀態與事件，玩家看到的東西永遠不會回饋給螞蟻的決策。

### 3.3 未來的玩家干預（尚未核准）
- 放置食物、調整生態箱、澆水、改變環境、建立觀察場景等，都只是**未來的設計候選**，不是現在已核准的功能。
- 現在不實作，也不把它們寫成永久禁止。
- 若未來核准：
  - 干預必須是**明確記錄的世界事件**（例如「玩家在某地點放了某物」），螞蟻依自己的規則反應，玩家不能直接控制牠們的決策；
  - 必須先區分**沙盒實驗**與**正式世界**，不破壞正式存檔規則。正式世界是否允許任何干預，由 Owner 另行決定。
- **目前正式模式維持非干預式觀察。**

## 4. 正式世界與實驗世界
| | 正式世界 | 實驗世界 |
|---|---|---|
| 是什麼 | Owner 的那一窩螞蟻：Day1～14 歷史，以及之後的每一天 | Day0 科學初始化、多種子、長期評估、極端情境、未來的沙盒 |
| 時間 | 只在 Owner 明確要求時推進，一次一天 | 可自由執行任意天數 |
| 寫入 | 只有 `npm run advance` 的交易 | 只寫入 `reports/`、`web/data/` 等報告與資料，不寫 `saves/` |
| 可視化 | 唯讀：Day1～14 靜態；Day15 以後可依日誌事件重播 | 引擎事件重播；明確標示「實驗世界、非正式」 |

## 5. 長期發展
1. **看得見的世界**：
   - 地表與巢內兩個視角、個體追蹤、生態觀察圖層；
   - 有時間軸可重播；
   - 手機與電腦瀏覽器都能用。
2. **動態生態**：季節、天氣、日夜、植物物候、半翅目、其他昆蟲與掠食者、多蟻群互動。
3. **完整養成**：長期觀察、存檔管理、成長歷程，以及逐步確立的玩家能力。
4. **多物種**：
   - 未來可能有紅火蟻、行軍蟻、其他大頭家蟻、臺灣常見蟻種；
   - 每個物種有自己的生命史、食性、階級、繁殖、覓食、招募與築巢方式，並附各自的文獻（CLAUDE.md §4）；
   - 不是只換名字、顏色與速度，也不能借用其他物種的實驗數值。

## 6. 科學模擬原則（摘要；完整規則見 CLAUDE.md、`docs/gm-rules.md`）
- 無上帝視角、生態獨立、GM 不干預；
- 數值誠實標註：文獻支持、一般生理學、遊戲假設（`assumption: true`）；
- 不為存活率或通過測試而調參；
- 規則修改獨立 PR，附多種子證據與 golden，從下一個遊戲日起生效；
- 歷史不可改寫。
