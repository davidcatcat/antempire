# v1 → v2 科學生態模擬遷移紀錄
**決策日期**：2026-10-31
**轉換檢查點**：`saves/main.json` 的 v1 第1150分鐘、事件#117；歷史原封不動保留。

## 為何要遷移
舊版是一個玩家下達A/B/C/D、每20分鐘產生固定採集量／新幼體／固定施工進度的加速劇情遊戲。它保有敘事價值，**不是寫實的生理、營養、傷病或生態測量**。不應把工蟻表現解讀為真實蟻群決策。

## 歷史不重寫的原則
- 保留原文紀事與每個 `history` 事件，包括已誕生W001–W017、累計死亡3、目前14工蟻；不以科學模型追究其在舊20分鐘時間尺度下「不可能」而悄悄刪除。
- 保留既有蟻后Q001與幼體0卵／2幼蟲／0蛹、糖3／蛋白質3；但食物是**v1抽象單位**，物理量未知。
- 保留兩育幼空間／一儲藏空間／泥脊防線「故事已完成」；不要把完成百分比看成精確施工工程實測。
- 保留角色W007／W008／W009／W012／W013／W014的既有傷勢描述，但傷勢嚴重度、感染與癒合期限均未知；不自行斷定永久殘廢／痊癒。
- 物種保持未定 `taxon=null`；不以使用者目前住址推斷遊戲花園的氣候或蟻種。
- `journal/chronicle.md` 早期以及 `journal/chronicle_<range>.md` 後續碎片檔都是**不可改寫的 v1 歷史**；不再將多檔案視為目前生態資料真值。
- 第1150分鐘後的**科學世界時鐘**另設Day 0，不將1150分鐘換算成19小時的真實幼體發育。

## 新資料與用途
- `docs/science-model.md`：行為、繁殖、育幼、傷勢、採集及巢穴規則。
- `docs/ecosystem-world.md`：節點式住宅花園生態、資源、競爭者及物理環境。
- `docs/simulation-engine.md`：時間尺度、事件因果、自動分工、資源帳、資料品質、驗收。
- `docs/species-calibration.md`：未知物種的限制、資料校準順序。
- `docs/references.md`：學術論文出處及外推限制。
- `saves/world-state.json`：地圖節點、世界時鐘、環境／物種未知值、傷蟻紀錄及生態觀測。
- `saves/main.json`：保存 v1 歷史，增添 v2 simulation meta，仍為殖群／歷史的權威主檔。世界場景專屬欄位由 world-state 管理。

## 新增遊戲操作方式
- 玩家已要求「整個世界真實自治模擬」，因此 `mode=observer_autonomous` 為預設；**只有使用者要求繼續時才推進**，不偷偷在背景過日。
- 新回合預設推進一個模擬日（可指定20分鐘、1小時、1週等）；短事件不代表幼體會立即長大。
- 不再強制每回合提供A/B/C/D四選一；如果想插手，玩家可要求改造環境、研究一條路線或觀察特定個體。這是外部觀察者干預，不是「蟻后發令」。
- 任何新數據：同時記錄哪些是舊故事觀測、模型假設和未知；不可把「沒有看到敵蟻」寫成「百分之百安全」。

## 風險與未完成事項
**已完成**：文字規格、地景重構、v2世界初始快照、舊存檔銜接。
**尚未完成／刻意不假稱完成**：正式鑑種、物理量校準、體重／能量模型、可重跑的程式級Monte Carlo、實地氣象與昆蟲調查。文字模擬會依這些規則推演，但**尚不等於定量驗證模型**。
