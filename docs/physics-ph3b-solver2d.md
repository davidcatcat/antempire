# PH-3b：事件驅動二維多個體物理解算器（隔離實驗）

> **地位**：隔離的物理實驗。`engine/physics/solver2d.ts`、`engine/physics/broadphase.ts` 不被每日生態循環、Day0、`cli/` 或 `web/` 引用（`tests/physics-isolation.test.ts` 自動涵蓋新檔）。沒有推進遊戲日，沒有改存檔或日誌，`engine/*.ts` 頂層沒有任何修改。
> **只處理物理約束**：讓路、攻擊、交哺、側移、掉頭、誰先走都是**生物決策**，解算器**不做**。走不動的個體就等；永遠沒有東西讓它走，就在時間終點回報「卡住」（stalled）。
> **依據分類**沿用 CLAUDE.md §3。所有情境都是合成世界（`synthetic: true`），不是臺中西屯花園。

## 2. 設計

### 2.1 運動模型
- 每隻沿自己的通道前進，速度 `v ∈ [0, 自由速度]`；**橫向偏移 u 維持給定值**（橫向轉向模型是未知候選，null）。
- 兩個事件之間，每個身體都是直線等速平移 → 每對身體的間距對時間是**凸函數**。
- 轉折處：朝向在轉折點瞬間轉到下一段（與 `body2d.laneBodyPose` 相同的姿態約定；**幾何約定**，真實螞蟻走曲線）。轉動以保守推進（conservative advancement，對角度 Lipschitz）檢查通道邊、障礙物與其他身體；會穿透就不轉，停在轉折點等。
- u ≠ 0 而路線經過轉折：**拒絕**。偏移的身體怎麼繞過轉折是橫向轉向問題（未知），不補一個做法。

### 2.2 連續碰撞偵測（沒有時間步長）
- `pairFirstHit`：兩個平移膠囊第一次接觸的時刻。第一次接觸前兩軸不相交，所以軸距 = 四個「端點對另一線段」距離的最小值；每個都對時間是凸函數，先解析求最小值位置，再在遞減段上二分求 `距離 = r₁ + r₂` 的第一個根。最近距離只差 `HIT_TOL_MM = 1e-10 mm` 以內的擦身不算接觸。
- 結果只取決於兩個個體的運動紀錄（參考時刻、位置、速度），**不取決於任何時間窗、網格、取樣步長**。
- 與 `body2d.sweptCapsuleContact`（三分＋二分，另一套方法）比對 2,000 組隨機案例，時刻一致到 1e-9 s。
- 靜態幾何（通道邊、多邊形邊、圓形障礙物）同樣用 `pairFirstHit`（速度 0 的膠囊）；轉折處的圓弧邊用保守推進。每隻沿自己路線的「第一個碰到靜態幾何的位置」只算一次（幾何不動），到達就停（`stop`，原因寫明）。

### 2.3 接觸約束與速度解（物理約束而已）
- 事件時刻，間距 ≤ `ACTIVE_TOL_MM = 1e-7 mm` 的每一對是接觸；接觸要求 `dg/dt = n·(v_j e_j − v_i e_i) ≥ 0`（n 是兩軸最近點方向）。速度固定時間距是凸函數，所以起點不減就一直不減，到下一個事件都不會穿透。
- 每條約束都是「`v_x ≤ c·v_y`（c ≥ 0）」或「`v_x ≤ 0`」：迎面＝兩隻都停；追上＝跟著前面那隻的速度（c = 1）；從側面擦過＝允許滑過。
- 取**最大解**（每隻 ≤ 自由速度下盡量快）：上界單調，最大不動點唯一（Tarski），以乘積形式的 Bellman–Ford 鬆弛求得；乘積 < 1 的接觸環的最大解是 0。**唯一解 → 與處理順序、陣列順序無關。**
- 接觸間距長到超過 `ACTIVE_TOL_MM` 時解除（`contact_end`，時刻用與判定相同的間距函數求，並推到第一個確實超過的浮點數，避免同一瞬間反覆觸發）。

### 2.4 事件與同一瞬間
- 事件：start、goal（抵達）、geo（碰到靜態幾何）、vertex（轉折）、retry（等待轉折後重試）、contact、release、pass（同一通道錯身）。全序：時刻 → 種類 → 個體 id。
- **時刻完全相同**的事件一起處理：先套用全部，再更新接觸、再解一次速度。
- 每個事件帶兩個個體與該對的版本號；版本變了就是過期，丟棄不執行。另有不變式：同一個接觸事件（個體＋版本）執行兩次就中止並回報缺陷。
- 轉折受阻：只在「真正擋到轉動的」身體離開轉動圓盤（解析求離開時刻）或改變運動時重試，與時間窗無關。
- 安全上限：同一時刻超過 10,000 批、或總批數超過上限 → `aborted`，如實回報。

### 2.5 寬相（broad phase）
- 時間窗 `window_s`（預設 0.25 s，純數值）：每個窗的開頭，對每隻算**保守掃掠框**＝這個窗內以自由速度沿路線最多走到的中心路徑，再四周加 L/2（任何朝向的膠囊都在裡面）。窗內不論發生什麼事件，身體都不會離開這個框 → 窗內所有可能的接觸都在候選對中。
- 三種方法輸出完全相同（排序後的同層候選對）：`bruteForcePairs`（O(N²)，**只當參考**）、`gridPairs2D`（均勻網格／空間雜湊，預設 8 mm）、`sweepAndPrunePairs`（x 排序掃描、y 檢查）。主流程預設網格，不做全對比較。
- 時間窗、網格大小、方法都只改變成本：測試中 7 種設定（窗 0.01／0.25／1／25 s、網格 2／8／60 mm、SAP、暴力、反轉輸入順序）的軌跡與事件**逐位元相同**。

## 3. 保證與容差
| 保證 | 依據 |
|---|---|
| 同層身體間距 ≥ −1e-9 mm（契約容差 `OCC_TOL_MM`） | 共同裁判（取樣點＋取樣之間的 swept 檢查）；獨立密集檢查（`capsuleInLane`、`capsuleGap`） |
| 身體在自己的通道區域內（圓角轉折、接縫精確） | 同上；轉折的每個轉動角度另外取樣 400 點檢查 |
| 結果與陣列順序、時間窗、網格、寬相方法無關 | 逐位元相同（雜湊） |
| 單隻抵達時間 = 出發 + 距離／速度 | 1e-12 s |
| 接觸只執行一次 | 版本號＋不變式；突變測試會被抓到 |

容差都是數值，不是模型參數：`HIT_TOL_MM = 1e-10`、`ACTIVE_TOL_MM = 1e-7`、`NORMAL_EPS = 1e-12`、保守推進停在間距 ≤ −容差/2。

**滑動接觸是近似**：側面擦過的接觸在 `dg/dt = 0` 處以分段等速近似，每當間距重新打開 `ACTIVE_TOL_MM` 就重新解。量測（crossing-traffic-100）：容差 1e-9／1e-8／1e-7／1e-6／1e-5 mm 時批數 204,081／64,718／20,656／6,724／2,316，最終位置與 1e-9 的差 0／8.8e-9／9.0e-8／7.0e-7／7.7e-6 mm（≈ 容差，線性收斂），卡住的個體都一樣（100/100）。`contacts` 計數因此依容差而變，不是物理量。

## 5. 不建模（不宣稱）
- 橫向位置怎麼選、側移、讓路、掉頭、交叉口誰先走：生物決策，未知候選，null。
- 偏移身體繞過轉折：拒絕（見 §2.1）。轉折處瞬間轉向是幾何約定。
- 身體外形是膠囊（遊戲假設），不含觸角與腳；觸角接觸只由裁判依距離計算。
- 推擠、摩擦、質量、加速度：沒有。速度只能在 [0, 自由速度]，不會被推著走、不會倒退。
- 節點（交會點、巢口）幾何：通道端點的平頭邊不當牆；身體伸出端點的部分屬於節點，契約回報「未檢查」。
- 同層內不同通道之間：每隻只受自己通道的邊界約束（與 PH-3a 契約相同）。
- 網頁播放：見 `docs/physics-playback.md`（隔離、非正式，只讀匯出的 JSON）。

## 6. 反例測試（`tests/ph3b-solver2d.test.ts`，BLOCKING）
寬相三法與暴力法相同（60 組隨機框、5 種網格大小、角對角相接、不同層）；`pairFirstHit` 與 `sweptCapsuleContact` 一致（2,000 組）；迎面解析時刻；擦邊（間距剛好 0 不算接觸、近 1e-9 mm 就算）；未知尺寸與寬度拒絕、三隻並排的起點拒絕（與 `lateralPacking` 一致）；邊界（|u| + w/2 = W/2 合法、多 1e-6 mm 拒絕）；偏移身體經過轉折拒絕；窄口（中心通過 1.0 mm 窄口、偏移 0.2 mm 的身體停在前緣碰到牆角的解析位置）；錯身只在幾何允許時（u = ±0.45 在 1.8 mm 通過、u = ±w/2 擦邊通過、再近 1e-9 mm 就兩隻停）；四隻同時到交叉口、兩個接觸同一瞬間開始（一批處理、排列不影響）；層分離（地面與葉面互穿、障礙物只擋同層）；跟隨（以前面那隻的速度、前面那隻抵達時同一瞬間停）；接觸 start／end 交替、每段只開始一次；40 條隨機折線（轉角至 ±69°、寬 0.85–3.85 mm）每個姿態與轉動角都在區域內，幾何停止是必要的；接縫（相接的鋸齒通道中，身體跨過接縫是合法的、在接縫結束處才停；留 0.001 mm 縫的對照組起點即拒絕）；轉折被另一身體擋住、該身體開始移動並離開轉動圓盤後才轉；7 種寬相／時間窗／網格設定逐位元相同；共同裁判（corridor-8、stone、crossing、crossing-traffic-100）0 違規；石頭前停止位置解析。
突變檢查（手動）：拿掉速度約束、拿掉一個接觸特徵、拿掉「前面那隻 id 較小」的跟隨情形 → 測試都失敗。

## 7. 未解缺陷、未知與需要 Owner 決定的事
1. **全部卡死**：crossing-traffic 100／1000 隻沒有任何一隻抵達。物理上正確（沒有決策層），但表示二維解算器必須接上**橫向位置模型**與**讓路等決策模型**才有生物意義；這些模型的本種依據都是 null。需要 Owner 決定先做哪個候選（靠右／讓出空位／隨機側移，皆非本種或未知）。
2. **滑動接觸的近似**：以分段等速近似，事件數約 ∝ 容差^(−1/2)；已量到收斂，但不是解析解。
3. **轉折**：瞬間轉向是約定；重試時刻用「擋路者離開轉動圓盤」，是保守的（可能晚於真正可以轉的時刻）。同時轉向的兩隻若互擋，兩隻都等（保守）。
4. **接觸環**：乘積 < 1 的環一律為 0；浮點捨入可能讓乘積剛好 1 的環被判成 < 1（尚未遇到）。
5. **裁判成本**：1000 隻的裁判時間約 1,203 s（20 分鐘）（取樣點是全部個體事件時刻的聯集）。
6. 尚未做：u 隨時間變化、轉折處的偏移路徑、節點幾何、加速度、觸角接觸事件、網頁顯示、把 PH-3b 接到任何正式流程（需另開規則更新 PR）。
