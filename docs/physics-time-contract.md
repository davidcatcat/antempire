# 物理時間邊界與接觸事件契約（解算器共用）

> **地位**：隔離物理實驗的工程契約（Owner 2026-11 指示，P0）。不接入每日模擬、不在規則指紋內、不推進遊戲日、沒有生物參數。所有數值都是**數值容差**，不是模型參數（遊戲假設也不是）。
> **適用**：PH-3b（`engine/physics/solver2d.ts`）現在通過；WP4 local-steer 等之後的解算器以同一個測試輔助程式採用。
> **上層契約**：世界時間與物理時間的分層契約見 [`p0a0-time-contract.md`](p0a0-time-contract.md)（`layered`：精確時刻排序、同一時刻由生產者決定）。本文件規定**生產者（物理解算器）內部**怎麼產生這些時刻，與該契約條文 2「同一時刻由生產者決定」、條文 3「延遲在原生時鐘上相加」一致。

## 1. 名詞

| 符號 | 值 | 意義 |
|---|---|---|
| H | 輸入 | 時間終點（horizon） |
| θ | 1e-7 mm（PH-3b `ACTIVE_TOL_MM`） | 接觸容差：兩身體間距 g ≤ θ 就是「接觸中」 |
| ρ | 1e-9 mm（`SEP_RES_MM`） | 分離解析度：間距離開 θ 的幅度小於 ρ 就回來，不算分離 |
| ε | 1e-11 mm（`GAP_EVAL_ERR_MM`） | 宣告的間距計算誤差上限（座標捨入、匯出紀錄與解算器內部位置的差）；用來給每個時刻的誤差界 |
| TIME_TOL(H) | 8·2⁻⁵²·max(1, H) s | 時間終點的捨入容差 |

## 2. 時間邊界（`tests/lib/physics-time-contract.ts`）

1. **時間終點是一個處理時刻、運動長度為 0**：t ≤ H 的事件都處理；沒有任何運動發生在 H 之後。
2. **出發時刻 = H**：記一次 `start`（時刻 H）；若出發時已在目標上，於 H 抵達一次（`arrived`）；否則最終狀態是 `started_at_horizon`，位移 0（PH-3b 仍解出該瞬間的速度，`final_speed_mm_s` 只是資訊，不代表有移動）。
3. **出發時刻 > H**：不出發、沒有事件、`not_started`。
4. **`moving`**：出發早於 H、未抵達、H 時可以前進。抵達最多記一次。
5. **不得因浮點漂移延誤事件**：事件時刻由**原始輸入一次算出**（PH-3b：`t = tA + (目標 − sA)·dir / v`，`(tA, sA)` 只在速度改變時重設，經過轉折點不累加）；不得用 `t = 0.1 + 0.1 + 0.1` 這類累加。精確時刻恰為 H 的事件（例如出發 0.1 s＋0.2 mm／1 mm/s；浮點 0.1 + 0.2 > 0.3）落在 (H, H + TIME_TOL] 時視為在 H，必須處理；精確時刻晚於 H 超過容差（例如 1e-9 s）的事件不處理。
6. **與時間終點無關**：同一輸入算到 H₁ 的結果，是算到 H₂ > H₁ 的前綴（H₁ 之前的運動、事件逐位元相同）。唯一例外是時間終點才能決定的事件（`stalled`、`contact_end_unconfirmed`）以及「確認時刻」晚於 H₁ 的接觸事件（§3）。

測試輔助程式 `checkTimeContract(adapter, label)` 只要求解算器提供「單隻在直線通道」的轉接函式，13 個案例（出發在終點／之後、在目標上／不在、0.1+0.2、3×0.1、0.4+0.3、反向、恰在終點、終點後 1e-9 s 等）。PH-3b 67 項全過。

## 3. 接觸事件

**定義**（物理接觸，與解算器內部的約束啟用分開）：
- 接觸中 ⇔ g ≤ θ。
- **contact_start** ＝ 間距第一次到達 θ − ρ 之前、最後一次由上往下穿過 θ 的時刻。
- **contact_end** ＝ 間距第一次超過 θ + ρ 之前、最後一次由下往上穿過 θ 的時刻。間距超過 θ 但沒到 θ + ρ 就回到 ≤ θ，是低於解析度的起伏，**不是分離**。
- 每個接觸事件附：`bracket_s`（解算器自己間距函數的根區間，記錄時刻＝右端）、`err_s`（間距誤差 ±ε 時該穿越時刻的不確定寬度：結束為「穿越前最後一次 g ≤ θ − ε」到「確認前最後一次越過 θ + ε」）、`confirmed_t_s`（到達 θ ∓ ρ 的時刻）、`exact: true`、`usable_as_cause: true`。
- **何時可讀（因果）**：接觸事件的 `t_s` 是事後回推的穿越時刻，但解算器要到 `confirmed_t_s`（間距到達 θ − ρ 或 θ + ρ）才知道這是一段接觸的開始或結束；在 `t_s` 與 `confirmed_t_s` 之間，它可能只是低於解析度的起伏（會被合併、不產生事件）。因此 `usable_as_cause: true` 的意思是「在 `confirmed_t_s` 當下或之後可當原因」：**決策層（行為規則、個體決策）只能在 `confirmed_t_s` 或之後讀到並使用這個事件**，不得在 `[t_s, confirmed_t_s)` 之間用它決策，也不得把決策回溯到 `t_s`（否則等於讀到未來）。排序後的事件表依 `t_s` 排列，只是觀察／記錄用；任何以事件驅動的決策必須以 `confirmed_t_s` 為可讀時刻。
- **不能精確決定的結束一律標明**：時間終點時間距已超過 θ 但未到 θ + ρ → `contact_end_unconfirmed`（`exact: false`、`usable_as_cause: false`）；接觸到終點仍未結束 → 不記結束（開放）。因移除／規則而結束（WP4 出口等）→ `contact_end_estimated`、`usable_as_cause: false`。**不得把估計當精確**。

**求法**：兩個運動紀錄之間兩身體都是等速平移，間距（兩個平移凸集的距離）對時間是凸函數。對每一對追蹤間距在門檻 θ−ρ、θ−ε、θ、θ+ε、θ+ρ 之間所在的區段；下一次跨越門檻：向上跨越（下水平集是包含現在的區間）以指數搜尋＋二分；向下跨越先用膨脹 th/2 的膠囊精確第一次接觸（`pairFirstHit`）找到水平集內的一點，再二分。**搜尋區間只取決於現在時刻與兩個運動，不取決於 H**（近切線的穿越在 1e-16 mm 的捨入雜訊下，取決於 H 的區間會選到不同的根，2e-14 s；已由前綴測試抓到並修正）。轉折瞬間的姿態跳躍在該時刻直接比對。

## 4. 三種接觸（Owner 2026-11-08 決策第 6 題，[#146](https://github.com/davidcatcat/antempire/issues/146)）

保留 §3 的幾何定義，另外分出三種接觸。**三種彼此不能互相推導**；任何一種接觸都**不代表**交哺、招募、攻擊或任何生物行為——之後的行為模型必須寫明它讀的是哪一種接觸，且行為本身要另有依據。

| 種類 | 定義 | PH-3b 輸出 | 時刻的嚴謹度 |
|---|---|---|---|
| `geometric_contact` | 兩身體膠囊間距 g ≤ θ（§3） | 事件 `contact_start`／`contact_end`／`contact_end_unconfirmed`，`contact_kind: 'geometric_contact'` | 根區間＋誤差界＋獨立檢查區間（§3、§5） |
| `constraint_active` | 解算器的不穿透約束 dg/dt ≥ 0 確實放進速度求解（作用集合成員） | `Solver2DResult.constraint_active` 區間：兩隻、`start_t_s`／`end_t_s`（終點仍作用＝`null`）、`start_trigger`（`contact_event`＝接觸事件／`membership_check`＝其他事件時刻檢查到 g ≤ θ）、`end_trigger`（`release_event`／`membership_check`）、`end_bracket_s`（釋放的二分根區間，只在由釋放事件結束時）、`binding_t_s`（第一次**真的限制了速度**的速度求解時刻；`null`＝從未限制）、`binding_solves` | 起點與終點是**解算器狀態改變的精確時刻**（解算器分段模型中約束恰好在此區間作用），**不是** g = θ 的根：約束在碰到（g ≈ 0）時加入，因此晚於幾何 `contact_start`；在第一個 g > θ 的浮點時刻釋放。由獨立檢查器以 ±ε 驗證它與間距的關係（下文） |
| `antenna_contact` | 觸角與他體的接觸（之後的化學感知、CHC 辨識用） | **不支援**：PH-3b 沒有觸角幾何（身體是不含觸角與腳的膠囊）。`Solver2DResult.antenna_contact = null`，永遠不產生；播放檔 `contact_kinds.antenna_contact = { supported: false, value: null }` | — 。CHEM／CHC（[#135](https://github.com/davidcatcat/antempire/issues/135)）需要先建立觸角幾何模型（觸角長度、角度、掃動範圍皆未知，null），**不得**由身體接觸推得 |

**不能互相推導的實例**（`tests/ph3b-contact-kinds.test.ts`）：
- 幾何 ⇏ 約束：`pass-graze` 兩隻並排錯身，間距進入 θ 以內（1 段幾何接觸），但從未碰到（g 沒到 0），約束從未作用（0 段）。
- 約束 ≠ 接觸段：`crossing-flank` 1 段幾何接觸內有 1,567 段約束作用（滑動近似的重解）；100 隻 97 段幾何接觸、10,261 段約束區間。
- 約束作用 ⇏ 限制速度：兩隻同速貼著前進，約束自 t = 0 作用但從未限制速度（`binding_t_s = null`）。
- 身體接觸 ⇏ 觸角接觸：PH-3b 沒有觸角，不輸出。

**constraint_active ⊆ geometric_contact**（獨立檢查器 `checkConstraints`）：每段約束區間 (1) 起點 g ≤ θ + ε；(2) 區間內 g 不超過 θ + ε；(3) 釋放時 g ≥ θ − ε，有 `end_bracket_s` 時根區間包含終點；(4) 落在同一對已記錄的幾何接觸段 [開始檢查下界, 結束檢查上界]（開放段到 H，容差 1e-12 s）之內；若不在任何段內，整段間距必須都在 θ − ρ − ε 以上（g 在 (θ − ρ, θ] 的約束未成為確認的接觸段：低於解析度，計數、不算違規；目前所有情境都是 0）。正對照：約束區間提前 0.05 s、捏造一對約束、釋放後延長 0.1 s，都會被抓到。

**軌跡不變**：這是唯讀的帳本，不回饋運動。所有 PH-3b 情境（solver-compare 6 個、播放 4 個）的運動紀錄、既有事件欄位與既有統計，與分離前的 83397c5 **逐位元相同**（測試以 sha256 斷言；1000 隻由裁判重跑記錄，見 [`physics-ph3b-solver2d.md`](physics-ph3b-solver2d.md) §4.5）。

## 5. 獨立檢查器（`prototypes/physics-check/contact-check.ts`）

另寫的程式，**不匯入 engine/ 或任何解算器**，契約數值是複製不是匯入（測試確認兩邊相同）。只讀匯出的分段運動（播放檔的格式）與事件表：
- 兩個運動的共同分段上間距是凸函數；分段兩端與最小值（黃金分割）判定是否跨越門檻，跨越時二分到浮點解析度；以掃掠盒距離作下界快速排除。
- 結束的檢查區間：c ＝ 第一次 g > θ + ρ − ε；lo ＝ c 之前最後一次 g ≤ θ − ε；hi ＝ c 之前最後一次 g ≤ θ + ε 之後的時刻。記錄的結束必須在 [lo, hi]；開始對稱。
- 另查：漏記的接觸（任何不在已記錄接觸內的 g ≤ θ − ρ − ε）、開放接觸其實已分離（g > θ + ρ + ε）、穿透（g < −1e-9 mm）、運動紀錄（無瞬移、位移＝速度×時間、路徑長＝∫速度 dt）、事件依時間排序。
- 正對照：結束移 1 ms／提前 1 µs、刪掉結束、刪掉整段接觸、精確結束改標估計、在滑動的約束重解處插入結束（6864974 的行為）、身體移入 0.3 mm、紀錄之間 1e-6 mm 瞬移，都會被抓到。
