# 共用物理接觸約束契約（Owner 決定 42）

> **地位**：隔離物理實驗，**非正式**；不接入每日模擬、不推進遊戲日、不改正式引擎。`engine/physics/solver2d.ts`（PH-3b）與 `engine/physics/kinematics2d.ts`（KIN-2D）**逐位元組不變**（測試比對 SHA-256）；兩者現行的接觸反應保留為**比較基準**。
> **程式**：契約與參考投影器在 `engine/physics/shared-contract.ts`（`projectVelocity`、`laneFollowProjection`）；KIN-2D 的選用模式在 `engine/physics/kinematics2d-contact.ts`（`runKinematicsWithContactMode(input, 'project')`；`'freeze'` = 原本的 `runKinematics`）。
> **測試**（阻擋性）：`tests/physics-contact-constraint.test.ts`（下表由測試重算，必須逐字相同；重算：`node prototypes/physics-shared/compare.ts`）。

## 1. 原則（物理約束，不是生物行為）
1. **不穿透**：任何兩個形狀的間距 g 不得小於 0。
2. **接觸反應＝速度約束**：對每一對接觸中的形狀，最近點的相對法向速度不得壓縮接觸（ġ ≥ 0），與局部幾何一致。
3. **執行速度＝最接近指令的可行速度**（求解器速度座標下的歐氏投影）：指令不壓縮接觸 → 原樣執行；可沿障礙邊界移動 → 保留切向分量（側滑）；沒有可行方向 → 停。
4. **不推擠**：兩個求解器都沒有質量與力，所以一個身體**不會被另一個身體推動**。只有自己的指令在縮小間距的一方要讓；它讓的是對方**實際執行**的運動（例如後者的速度被約束成前者的速度）。雙方都在接近時，各自移除自己的接近分量（兩者都停）。
- 「跟車」**不是**社會行為；本契約只描述不穿透的物理約束。螞蟻接觸後實際做什麼（等待、後退、轉向、觸角接觸）本種沒有資料，**未模擬**。

## 2. 參考投影器
- 通式：在速度向量 x 上，min ‖x − x₀‖²，限制 aᵢ·x ≥ bᵢ。以**列舉作用集**求精確解（KKT：乘數 ≥ 0、所有列滿足）；列數 > 12 時拒絕（`too_many_rows`），不近似。矛盾的列回報 `infeasible`（呼叫端停下）。
- **PH-3b 對應**（1-D 路線速度）：每個跟隨者一列 −v ≥ −v_前者，投影結果 v = min(v_指令, v_前者)，**正是 PH-3b 現行的跟隨規則**（測試逐例比對）。PH-3b 本身不改；它已符合本契約的 1-D 形式。
- **KIN-2D 對應**：投影變數是身體座標的平移速度 (v, vl)；指令的角速度 ω 保留（KIN-2D 沒有慣性與力矩，接觸不會讓身體旋轉）；若沒有任何平移能滿足約束，身體完全停下（v = vl = ω = 0）。

## 3. KIN-2D 選用模式 `project` 的數值處理
- 自由的一對：與 KIN-2D 相同的保守前進；兩個身體都只平移時，間距對時間是**凸函數**，改用精確的二分（找最小值再找第一次越過 θ），不會在擦邊時停滯。
- 已接合的一對、兩者都只平移：投影使初始 ġ ≥ 0，凸性保證間距不減；下一個事件（接觸結束 θ + ρ、約束釋放）以二分求得。有旋轉時改用保守前進，達到迭代上限就停下兩個身體並記錄 `solver_status`。
- **釋放帶** `RELEASE_GAP_MM = 1e-3` mm：約束從接觸起保持到間距超過此值（數值遲滯，不是模型參數）。平面邊界上的滑動是精確的；**曲面**（圓石）上的滑動由多段切線組成，與真正貼著曲面滑動的間距差 ≤ 1 µm，並產生多次接觸／分離事件（下表「接觸數」）。
- KIN-2D 計畫是**依時間**的指令：被減速的身體不會補回距離；PH-3b 依終點行走。這是兩個求解器的計畫語意不同，不是約束不同（見「追撞（終點 100 mm）」）。
