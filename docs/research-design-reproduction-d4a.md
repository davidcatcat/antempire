## 1. 兩份 PR 的關係與審查結論（摘要）
- #53 是文獻調研（RP-01～RP-13），#55 複核 #53 並提出 ODD 子模型與 RR-1～RR-8。兩者互補，也互相修正，必須一起看。
- #55 對 #53 的更正（E1～E14）：10 項成立，E1、E13 部分成立，E11、E12 有部分無法查核（審查報告 §4）。
- **重要的新發現**（審查報告 §5）：
  1. **Yuan 2026 的繁殖蟻 37.60 日不是量測值**：繁殖幼體從野外群的三齡才開始追蹤，卵期與幼蟲期借用工蟻的數字；SD 3.20 正好是 2.74＋0.46 直接相加。可用的本種逐隻量測只有繁殖型前蛹 4.16 日、蛹 12.31 日（28°C，雌雄合併）。
  2. **兩份 PR 都漏掉 Reimer 1991 的 pyriproxyfen 組**：處理後出現少數蟻后型幼蟲（都未化蛹），對照組沒有任何繁殖蟻幼體。這是本種 gyne 分化與保幼激素方向有關的干預證據（方向，不是數值）。
  3. **Fournier 2012 的「50～75% 同胞交配」是超級殖群層級的 f**（0.207～0.431），族群層級只有約 0.10～0.12（兩個類群的 95% CI 都包含 0）；而且資料來自喀麥隆原生區的隱蔽類群，不能直接套用臺中。
  4. **Liu 2022**：取樣時已用攻擊試驗挑選不同的群（選擇偏差）；「無距離隔離」作者自己歸因於樣本少；歷史上的長距離擴散不能轉成每日婚飛機率。
  5. **分巢的引用鏈找不到一手觀察**（Hoffmann 1998 本身是綜述）。
  6. **#55 的錯誤**：把 Reimer 說成「蟻后控制受精」的證據（不當外推）；以 R101、R141 支持「化學辨識」不成立（Fournier 發現表皮碳氫距離不能預測攻擊；Liu 沒做化學分析）。

## 5. 與開放生態的交換（同一本帳）
- 婚飛離巢、分巢群離開、外來雄蟻或 gyne 進入、外部同種群的覓食者進入，都是 `docs/spec-open-ecology.md` §d 的邊界事件。
- 出發區減一、到達區加一；個體 ID 不重用，不能同時出現在兩個區域；攜帶的食物以 `food_transfer` 轉移，不能憑空出現。
- 焦點蟻群的人口守恆式（`engine/day.ts`：工蟻數＋死亡＝前一日＋羽化）要改為加上遷入與遷出（開放生態 OE-7 與 RR-8），這是規則更新，不是重構。
