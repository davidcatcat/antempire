# V6-2 實驗模式（P0-A2 PR 3：Worker × 分層畫面）

> **地位**：非正式實驗世界／不屬於正式遊戲歷史。預設世界是 **P0-A2 24 小時個體行為世界**（**候選／實驗世界，非正式**；Owner #201：未經 Owner 核准不建立正式 Day0；§7）；另可選 [`experimental-worker-runtime.md`](experimental-worker-runtime.md) §5 的**合成**小世界（全部遊戲假設，不是螞蟻科學模型；`?world=synthetic`）。本頁不修改正式觀察模式（`web/index.html`、`web/analysis.html`）、正式每日循環、Day14、`saves/`、`journal/`，不推進遊戲日。

## 1. 入口與分離

- 網址：`web/experiment.html`（`npm run web` 後開 `http://localhost:8780/experiment.html`：先顯示選單，見 SAVE-2；加 `?seed=N` 是不存檔的臨時實驗，`&autostart=0` 只建立世界、不開始）。頂列固定顯示「非正式」標籤與「非正式實驗世界／不屬於正式遊戲歷史」。
- 正式模式（`index.html`→`game.ts`、`analysis.html`→`main.ts`）的匯入圖**不包含** Worker client 或實驗頁；瀏覽器測試確認兩頁都不建立 Worker、不載入 `worker-dist/`。
- 實驗頁的匯入圖沒有 `fetch`、XHR、儲存 API，也不含 `data/`、`saves/`、`journal/` 路徑；瀏覽器測試確認它不請求這些路徑。
- 模擬只在 Worker 內執行（`experimental/worker-client.ts` 是唯一可建立 Worker 的檔）。主執行緒只送排程／觀察指令並畫圖，不匯入 `engine/`、`prototypes/`、`cli/`（`tests/worker-boundary.test.ts`、`tests/web-v62-experiment.test.ts`）。

## 2. 畫面內容與資料分類

| 類別 | 內容 |
|---|---|
| 引擎事件／狀態 | Worker 每拍送來的狀態框（每隻個體目前線段的起點、終點、起訖時刻、活動、是否在巢內；環境日期、光照狀態、合成氣溫）與事件列表（「引擎事件」按鈕，原樣顯示 seq、時間、種類）。 |
| 顯示插值 | 個體在目前線段**兩個紀錄點之間**的位置（直線插值）；兩個狀態框之間畫面時鐘最多超前 0.05 秒真實時間的推進量；腳步、轉身、鏡頭、縮放。只供畫面，不回寫、不產生事件。 |
| 示意 | 地面紋理、可選的落葉石塊（預設關閉：合成世界**沒有障礙物**）、固定示意光源。虛線圓是場地邊界（引擎參數 `arena_radius_cm`）。螞蟻放大顯示（左下角 ×N）。 |

- 在紀錄時刻（線段起點、終點）畫面位置**就是**引擎位置：`v62-model.poseAt` 在 k≤0 回傳起點、k≥1 回傳終點（不做 `from + (to−from)×1`，以免浮點誤差）；只有 0<k<1 才標為插值。巢內個體不畫位置，只計數。
- 世界時間：自實驗第 0 天 00:00 起的秒數（`t_sim`），顯示為「實驗第 ⌊t/86400⌋ 天 HH:MM:SS」。

## 3. 操作（只觀察）

開始／暫停／繼續、觀察速度（1×、5×、10×、60×、600×、3600×；**預設 1×**，Owner 決策 47）、追蹤個體（下拉選單或點選螞蟻後「鏡頭追蹤」；Worker 只回傳該個體的唯讀副本）、滾輪／雙指縮放、＋／－按鈕、拖曳平移、「全場地」、畫面幀率上限（60／30／15，只影響畫面）、示意落葉石塊開關。**沒有任何干預功能**（不能改食物、天氣、個體、參數或種子）。

## 4. 驗證

## 5. 效能數字的性質

瀏覽器測試記錄畫面間隔（fps）、主執行緒工作時間（CDP `TaskDuration`／`ScriptDuration`，每秒）、JS heap、Worker 推進量（世界秒／真實秒）與是否落後，另以 4 倍 CPU 節流量測一次。這些都是**無頭 Chromium 在測試機器上的數字**；Pixel 7 是模擬視窗與觸控，**不是實機**；Worker 自身的 CPU 沒有量測。不以這些數字宣稱達成任何幀率目標（Owner 決策 50）；畫質自動降級只影響畫面，不影響個體或事件。

## 6. 限制

- 合成世界不是科學模型。P0-A2 世界已接入（§7），但它本身是隔離原型：多數參數是遊戲假設或他種外推，日夜活動分布未經科學驗證（`docs/p0a2-24h-prototype.md`）。
- 合成世界的畫面光源固定（示意）；P0-A2 世界的畫面光照依引擎光照狀態（§7）。
- 跨環境（Node 與 Chromium）逐位元組相同的限制見 [`experimental-worker-runtime.md`](experimental-worker-runtime.md) §6；本頁的「UI 操作不改結果」比較都在同一個瀏覽器內進行。
- 選單、自動存檔與接續（SAVE-2）見 [`experimental-save-system.md`](experimental-save-system.md) §12c；`experiment.html` 不帶參數時先顯示選單，`?seed=N` 是不存檔的臨時實驗。

## 7. P0-A2 24 小時個體行為世界（#156 第三階段）

- **入口**：選單「開始新遊戲」的「世界」預設為「P0-A2 24 小時個體行為世界（候選／實驗世界，非正式）」；臨時實驗 `?seed=N` 預設也是 P0-A2（`&world=synthetic` 選合成世界）。頂列標示「非正式實驗世界／不屬於正式遊戲歷史｜候選／實驗世界，非正式｜P0-A2 24 小時個體行為世界」。存檔、自動存檔、繼續、讀取、匯出／匯入都適用（存檔清單顯示「工蟻 30、幼蟲 8」，沒有蟻后，不捏造）。
- **世界**：30 隻小工蟻、8 隻幼蟲、一個情境蜜露源；每隻工蟻依自己的生理與局部訊號在巢內休息、巢內走動、育幼、走向巢口、出巢（沿路線或搜尋）、取食、回巢之間轉換；環境（日出日落、合成氣溫）是時間的純函式。模擬只在 Worker 內（`experimental-worker-runtime.md` §9）。

| 類別 | P0-A2 畫面上的內容 |
|---|---|
| 引擎狀態 | 每隻工蟻的活動與開始時刻、巢內／巢外、自己的嗉囊比例（巢內圖點的填色）、路線記憶；路線往返的出發與抵達時刻；幼蟲腸道比例（巢內圖幼蟲的填色）；路線長度 200 cm（`source_distance_mm`）；光照狀態（日／曙暮光／夜）；合成氣溫；事件列表（世界自己的日誌行，原樣）。蜜露存量是**玩家視角**（沒有工蟻讀它）。 |
| 顯示插值 | 去程／回程工蟻在「出發（巢口或食源）」與「抵達」兩個引擎紀錄點之間沿路線的位置；在紀錄時刻（`since_s`、`until_s`）畫面位置**就是**路線端點（`v62-p0a2-model.p0Pose` 在 k≤0、k≥1 回傳端點）。腳步、轉身、鏡頭、縮放。 |
| 示意 | 路線**方向**（模型只有長度，畫面固定一個方位）；搜尋中工蟻的位置（搜尋沒有空間模型，畫在巢口周圍並以虛線圈標示）；取食工蟻在食源周圍的排列；**「巢內（示意）」小圖**：巢內位置沒有模擬，只依引擎狀態分組（休息／巢內走動／育幼／巢口通道）；陰影方向（上午東、下午西）；蚜蟲圖示；地面紋理。 |

- **日夜**：畫面光照取自 Worker 狀態框的光照狀態（工蟻在巢口感知的同一個值）與太陽高度（`engine/clock/solar.ts` 一般方法，只供畫面），分段（夜、曙暮光、日：太陽高度 <15°、15～40°、≥40°）以免每幀重新烘焙；分段改變時重設場景。光照標籤寫明「引擎光照」與「陰影方向示意」。
- **點選與追蹤**：可以點地表上的工蟻或巢內小圖中的點；卡片顯示引擎狀態，追蹤時附 Worker 的唯讀副本（近期接觸、碰到的幼蟲、已代謝量、個體門檻）。巢內工蟻沒有地表位置，鏡頭不移動。
- **驗證**：`tests/web-v62-experiment.test.ts` §4b（Node）：兩個種子各 24 小時、每 97 秒一個狀態框：路線上的工蟻在出發／抵達時刻畫在路線端點、之間是落在路線上的顯示插值；搜尋點標為示意；巢內小圖恰好列出所有巢內工蟻；畫面光照名稱依引擎光照；與頁面相同的指令序列（追蹤、改速、暫停、不同拍長、分段推進）→ 事件摘要、事件數、事件日誌雜湊、完整狀態相同。`tests/browser/v62-experiment.check.cjs`（桌面、Pixel 7）：標籤；預設 P0-A2；暫停後在 10 個往返紀錄時刻，每隻畫在地表的工蟻＝其引擎姿態的仿射映射、出發者正好在路線端點；22:30 夜光、次日 12:00 日光；點巢內小圖選取＋追蹤；真實輸入（暫停／繼續、速度、縮放、拖曳、追蹤、幀率上限、示意開關）→ 與只推進的新頁面事件摘要、事件日誌雜湊、payload 雜湊相同；3600× 量測（只記錄）。`tests/browser/save2-acceptance.check.cjs` 預設以 P0-A2 世界跑完整 SAVE 驗收（`SAVE2_WORLD=synthetic` 改用合成世界）。
