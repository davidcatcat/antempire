# 存檔規則

此 repo 是《螞蟻帝國》的遊戲進度資料庫，**不是遊戲程式碼專案**。

## 資料分工

- `saves/main.json`：唯一的主存檔，供下次續玩快速讀取；包含狀態、決策和待處理事件。
- `journal/chronicle.md`：給玩家閱讀的劇情編年史；事件持續追加、不覆寫歷史。
- `README.md`：專案入口及續玩指引。
- Git commit history：每次存檔的版本紀錄，可以回溯。

## 一次遊戲回合的寫入流程

1. 先讀主存檔，確定目前章節、角色、資源和待決策項。
2. 玩家決策後，推演結果應有明確因果：時間、事件、增減、傷亡、巢室變化。
3. 將確定的結果追加到編年史，更新 JSON；不要把候選選項當成已發生。
4. 如有新的選項，將其寫入 `pending`，**不得替玩家自行作重大選擇**。
5. 寫入 GitHub 後核對內容，向玩家簡短說明存檔成功與當前決策點。

## 連續性及數據

- `null` 表示未知，而不是零。
- `confirmed_born` 是累計已確認出生，不等於現存活數。
- 沒有玩家確認或已記錄的事件，不應回填成歷史。
- 如未來新增遊戲規則、物種細節和資源單位，放到 `docs/`；以當時版本的規則計算。
- 進行重大敘事修正時，保留原記錄並追加校正說明，不悄悄改寫事件。
