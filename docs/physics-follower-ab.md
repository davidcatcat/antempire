# 接觸後跟隨者 A/B：「減速到前者速度」與「停下」（#189、#193 裁示第 11 項）

> **地位**：隔離物理實驗・整合候選・非正式（非本種／假設）。只用 `engine/physics/lane-flow.ts`（KIN-2D 身體、目的地帳、進場控制、決策層）比較兩種接觸反應；**沒有選出勝者**，兩者都保留可選（`contact_response` 沒有預設值，必須由呼叫端指定）。沒有改任何解算器，golden 逐位元組相同。
> **不宣稱**：本種沒有接觸後跟隨行為、讓路或速度差異的資料。這個比較只說明兩種**物理反應規則**在相同情境下的後果，不是哪一種「像螞蟻」。

## 3. 讀法（不選勝者）

- **安全**：兩組在所有情境、所有種子都 0 穿透、0 漏接觸、守恆、無瞬移、重跑逐位元相同；最小間距為正（`slow` 約 θ = 1e-7 mm，`stop` 約 5e-8 mm，即 KIN-2D 的保守推進層級）。安全性本身不能區分兩者。
- **單向**：吞吐 `slow` 1.65–1.80 /s、`stop` 1.40–1.80 /s，範圍重疊；`stop` 的停滯比例 6–13%、`slow` 0（被減速的跟隨者仍以前者速度前進）；`stop` 的接觸次數約 8 倍（合併後 221–369 vs 22–39），因為每次決策恢復前進就再撞上前者（停—走循環）。排隊等待 `slow` 0.35–1.02 s、`stop` 0.68–1.16 s。
- **雙向**：兩組都幾乎完全卡死（迎面同一條線上雙方都等；抵達 `slow` 2–4、`stop` 0–1；終點時約 70–77 隻仍在等進場）。這是決策規則 `go_unless_oncoming` 沒有讓路／繞行的**結構性失敗**，不是接觸反應造成的；`stop` 的約束區間約 1,900–1,960（停—走循環）。
- **極端 1,000 隻同點**：兩組完全相同（同速、單一入口，入口每次只放一隻，沒有追撞）。
- `slow` 的「原始」接觸段數（348–577）主要是 θ 附近的數值抖動（段界重新開始接觸遲滯，見 §4），合併後才是可比較的接觸次數。

## 4. 已知問題（如實記錄，未修）

- **分段不變性未通過**（裁示第 6 項指標）：只多切一些沒有行為意義的段界（每 0.37 s）時，觀察者視角（固定時間格的位置、抵達、帳目）就改變：`slow` 位置最多差約 0.069 mm；`stop` 出現結構差異（抵達或帳目事件不同）。原因：每個段界都從目前姿態重新開始 KIN-2D（接觸遲滯 `touching`／`engaged` 狀態不跨段保存、閉式姿態重新錨定），而 `stop` 的離散停止會放大微小差異。決策時刻本身也是段界，所以結果也依賴決策間隔。修正需要讓 KIN-2D 接受跨段的接觸狀態，或改用絕對時間的位置計算（裁示第 8 項，另案規則更新），本 PR 不做。
- `slow` 的約束區間與原始接觸段同樣受段界影響（數值抖動）。

## 5. 尚未驗證／仍是假設

- 個體速度差異（SD 2.5 mm/s）、決策規則、感知半徑、決策間隔、巢口容量都是遊戲假設；結論只對這組假設成立。
- 本種沒有接觸後反應、相遇讓路的影片或量測（#193 裁示 6：應優先蒐集）；兩種反應都未經生物驗證。
- 雙向卡死說明需要讓路／繞行的候選（WP4 的 A／B／C 或轉向主候選），不在本 PR 範圍。
