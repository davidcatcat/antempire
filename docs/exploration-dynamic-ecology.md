# 《螞蟻帝國》v2｜未知世界探索、移動速度／半徑與自治生態隨機變化

> 研究規則整合日 **2026-11-01**；**自下一次 Day5→Day6（遊戲日 2026-11-05）起生效**，未推進遊戲時間，不更動既有個體、巢穴、食物與事件。虛構臺中市西屯區別墅花園；蟻種、巢外地面微氣候、路線真實長度、個體跑速與精準搜尋半徑均 **null**。本規格有文獻支撐「機制」，**不是特定物種校準過的速度與生態概率引擎**。參照 [references.md](references.md) R79–R92，以及 R07、R17–R31、R32–R48。

## 1. 先分開四種空間和時間指標
- **瞬間步行速度** `walking_speed_mm_per_s`：有在走的時候多快；不包含停下來觸角搜索、避敵、搬運和休息。身體大小、載重、溫度、傷勢與地表基質都會改變速度。
- **單次出行實走路長** `trip_path_length_cm`：蜿蜒路線、樹葉繞行與折返的累積距離；不是從巢口到目的地的直線距離。
- **最大離巢距離** `trip_max_nest_distance_cm`：本次出行最遠離N00多遠；未量測時null。
- **搜尋覆蓋區** `actually_searched_cells` 和 `coverage_area_cm2`：工蟻**實際感知或探過**的局部地表；「經過」不等於仔細檢查，也不等於所有隱藏物資都會被發現。
- **有效回巢時間** `time_budget_for_return`：出巢、探索、補給／載物、迴避、找路與回巢互相競爭；超時可以在外留宿、迷路或死亡，不得瞬移回巢。

### 文獻中的速度與範圍（只作跨物種量尺，不能轉成Q001參數）
1. `Temnothorax rugatulus`：空曠實驗場地**移動中的速度中位數8.3 mm/s**，78%個體的轉向表現近似規律左右交替；交替尺度約10mm（約3體長）。研究對象/arena與本花園不同 [R79]。
2. 樹棲`Cephalotes goniodontus`：舊有植物路徑的平均**4.39 cm/s**（20隻；路線38cm），枝葉實走距離可為直線距離2–5倍；**樹上已知路線速度不等於未知地棲工蟻速度** [R80]。
3. `Camponotus fulvopilosus`：野外**平均覓食距離20±6.3m，範圍8–31.3m**（14個體）[R81]；`Myrmecia croslandi`在一研究中地面捕食多於巢周2–3m，樹上資源可達5–15m [R82]。都不是本巢的固定活動半徑。
4. `Pogonomyrmex barbatus`殖群覓食區隨成長與年度發生變化，並非固定同心圓「每年擴1公尺」[R83]；部分採種子的收穫蟻單次路程時間與移動速度差異大 [R84]。
5. 氣溫、地表溫度、濕度與雨的影響在阿根廷蟻及收穫蟻有實驗支持 [R85,R86]，但研究物種的活動最適溫、停止溫度**不得套至本未知黑色花園蟻**。

**本世界目前不會設定「一隻工蟻每20分鐘走X公尺，探索半徑Y公尺」的假精準數字。** `walking_speed_mm_per_s=null`，`effective_foraging_radius_m=null`，`path_length_cm=null`。當日可記「短程／延伸／受阻／繞行／搜索中」，並通過**移動需耗時間、只能訪問連通路段、不可瞬移**的保守規則；若日後物種與地形有校準值才啟用物理行走距離計算。**標稱參考值不可當作實測或正式遊戲參數。**

## 2. 工蟻在未知地區如何搜尋？
參照 Popp & Dornhaus 2023 [R79]、面積限制搜尋綜述 [R87]、未知導航實驗 [R88]、跨402蟻種資源分布文獻 [R89]：
- **初次離巢的學習／定向**：先保持與巢／已知地標有可建立的關聯，部分蟻種需在巢口附近學習方向。不能聲稱未識路的個體出門立即知道全地圖。
- **舊路線跟隨**：如果個體自己知道該路線或確實感知到物種適用的訊號，可以沿路接近熟悉節點；**路徑費洛蒙能力仍屬未知、歷史弱氣味濃度仍null**。
- **廣域搜尋（extensive/CRW）**：未知區域可用**相關隨機步行**與持續的方向偏好；步長、轉向、實際運動需受身體／基質／障礙物限制，不能每20分鐘隨機瞬移不同F節點。
- **局部密集搜尋（ARS）**：當個體真的聞到／接觸到疑似食物、在某處有過報酬或觀察到線索，可以在附近增加轉向、降低位移擴散、仔細搜尋；線索消失、投入時間過長可能退出。
- **學習與局部認知地圖**：每隻工蟻只記錄自己走過的路、接觸過的同伴線索，以及返回過程成功／失敗。即使W015在U00邊緣走過，也不能直接知道U00全部地貌、其餘未知X區域或藏有哪隻蜘蛛。
- **路線回返**：保留回巢路徑時間和體力，不一定成功；受傷、負載、強降雨、人為阻隔或植被倒伏可改變可通行性；未證實路線不會因「地圖顯示相鄰」直接連通。
- **多隻工蟻**：多隻可能採同路，也可能為降低重疊而在不同方向各自探索；巢內接觸信息不是GPS傳送，需整合[ant-communication.md](ant-communication.md)。

## 3. 世界地圖與殖群知識分開（fog of war）
**兩層完全分離**：
A. `latent_ecology`——背景世界的虛構真實狀態（模擬器可更新，事件必須有時空、生態前提）。**不表示在現實臺中真正有這些昆蟲／植物**。
B. `worker_knowledge`——只有該工蟻實際經過／感知的局部線索；`colony_reports`只含帶回、觸角接觸或留有可感知訊號之事項，不能神奇同步整個世界。
C. **觀察者報告層**：可以在日誌獨立呈現「背景生態變化（本巢未察覺）」作科學推演，但**該資訊不可加入工蟻認知或作為工蟻出勤決策的直接輸入**。

**已知現狀**：N00與F01–F11存在此前故事世界，U00是一片**尚未探完的未知住宅花園**；Day5只有W015到過U00的草根縫外緣，沒有證實食物。新增`X01–X04`僅為**遠離已知節點的外圈候選區域佔位符**，不是已確認存在的牆、排水溝、隣居門牌、植物或敵巢，也不是已經實際連通或有可採食物的新F節點。

探索時依序`known_node → real_reachable_frontier → local_sensory_observation → confirmed_terrain_and_obstacle → possible_resource_or_rival_encounter → memory_only_for_present_worker → possible_return_and_contact`。只有局部地貌確認後，才能把X候選扇區細分為真正有證據的地圖節點、路線或食源；空載探查也可增加有限知識。

## 4. 不靠螞蟻觸發的外部世界：生態自治 + 隨機擾動
世界每次模擬日先於螞蟻行動**自行演化**，即使所有工蟻當天都留巢。根據 Lanan 2014的402蟻種比較 [R89]，食源在空間與時間的集中度、可耗竭性會影響覓食策略；2024年的隨機格點覓食研究展示可以用可重播的隨機步驟得到群體路徑回饋 [R90]。

| 世界子系統 | 每日潛在變化／因果 | 必須具備的前置條件 |
|---|---|---|
| **花朵／植物／蜜露** | 開花／凋謝、葉片生長、植物受傷、蚜蟲族群移動、蜜露供給暫時增減 | 相關宿主或花朵已在模擬中存在；未知植物不直接宣告滿滿蜜露 |
| **昆蟲／腐屑** | 一隻新昆蟲活動／意外死亡形成**新的**屍體、昆蟲屍體被分解者移除、果實繼續腐敗 | 新屍體需唯一ID、起始日期與來源，不刷新F07既有飛蛾 |
| **其他蟻群** | 在自己可達的活動區轉向、繞開主巢、因食源變動改變活動路線、局部競爭 | 有異巢蟻或其可能活動帶，不能從未知直接確定敵巢座標 |
| **掠食者** | 蜘蛛移到葉背／織新網、蟾蜍在夜間根際活動、捕食普通小昆蟲 | 符合其已知棲地與活動窗口；捕食W005必須有同時間同地點接觸事件 |
| **天氣／局部微氣候** | 使用臺中有來源的實際／預報作區域外部驅動，地表陰影、溫差、積水與露水可在虛構場景發生 | **不能替實際天氣隨機產生「官方觀測雨量」**；降雨機率0%≠實測雨量0 |
| **住戶／花園干擾** | 澆水、掃落葉、修剪、搬動盆栽或完全沒有活動 | 明確標作**虛構人類活動事件**，不是現實住宅紀錄；若事件成立會影響可達路線與植物 |
| **外圈邊界** | 植被、障礙物或其他昆蟲可能因環境而改變；背景可在未知期間變化 | **X候選區域先要有情境合理的棲地具體化**，不是每日必生一個神祕新寶藏 |
| **巢本身** | 入口被落葉阻擋、濕土變化、局部裂縫、舊土粒滑動 | 與[nest-construction.md](nest-construction.md)同帳，若沒有實際結構變化就不能改房數 |

**時間尺度**：20分鐘行為窗並非所有世界物種每20分鐘抽一次事件。天敵活動可跨分鐘／小時，植物生長可能跨多日，昆蟲發育可能跨週，腐敗持續多日。外界也允許連續多日無可見重大事件。

## 5. 隨機必須有持續性、因果和重播能力
- 引擎仍是`FNV-1a32 → mulberry32`，取下一日`parent_main_commit_sha`、`Day5->Day6`與日期作可重播種子材料，**Day5已用過的種子和事件一概不變**。每個子系統使用標籤化獨立stream，以避免多一個事件就使全部子系統亂跳。此為**遊戲工程選擇**，不是螞蟻自然界的物理隨機源。
- 每個外界事件應有`event_id`、`kind`、`time_window`、`sector_id`、`preconditions`、`seed_stream`、`roll`、`model_assumption`、`resulting_state_delta`、`observation_status`。如果根本沒有有效棲地、時間重疊或生物主體，就不執行對應抽樣。
- **真實研究未提供本花園事件發生率**：食源再生、蜘蛛移動、昆蟲死亡、澆水等日機率預設`null`，不虛構「天敵30%」「掉果70%」成科學值。若為了故事抽取相對頻率，必須明示`unvalidated_scenario_weight`，且**絕不可向用戶宣稱這是自然界觀測概率**。
- **條件式而非每格獨立重抽**：植物狀態延續、同一果實腐敗、異巢蟻可從前日位置移動、蜘蛛轉移會有時間成本、舊食源耗竭後需新來源；遭大雨／人為翻動後外部棲地或路線可能逐步改變。
- **可有零事件**：每天都可以沒有新屍體／落果／天敵／新食源，不能因Day5多次空載就硬刷補給以維持玩家進度。原有食物與外部蟲群數未知應保留null。
- **獨立生物群系**：植物、異巢蟻、蜘蛛、蟾蜍、腐食者先依各自局部條件更新，再決定與主巢螞蟻是否碰到；主巢未出門≠世界靜止。
- **分流狀態**：天氣資料是公共事實（需來源與發報時間）；其餘外界遭遇是有生態約束的**虛構模擬事件**，不可報成現場真實觀察。

## 6. 在20分鐘模擬窗與日終如何核算？
1. 每日首先產生**整體外部強迫條件**：真實日期、城市天氣預報或觀測、季節，標識日／夜；巢口地表數值未知保留null。
2. 更新背景的**真實已有模擬物件**：植物／蚜蟲／屍體／蜘蛛／其他蟻群；對未探區只依已具體化的假設棲地產生有限背景事件。事件可在本巢不在場時發生。
3. 決定工蟻是否出巢。出巢後每一窗口只有**相容的行走／搜索／停頓／搬運／逃避**，不能20分鐘內在多個未連通遠區瞬間完成所有工作；受傷與疲勞影響探查和返巢。
4. **累積時間、路線和局部覆蓋**；在資源氣味或線索處切換ARS密集搜尋，線索不足可改換方向或返巢。由研究數值設定的是參考範圍，不是物種不明時偽造的日行走公里數。
5. 螞蟻是否察覺外界背景事件，需**同時同地、可感知媒介／能力**；沒有接觸就不知道。陌生蟻活動、蜘蛛移動和昆蟲死掉，不能從背景直接變成本巢全體消息。
6. 若找到東西才由[foraging-food-economy.md](foraging-food-economy.md)判定能否取得、帶回；若與其他蟻群／天敵重疊，才做接觸→迴避→交戰/捕食與受傷／死亡。
7. 返回N00（或明確未歸）後，僅透過[ant-communication.md](ant-communication.md)能支持的局部接觸與訊號，更新其他工蟻的知識；內巢食物與建築代謝跟其他子系統對帳。
8. 日終保留**背景世界事件**、**工蟻親自發現事件**、**分享的巢內線索**三本帳，且未知世界仍保持未探部分。每一事件要有可重現種子與獨立空間有效性。

## 8. 科學驗收與反例
- 只經過U00外緣草根縫，不可自動全面顯示所有U00地貌／資源／敵巢；X01–X04只是預留抽象區域，不是已發現的路。
- 不能把`Temnothorax`的8.3mm/s或`Cephalotes`的4.39cm/s直接當W015的實際速度；速度與有效探索半徑、路徑長度分別管理。
- 遠區不會因新的一天自動擴散知識；新資訊先給到場個體，再由接觸網可能分享。
- 世界在所有工蟻留巢時仍可**獨立變化**；但其變化不可直接寫入主巢資訊與庫存。
- 沒有新昆蟲來源事件就不得使F07原舊飛蛾「復活」；沒有蜘蛛與工蟻時空接觸不得死工蟻。
- 不因玩家要求「隨機」就每天強制刷食源／天敵或讓人類實際澆水紀錄變成天氣觀測。
- 既有Day5（日誌已完成120h）的W015故事與既有Day1–Day5全部只讀；此次文件增補不是第6天推演。
