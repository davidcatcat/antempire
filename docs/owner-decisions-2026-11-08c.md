## G. 交付優先序
1. 可持續運行的實驗遊戲：開啟遊戲 → 繼續／新世界／載入其他存檔／匯入備份；世界依模擬時間持續運作；暫停、繼續、調速；觀察螞蟻與個體／環境資料；手動與自動存檔；關閉重開可繼續；世界互不覆寫。玩家只觀察，不干預。
2. 物理、感知與生物整合的因果流程：物理位置與運動 → 幾何與觸角接觸 → 局部環境與化學感知 → 個體生理與記憶 → 行為決策 → 物理運動與生態事件 → 狀態更新 → 觀察器與存檔。不得讀未來、全圖或無來源資訊；畫面動畫不得回饋成假生物事件。
3. 視覺品質：螞蟻實際移動、頭部與觸角、巢口、植物與地表、天氣與日夜、鏡頭跟隨、近距離觀察、大量個體效能；引擎事件與顯示動畫明確分離。
