# 觀察器 V6：遊戲畫面（第一階段：引擎紀錄重播動畫）

> Owner 2026-11-08 的產品要求：最終產品是能連續播放、有自然場景、螞蟻自主活動的 2D 生態模擬遊戲。玩家只有上帝視角的觀察權限。
> 本文件說明 V6 第一階段做了什麼、資料從哪裡來、效能測量結果，以及第二階段的工作。
>
> - **唯讀**：沒有改動引擎、規則、參數、存檔或日誌，不推進遊戲日。
> - **非正式**：資料只來自實驗世界 Day0 的重播。

## 0. 美術升級（2026-11-08，PR A／B／C）

遊戲畫面改由分層繪圖器（`web/src/render-canvas.ts`，見 [game-render-system.md](game-render-system.md)）以 PR A 的原創美術資產（[game-art-style.md](game-art-style.md)）繪製：

- **開場**：自動選第一個有紀錄行走的日子，從紀錄中「3 分鐘內同時在走的螞蟻最多」的時刻前 3 秒開始（`game-model.openingMoment`，只用引擎紀錄），鏡頭框住巢口與這些行走前往的食源；預設 5× 實際速度。
- **畫面**：花園土壤（世界座標的連續紋理與微地形光影）、成堆的落葉、碎石與大石、成簇的草、苔（全部**示意場景**，以種子產生，避開地點與紀錄路段）；引擎地點以巢口、寄主＋半翅目簇（簇數＝引擎群數）、花、屍體精靈畫在引擎座標上；螞蟻為圖集精靈，最少畫成 48 px（手機 34 px），左下角標示「螞蟻放大顯示 ×N」。
- **光與天氣**：固定示意光源（重播沒有時刻，不畫日夜）；天氣只顯示引擎的當日狀態（潮濕地面、雨天陰影），時間列標示「日值」，不畫雨滴。
- **介面**：半透明的最小 HUD；「圖層」選單可開關引擎物件標示、地點代號、紀錄路段、螞蟻 ID、狀態列（預設全部關閉，玩家視角）；「資料說明」與「分析模式」照舊。
- **保證不變**：每個畫面位置＝`model.poseAt`（`web-v6-game` 測試與瀏覽器測試未改斷言）；巢內與未記錄地點不畫；快轉不跳過任何行走；R13-01；不建立事件、不用無種子亂數、只匯入觀察器模組。

| 設定（瀏覽器測試 `web-game.check.cjs`，播放中 10 秒，headless Chromium 軟體繪圖） | 最終版本（同機有其他測試在跑） | 決定 18–21 之前的版本（機器較空） |
|---|---|---|
| 桌面 1280×800 | **40.0**（p95 67 ms） | 59.9（p95 16.8 ms） |
| Android Pixel 7 | **48.7**（p95 50 ms，自動降為 DPR 1） | 60.0（p95 16.7 ms） |
| Pixel 7＋CPU 4× 降速 | **40.0**（p95 33 ms，DPR 1） | 40.9（p95 50 ms） |

- 最終版本量測時，同一台 4 核心機器上有其他工作的測試同時在跑（`ps` 可見），數值偏低且波動大；另以獨立腳本量得桌面 46.0、Pixel 7 56.1、4× 降速 24.8（同樣受干擾）。**請以 CI 或空機重新量測為準**；目標（桌面 ≥ 55、Pixel 7 ≥ 50、4× ≥ 30）在空機上的達成與否尚未確認。
- 最終版本比前一版多了：每隻螞蟻的體色變體（5 張圖集）、較大的螞蟻（畫面短邊 8%）、巢口近景（每 cm 的像素更多，地面分塊更多）。

CI 閘門仍為桌面 ≥ 30 FPS。截圖（開場、圖層、追蹤；桌面與 Pixel 7）由 `node reports/viewer-v6-art/shoot.cjs <url>` 產生到 `reports/viewer-v6-art/screenshots/`；該目錄在 `.gitignore` 中，**不提交**（本機產生或作為 CI artifact）。

## 1. 開啟方式

- **本機**：`npm ci && npm run web`，然後開 http://localhost:8780/。開啟時直接進入**遊戲畫面**（`web/index.html`）。
- **分析模式**：右上角「分析模式」按鈕切換到 V3～V5 的分析介面（`web/analysis.html`，原本的 `index.html` 改名）；分析模式左上角有「← 遊戲畫面」可回來。
- **CI 預覽**：每次 push 的 artifact `antempire-viewer-preview` 的 `site/` 同時包含兩頁。

## 3. 資料分類（頁面「資料說明」也逐條列出）

| 分類 | 內容 |
|---|---|
| **引擎紀錄** | 每隻螞蟻每個時刻的所在地點、出發與抵達的分鐘（`route_step`）、行動段落（`worker_activity`）、當日任務；食源的蚜蟲群數與寄主存活；天氣日值 |
| **顯示插值** | 兩個紀錄點之間沿直線的位置；同一路段同時出發的螞蟻左右錯開（−2～+2 個固定車道，依 ID）；停在同一地點的螞蟻圍成固定的圓形排列；轉身與足部擺動。只為畫面，不寫回，也不產生事件 |
| **示意場景** | 土壤與植物外觀；地點座標由「方位＋約距離」推得，非測量；螞蟻外形為示意，引擎中的體長是 null；縮小時螞蟻以最少 26 px 放大顯示 |
| **沒有畫出的** | 巢內活動（只計數）；在位置未記錄地點的螞蟻（只計數，不給座標）；任何引擎沒有記錄的覓食、交哺、攻擊、死亡 |

**時間**：引擎目前以每日 360 分鐘的活動時段簡化一天，不是 24 小時；24 小時時鐘見 P0-A。
**快轉**：只跳過「沒有任何螞蟻在外行走」的時段，跳過時會顯示提示；它不改變任何紀錄，也不會跳過任何一段行走（有測試驗證）。

## 4. 測試

| 測試 | 內容 | 結果 |
|---|---|---|
| `tests/web-v6-game.test.ts`（Node，BLOCKING） | 見下方說明 | 7,519 項通過 |
| `tests/browser/web-game.check.cjs`（CI） | 見下方說明 | 29 項通過，failures 0、errors 0 |
| 既有 V5 瀏覽器測試 | web-viewer、web-follow、web-stats、web-v5。只把開啟網址改為 `analysis.html`，沒有改動任何斷言 | 全部通過 |

**`web-v6-game`（Node）** 涵蓋三個重播、每一日、每隻當日在冊的工蟻：
- 在每個紀錄邊界、紀錄之間與中點，共 16,840 個畫面位置，逐一等於分析模式用的 `model.poseAt`；
- 只在兩端都有座標的路段上行走；朝向等於該路段方向；只有嚴格介於兩個紀錄點之間才算「移動中」；
- 在巢內或未記錄地點時不畫；
- 快轉從 3,563 個起點出發，全部落在紀錄的行走上，沒有跳過任何行走；
- 場景以種子決定，且避開地點；
- 程式只匯入觀察器模組，不使用無種子的亂數，不建立事件，不寫入。

**`web-game`（瀏覽器）** 在桌面 1280×800（滑鼠）與 Android Pixel 7（觸控）上檢查：
- 開啟就是遊戲畫面；
- 螞蟻在兩個相隔 250 ms 的畫面之間確實移動；
- 暫停後，頁面內用同一份資料重算的 `poseAt` 與每隻畫出的螞蟻完全一致，巢內與未記錄地點的螞蟻都沒有被畫出；
- 暫停會凍結時間；
- 點選開啟資訊卡；鏡頭追蹤使個體保持在畫面中央；
- 滾輪縮放、拖曳平移；
- 60× 速度約為每秒 1 模擬分鐘；
- 資料說明列出三類資料與非正式；
- 分析模式連結可用；沒有水平捲動；
- 量測 FPS。

## 5. 效能（Playwright＋Chromium，headless，每段 10 秒，播放中，20× 速度）

| 設定 | 畫布 | 平均 FPS | 每幀 p50 | 每幀 p95 |
|---|---|---|---|---|
| 桌面 1280×800 | 1280×800 | **60.0** | 16.7 ms | 16.8 ms |
| Android Pixel 7（DPR 2） | 824×1678 | **60.0** | 16.7 ms | 16.8 ms |
| Android，CPU 降速 4×（低階手機估計） | 412×839（自動降為 DPR 1） | **45.9** | 16.7 ms | 33.4 ms |

- **自動降解析度**：開啟 4 秒後，若最近 120 幀平均超過 30 ms，畫布解析度改為 DPR 1。只影響繪圖，不影響資料。
- **場景繪製**：縮小時使用一張快取點陣圖；放大超過快取解析度時，只以向量繪製畫面內可見的裝飾。
- **閘門**：CI 要求桌面平均 ≥ 30 FPS；Android 與降速數值只記錄，不設閘門。
- **限制**：這是 headless Chromium 的量測，不是實機。實機（不同 GPU 與瀏覽器）可能不同。

## 6. 限制（第一階段）

1. **這是重播，不是持續運算**：畫面播放引擎預先算好的 30 日紀錄，播完就結束。
2. **路徑是直線**：地點之間沒有實際路徑幾何；螞蟻也沒有物理身體，物理播放（#118／#120）仍是另一個隔離頁面。
3. **一天是 360 分鐘活動時段**：沒有日夜與 24 小時。
4. **只有實驗世界**：正式 Day14 只有快照，沒有逐分鐘紀錄，遊戲畫面不提供。
5. **巢內看不到**：分析模式有巢內示意；遊戲畫面尚未做巢內視角。
6. **個體數少**：每個實驗世界約 10 隻工蟻，這是模型的創巢情境，不是為畫面調整。
