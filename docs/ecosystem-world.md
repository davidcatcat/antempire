## 2. 多層生態模型
**植物**：葉片生長／衰老、受損汁液有限、花期、腐果分解；灌溉與降雨改變蜜露來源與通道。
**吸汁昆蟲**：蚜蟲、介殼蟲群落的大小、位置、排泄蜜露速率、宿主健康、天敵／寄生蜂壓力；與螞蟻可能互利，也可能不互利，不強制所有種類可被牧養。
**獵物及腐屑**：死蟲、飛蛾、小型節肢動物；腐敗與競爭者消耗會造成時間性枯竭；甲蟲、潮蟲等物種可能是分解者、競爭者或掠食者，需依種類。
**掠食者**：蜘蛛（依網／跳捕方式區分）、蟾蜍、壁虎、蜈蚣及獵食性甲蟲；必須依身體尺寸、活動時間、位置及接觸機率決定能否捕食螞蟻，不能每20分鐘刷怪。
**其他蟻群**：歷史辨識到至少兩組異巢活動訊號，但物種、巢址、勢力範圍仍未知；沒有「敵我永遠開戰」固定設定。互動可能為競爭、迴避、偷食、短暫接觸或交戰。
**微生物／寄生物**：傷口感染、幼蟲病害、腐敗、真菌、寄生蜂與蟎類；種類未確認時保持風險而非事實。
**人類干擾**：澆水、除草、踩踏、盆栽移動、農藥／清潔劑、食物殘屑；發生率受世界時鐘／場景設定控制，不能每回合必有事件。

## 3. 無生命環境
- 天氣：場景地理固定**臺中市西屯區**、時區**Asia/Taipei**，Day1錨定**2026-10-31（秋季）**。採中央氣象署該區／鄰近可辨識測站真實觀測；缺測時標 null；未來日期僅能使用標明來源與發布時間的預報，不可將預報說成實測，也不可拿使用者所在城市代替。降雨量、歷時、日照、氣溫、風、相對濕度等應記錄來源、有效時刻和觀測／預報屬性。
- 土層：粒徑、壓實、孔隙、水分梯度、滲水、根系、地表坡度與積水。已知土丘高處較有利排水，但**尚未通過暴雨驗證**。
- 巢內：各室濕度／溫度、食物區變質速度、幼蟲位置與安全性。泥脊與防禦轉角需維護，遭雨蝕可能退化。
- 晝夜／季節：影響植物、昆蟲及螞蟻的活動；因物種與地理未定，具體節律使用待校準參數，非萬用「螞蟻只在白天工作」。

## 4. 因果鏈，而不是劇本事件
1. 葉片長勢變化 → 吸汁昆蟲食物供應變化 → 蜜露流量與位置變化。
2. 蜜露多 → 不同蟻群可能聚集 → 招募、擁擠、爭奪與掠食者注意改變。
3. 下雨 → 土壤孔隙含水上升 → 巢室微氣候變動 → 幼體重新搬運、挖土停工或遷巢。
4. 枯葉中死蟲腐敗 → 蛋白質品質下降、分解者增加；吸引工蟻但不保證安全。
5. 人類澆水或移動花盆 → 多區同時變化；工蟻只對當下接觸的變化做反應。
6. 傷蟻數上升 → 有效採集勞動力下降，若缺糖則提高出巢壓力；可能形成惡性回饋。

## 5. 資料可信度
- **observed_in_story**：舊故事明確發生／發現；不是現實實測。
- **inferred**：由場景合理推定但未觀察。
- **unknown**：完全未知；用 null，不能用0。
- **calibration_hypothesis**：為模擬必須補的演算法假設，有待物種／數據校準。
- 地圖初始「距離」是既有故事的敘事量尺，不是外部 GPS 測量。
