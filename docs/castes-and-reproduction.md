# 《螞蟻帝國》v2｜性別、形態階級、工蟻分工與有翅繁殖蟻

> 規格新增日期：**2026-11-01**；**自 Day6（2026-11-05）起適用**。目前Day5已完成120模擬小時，**不前進遊戲時間、不增減已存在成蟻與幼體、不倒改任何歷史**。
>
> **重要**：本殖群只知黑色地棲、單蟻后Q001、14隻現存工蟻、1卵E001、2幼蟲L001/L002；**蟻種未鑑定**、體長／頭幅／雌雄基因型／幼蟲發育齡均無資料。以下基於已發表實驗與綜述建立**條件式**生態規格，參見[references.md](references.md) R49–R61。

## 1. 先分清楚：性別≠發育階級≠工蟻工作
- **生物學性別**：大多數螞蟻為雌性雙倍體、雄性單倍體的單倍—雙倍體性別決定（一般受精卵→雌蟻；未受精卵→雄蟻）。特殊物種有非常規生殖／遺傳系統，不能以通用規則覆蓋所有例外 [R49,R50,R59]。
- **發育成蟻的階級（developmental caste）**：雌蟻可發育成工蟻或具繁殖功能的新蟻后；某些種類工蟻再分 minor、major／soldier，部分還有更細分型。這些形態主要在幼蟲發育時由遺傳、營養、激素、季節、社會背景等共同影響，不是工蟻成年後「升級成兵蟻」[R51,R52,R53,R60]。
- **任務（behavioural role）**：清潔／育幼／挖土／巡邏／覓食／防禦等，隨個體感知、齡級、體能、外界刺激和群體需求改變。W005曾覓食不代表其形態是minor，也不表示永遠專職採蜜 [R54]。

## 2. 不同工蟻類型要怎麼運作？
1. `worker_morphology` ：`unknown / monomorphic / polymorphic_continuous / dimorphic_minor_major / trimorphic / other`。本蟻種預設`unknown`，不可假設「14隻中4兵蟻10工蟻」。
2. 對各工蟻保留 `adult_morphological_subcaste=null`、`head_width_mm=null`、`body_length_mm=null`、`developmental_caste_evidence=null`，沒有鑑種與身長資料前不能寫minor或major。
3. 真有多型性證據時：minor／major在活動能力、頭部力量與食物加工效率**可能**不同；部分研究顯示major偏向防衛／種子加工，但並非只能防衛，也不給未鑑種者精準能力係數 [R52,R53]。
4. 年齡分工與形態分工是不同面向：研究與模型顯示某些物種年輕者偏巢內、年長者偏覓食，但可隨群體需求或環境變化轉換 [R54]。
5. **不回溯**改寫W007–W014舊傷、W016/W017既有幼齡描述；不假設「W017目前確實只有5天大」：v1加速故事時間無法轉成真實生理日數。

## 3. 雄蟻是怎麼產生的？
- 常規單倍／雙倍機制中，未受精卵→單倍體雄蟻，受精卵→雌蟻；**E001受精狀態未知**，因此性別與未來階級維持`null` [R49,R50]。
- 在部分蟻種，工蟻卵巢具功能，可產未受精雄卵或供給用營養卵；有蟻后時的工蟻產卵可能受社會調節／工蟻警察行為限制。只有鑑定種類和前置條件後才啟用`worker_male_egg_laying`，未來不能因蟻后短期停產就讓W009自動產雄蟻 [R57,R58,R61]。
- 雄蟻和gyne也必須走完整**卵→幼蟲→蛹→羽化**，不會在某個回合直接生成10隻飛蟻。每一個體要有唯一ID、母親身分（若能確認）、性別決定證據及營養成本。
- 雄蟻通常主要負責交配，**不擔任採集／挖土／守巢的普通工蟻任務**；繁殖個體進出巢、季節與生理發育受物種影響 [R55,R56,R59]。

## 4. 新蟻后（gyne）和蟻后Q001不是同一階段
- `gyne`是尚未開始定居繁殖的新后候選者，常見為有翅雌性；飛離巢穴、交配後部分新后脫翅尋找巢址。Q001為既有產卵蟻后，而**不是**在Day5新產生的gyne。
- 雌性受精卵最後走工蟻或gyne發育，依物種可能受幼體營養、幼蟲發育期激素、基因組成及社會環境影響；特定 `Pogonomyrmex` 有遺傳限制型階級決定，並非所有蟻種皆如此 [R51,R60]。
- 雄蟻與gyne的繁殖飛行受季節、氣象背景、巢群成熟度與物種影響。**研究發現繁殖飛行可能集中在特定季節與濕度轉變期**，不能用「台中11月」或「白天降雨機率0%」直接觸發飛行 [R55,R56]。
- 是否有翅、婚飛後死亡率、交配成功率與新后創巢方式都保持物種依賴且數值未知；**婚飛不等於所有個體自動成功交配**。

## 5. 小型殖群的繁殖資源與成熟限制
- 本群目前14工蟻，確認仍處於小型殖群敘事；目前沒有確認具有繁殖季的成員或繁殖成熟狀態。
- `Pogonomyrmex badius` 實地研究中，殖群約700工蟻後才開始生產雄蟻與新后，而且有固定的季節性生產。**700隻只是該研究物種與族群觀察，不是所有蟻種硬門檻** [R55]。
- 生產繁殖個體可能需要更高的營養／空間與時間投入，與持續工蟻增長競爭；食源真實存量、蟻后生理儲備不明時不得因為故事需要就啟動婚飛。
- 將`reproductive_maturity`和`colony_resource_sufficiency`保持`null`，**不是設定成false，也不是默認已成熟**。未來可評估，但缺證據時不觸發明確的生殖分化結果。
- 若真的日後有繁殖個體產生，需分開記**成蟻雄蟻、gyne、離巢外飛、死亡、成功建立新巢**；原始本巢數量守恆，並可在世界建立受獨立生態規則控制的子殖群。

## 6. 從Day6起的必須更新順序
在[simulation-engine.md](simulation-engine.md)、[foraging-food-economy.md](foraging-food-economy.md)、[ant-communication.md](ant-communication.md)既有環境、訊號與資源更新之外，新增：
1. **環境／殖群訊號**：季節及有來源的台中氣象；若花盆地表與巢室溫度未知保持null。估計巢內局部營養與工作力，不以舊糖3／蛋白3當物理庫存。
2. **各工蟻**：性別類別保持生物學通常的female worker，形態subcaste未知；依自身工作、傷勢、負載、年齡等調節活動，不從工作命名成新生物學階級。
3. **蟻后與卵**：記產卵事件、母親、是否受精（無直接證據null）、卵ID，**不能直接依需要而決定其將來是工蟻／雄蟻／gyne**。
4. **幼蟲發育**：營養投入、物種、齡級、形態／性別形成閾值需要證據；缺發育資料時`future_sex=null, future_caste=null`，不強行化蛹。
5. **蛹期與羽化**：確認有蛹且發育條件滿足後，才能成為工蟻（增現有工蟻總數）、雄蟻或gyne（增性成員數）。**不能只因Day6就立刻加兵蟻或雄蟻**。
6. **繁殖機會**：殖群營養與成熟狀態可評估，但若`mature=null`／物種`unknown`，不抽婚飛；外部鄰近大殖群可能有雄蟻飛行，但**不能不經證據把外來雄蟻記為本巢新生個體**。
7. **三類計數守恆**：存活工蟻（含已證實的major/minor）、成蟻雄蟻、成蟻gyne分別計數；新生=蛹羽化，移出=婚飛／遷移／死亡。幼體卵／幼蟲／蛹之各階段轉換也必須守恆。

- 在新事件確認雄蟻／gyne後才能產生`M001`／`G001`等唯一ID，**目前不預先分配實體個體或把E001重分類**。

## 8. 禁止案例／驗收
- 不因玩家提「兵蟻」就直接把W010變成major；不因W013受傷就讓牠生理變成nurse caste。
- 不把male解釋成受精的雄性工蟻，也不預設成年雄蟻會挖土、採蜜和育幼。
- 不把一顆已存在的卵E001從unknown突然寫成male，只因模擬希望出現雄蟻；必須有受精／遺傳與發育證據。
- 不在Day6瞬間產生羽化的雄蟻與gyne，沒有卵、幼蟲、蛹的前序就不能有新成蟻。
- 不把700工蟻或某研究物種的婚飛月份當成台中未知蟻種的固定繁殖門檻。
- 年齡任務可變，成年形態不能因一個任務切換就轉換major/minor。
- 研究規格更新不推進世界：**Day5／120h，Q001×1、存活工蟻14、卵E001×1、幼蟲L001/L002×2、蛹0**全部原樣。
