## 2. 條件 1～6

| 條件 | 結果 | 主要原因 |
|---|---|---|
| 1 本種、西屯環境、初始蟻群、環境獨立 | 未通過 | 候選世界沒有物種參數、花園情境、天氣只有手寫合成剖面、沒有食源；分巢單位初始條件未定（M01、M02、M05～M07、M09） |
| 2 個體機制、收支、生命階段、無干預 | 未通過 | 候選世界是合成行走，沒有決策、收支、蟻后、幼體或死亡（M10～M17）；無干預與畫面不改命運已成立（M30、M31） |
| 3 物理／化學不假裝 | 部分 | 物理與化學都未接入（允許）；畫面尚未列出「尚未模擬」清單（M38） |
| 4 存檔、驗證、跨平台 | 部分 | 存檔生命週期已在實驗世界驗收；正式欄位、Node 驗證器、三種狀態、ARM64 與手機實機未完成（M29、M33～M36） |
| 5 驗收矩陣 | 部分 | 矩陣與阻擋性測試已建立；候選世界的 ODD 與長時段多種子報告不存在（M41、M42） |
| 6 版本邊界、不回填 | 未通過 | 規則不同只會拒絕，沒有邊界事件或 fork（M37） |

## 3. 已成立的基礎（不阻擋）
事件時間軸（M03）、光照（M04）、決定性與切分不變（M28）、畫面不改命運（M30）、無干預（M31）、環境不讀蟻群（M32）、「非正式」標示（M39）。這些都是**工程**基礎，不代表任何科學模組已接入或已驗證。
