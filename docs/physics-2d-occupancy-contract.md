# PH-3a：二維占用契約（隔離物理實驗）

> **地位**：物理實驗層的契約與第一批實作。沒有接入每日生態循環或任何 Day0，不改既有 `simulate()` 的行為。
> **依據分類**沿用 CLAUDE.md §3：【文獻支持】【一般生理學／幾何】【遊戲假設】；他種標「非本種」。
> **來源**：#107 P2-E。一維通道模型（PH-2）只做成對寬度檢查，三隻以上可以在同一弧長位置超出通道寬度；Owner 審閱 #108 時要求不得以成對距離宣稱整條通道合法。

## 1. 為什麼需要
- PH-2 的螞蟻只有弧長 `s`，沒有橫向座標。
- 引擎與 `checkExclusion` 檢查的是「每兩隻」能否並排，不是「同一處所有個體」能否並排。
- `checkWidthOccupancy`（#108）量到：traffic 1–60 的 60/60 個場景、dense 1–200 的 45 個場景，都有三隻以上需要的寬度超過通道。
- 所以 PH-2 的任何抵達數都不是二維可行性的證據。

## 2. 契約（每個瞬間都必須成立）
| 項目 | 內容 | 依據 |
|---|---|---|
| 位置與方向 | 每個個體有 `(x, y)`、朝向 θ；在通道內以 `(s, u, dir)` 表示：`s` 是中心線弧長，`u` 是橫向偏移（中心線行進方向左側為正） | 幾何 |
| 身體 | **膠囊**：沿朝向、長 `max(0, L − w)` 的線段，向外膨脹半徑 `w/2`。`L`、`w` 取自 body-candidates 檔 | 外形是**遊戲假設**（真實輪廓不是膠囊；不含觸角與腳）；尺寸依候選檔的依據 |
| 未知尺寸 | `L`、`w`、通道寬 `W` 未知時拒絕或回報「未檢查」，**不補值** | CLAUDE.md §3 |
| 通道區域 | 與中心線距離 ≤ W/2 的點，兩端是平頭：每個直線段一個寬 W 的矩形，加上每個轉折點一個半徑 W/2 的圓（等寬路徑、圓角轉折）。先合併共線的相鄰線段，所以直線上的頂點不算轉折。通道端點以外屬於節點（交會點、巢口），本模組不建模 | 圓角轉折是**幾何約定**（遊戲假設：真實路徑在轉折處的寬度沒有資料） |
| 在通道內（精確） | 膠囊 ⊆ 通道區域 ⟺ 軸線中點在區域內，且區域邊界上沒有任何點離軸線 < r。邊界每條通道只算一次：各矩形的邊與各轉折圓，扣掉位於其他片**開內部**的部分，剩下線段與圓弧；線段–線段、線段–圓弧距離都是精確的 | 幾何 |
| 無法判定 | 通道寬未知，或身體超出通道端點進入節點：列在 `not_checked`，結果 `valid = null`，**不是違規**，也不默認通過 | CLAUDE.md §3 |
| 互斥 | 同一可碰撞空間（同一 layer，預設為同一通道）的兩個膠囊，間距 = 線段距離 − 兩半徑，不得 < −tol | 幾何 |
| 不同空間 | 不同 layer 不碰撞（例如地面與上方葉面）；由呼叫端決定誰在同一空間 | 幾何 |
| 容差 | `OCC_TOL_MM = 1e-9 mm`，純數值，遠小於身體尺寸，不是模型參數 | 數值 |

**橫向排列的精確判準**（`lateralPacking`）：同一直線段上、弧長位置 sᵢ 的平行膠囊，能否給出橫向偏移 uᵢ，使每隻都在帶內（|uᵢ| ≤ W/2 − rᵢ）且兩兩不重疊。
- 兩個平行膠囊的軸線沿通道相距 d 時，需要 |uᵢ − uⱼ| ≥ √max(0, (rᵢ + rⱼ)² − d²)。
- 任一可行排列依 u 排序就是一個順序；固定順序時，「每隻放在最低可行位置」是最優的（差分約束），所以窮舉順序（深度優先、放不下就剪枝）是精確的。n > 9 時不搜尋，回報 `null` 與原因。
- Σwᵢ ≤ W 只在**所有軸線沿通道都重疊**（d = 0）時才精確。
- P2-E 反例：2.0 mm 寬的通道上三隻 0.8 mm 寬的螞蟻，需要 2.4 mm，**任何橫向排列都不合法**（測試另外抽了 5,000 種隨機排列，全部失敗）。
- 對照：兩隻在 `u = ±0.5` 並排是合法的。

> **更正（Owner P2，2026-11-07）**：前一版有兩個錯誤，都會拒絕合法的幾何：
> 1. **合法幾何被誤拒**：跨越頂點（連共線的頂點也算）或轉折的身體一律回報 `not_checked`，而 `checkOccupancy2D` 把它放進違規清單。反例：中心線 (0,0)→(5,0)→(10,0)、寬 2 mm，身體在 s = 5、u = 0.5，完全在帶內卻被拒絕。現在通道區域有精確定義（上表），轉折處也精確判定；`not_checked` 與違規分開。
> 2. **排列判準錯誤**：前一版用 Σw ≤ W，條件寫成「沿通道範圍有共同點」。但膠囊兩端是圓的，軸線沿通道錯開時需要的橫向距離較小。反例：兩隻 0.8 mm 寬、2.5 mm 長的螞蟻，中心相距 2.3 mm（軸線相距 0.6 mm），只需橫向相距 √(0.8² − 0.6²) = 0.529 mm，可放進 1.4 mm 的通道；Σw = 1.6 mm 卻判為不可行。現在用上面的精確判準。

## 3. 碰撞方法的適用性（3.2）
| 方法 | 用途 | 本模組 |
|---|---|---|
| Capsule／body geometry | 身體占用與互斥 | `capsuleOf`、`capsuleGap`，**精確**（線段距離） |
| Spatial exclusion | 單一瞬間的合法性證明 | `checkOccupancy2D`：在通道內＋同層不重疊；回傳 `valid`（true／false／null）、違規與 `not_checked`；與輸入順序無關 |
| Swept／continuous collision detection | 兩次取樣之間不得穿隧 | `sweptCapsuleContact`：平移膠囊的間距函數對時間是**凸函數**，先三分搜尋最小值，再二分求第一個根。沒有步長，任何速度都不穿隧，擦邊也會結束。回傳間距 = 0 的時刻，不因 tol 提早 |
| Event-driven integration | 事件在解析時刻發生 | PH-2 已是事件驅動（#98／#105／#108）；二維版要把 `sweptCapsuleContact` 當成接觸事件的排程函數（下一步） |
| Contact constraints | 接觸後的約束（停下、等待、退後） | 只處理**物理約束**（不可重疊）。讓路、攻擊、交哺、招募是**生物決策**，由獨立模型決定，不放進碰撞解算器 |
| Congestion／queue dynamics | 擁擠與排隊 | 需要橫向位置模型，見 §5（候選，未實作） |

## 4. A–F 的對應
| 項目 | 本 PR | 下一步 |
|---|---|---|
| A 多隻在通道中的實際占用 | 二維契約（含轉折）與精確排列判準（含沿通道錯開）；P2-E 反例被拒絕 | 讓求解器輸出 `u`，每個事件時刻跑 `checkOccupancy2D` |
| B 三隻以上同時接近狹窄處 | `lateralPacking` 給出可行與否與見證；排列不可行時必須有人等待 | 「誰等」是生物決策，維持既有排隊規則，並標示為遊戲假設 |
| C 身體接觸／觸角接觸／真正碰撞 | 身體：膠囊間距 ≤ 0 為接觸，< −tol 為重疊（違規）。觸角：可用 `pointCapsuleGap`，觸角可及距離取自 interaction-candidates | 觸角接觸事件與身體接觸事件分開記錄（PH-2 已分開；二維版沿用） |
| D 停止、等待、後退、恢復的因果事件 | 契約只判定合法性 | 每個停止或恢復都要有接觸或幾何事件作為原因（PH-2 已有）；二維版用 swept 時刻排程 |
| E 有空間處的錯身 | `checkOccupancy2D` 可以驗證錯身時的橫向排列合法 | 橫向位置怎麼選是候選模型（§5） |
| F 多物件同時接觸的一致性 | 違規清單依 ID 排序，與輸入順序無關（已測） | 同一時刻多個接觸的處理順序要固定（PH-2 的 `candOrder` 做法） |

## 5. 未知與候選（不實作、不宣稱）
- **個體如何選擇橫向位置**：本種沒有資料。候選：
  - 靠右或靠左習慣：其他種有報告（非本種，需逐篇核對）；
  - 讓出最近的空位；
  - 隨機側移。
  
  三者都是候選，參數 `null`。
- **擁擠下的流量與密度**：Poissonnier et al. 2019 只研究阿根廷蟻（**非本種**），只能提供候選機制（例如高密度下仍不堵塞），不能當作本種參數。
- **轉折處的寬度**：圓角轉折是幾何約定，不是觀測；真實路徑在轉折處的可走寬度沒有資料。
- **節點（交會點、巢口）的幾何**：未建模；超出通道端點的身體回報 `not_checked`。

## 6. 與 #101（Rapier 獨立求解比較）的關係
- 這個契約就是比較的**共同裁判**：原生求解器（加上橫向位置後）與 Rapier 的輸出，都轉成 `(s, u, dir)` 或 `(x, y, θ)`，用同一個 `checkOccupancy2D` 與 `sweptCapsuleContact` 檢查。
- 不預設哪一方正確；比較抵達時間、接觸事件、占用違規、數值誤差、成本與重播一致性（#101）。

## 7. 驗證（`tests/physics-2d-occupancy.test.ts`，2,530 項）
- **尺寸**：未知尺寸被拒絕。
- **膠囊間距**：2,000 組隨機膠囊與密集取樣比對，精確值 ≤ 取樣值 ≤ 精確值 + 取樣步長；對稱（1e-12 mm 內）；平移不變。
- **通道內判定**：
  - 直線帶在邊界上精確（0.6＋0.4 = 1.0 合法，0.61 不合法）；
  - 共線頂點：2,000 個隨機身體，與不分段的通道結果完全相同；跨越頂點的身體合法（舊版誤拒）；
  - 轉折：直角轉折外角凸出的身體判為在外；在兩帶與轉折圓聯集內的身體判為在內（舊版誤拒）；
  - 400 條隨機折線通道（2–4 段、轉角至 ±149°）與獨立寫的暴力取樣比對：精確判為在內 ⇒ 每個取樣點都在內；精確判為在外 ⇒ 取樣找到在外的點，除非凸出量小於取樣間距；
  - 寬度未知、超出通道端點：`valid = null`，不是違規。
- **排列判準**：
  - 軸線全部重疊時（500 組）：可行 ⇔ Σw ≤ W，見證排列通過契約；
  - 沿通道錯開的反例：1.4 mm 可行、1.3 mm 不可行；軸線相距 = r + r 時單列即可；
  - 300 組隨機 2–3 隻、沿通道錯開：可行時見證合法；不可行時 1,500 種隨機排列都不合法；
  - 寬度或尺寸未知、n 超過上限：`null`。
- **P2-E 反例**：排列證明與 5,000 種隨機排列都失敗；兩隻並排合法；不同層不互動。
- **swept 接觸**：
  - 迎面接觸時刻與解析值 (距離 − L)／v_rel 一致到 1e-12；
  - 每 10 ms 取樣會穿隧的快速細長身體，swept 找得到接觸；
  - 擦邊差 1e-6 mm 時兩個方向都正確；
  - 500 組隨機案例中，swept 時刻都不晚於細取樣找到的重疊時刻。
- **輸入順序**：違規清單與輸入順序無關。
- **隔離**：`physics-isolation` 自動涵蓋新檔：沒有平台 API、沒有未設種子的亂數、沒有物種名稱分支，也沒有被正式流程引用。
