# 《螞蟻帝國》v2｜領地、分巢、群體競爭、營養鏈與生態連鎖

**2026-11-01新增，Day6起適用**。本巢Pheidole megacephala，已確認Q001一蟻后、14隻存活工蟻；未知區U00及X候選區不會直接生成新蟻巢。

## 1. 領地與異巢辨識：同種不等於同巢
- P. megacephala研究顯示：不同區域的**超殖群**可能互不攻擊，也可能彼此激烈衝突；Cameroon 2012年研究見不同群的辨識與侵略差異 [R101,R110]；澳洲某些入侵族群相隔很遠也不攻擊同種 [R113]。
- `rival_colony_id`、`taxon`、`known_entrance`、`strength`、`relation_to_Q001`、`CHC_profile`沒有證據時均null；故事在F03看到外蟻、F04有異巢訊號**不能**推論其精確蟻后數、敵巢距離或是否同種。
- 個體在同時間同地感知對方、接觸或辨識後，可能無視、退避、警戒、競爭或衝突；巢群歷史的敵意若無相應接觸不能擴成全區域戰爭。
- 本物種有分巢／多蟻后文獻，但**14工蟻小群不自動變超殖群**。新巢需先找到候選點，逐步搬運工蟻／幼體／蟻后，且保持原巢資源、人員總數守恆；不得從空氣中複製第二個Q001。雄蟻、新后需從卵→幼蟲→蛹→成蟻及繁殖條件確認。

## 2. 生態連鎖效應（時滯、多個營養階層）
- [R111] 2024年非洲生態研究證明P. megacephala擾亂原生蟻—刺槐的互利關係，進而改變大象啃食與獅子捕食斑馬的結果；**本台中花園不會出現非洲草原的大象與獅子，也不能沿用該研究的植被變化率**。
- 可以由本場景物種和資源建立有限的局部鏈：`螞蟻照護吸汁蟲 → 吸汁蟲存活/蜜露 → 瓢蟲捕食 → 植物生長/煤煙病 → 葉片/蜘蛛微棲地 → 工蟻路線危險`；另一條`螞蟻排擠某外巢 → 其活動下降 → 某食源競爭減少／其他捕食者食物改變`。
- 每一節要有**存在的生物體或條件、時空相遇、可能的延遲、能量與數量守恆**。介殼蟲減少不代表立即花開，新巢被掠不代表全區生物滅絕。抽樣權重不具本地資料保持null。
- 未被本巢探索的背景世界仍可獨立變化，但**背景事實不能當成工蟻已知**，也不能因玩家在觀察者報告看到蜘蛛，就讓W004知道F05當下蜘蛛位置。

## 3. 幼體營養配置與殖群生命周期
- [R23/R112] 在研究物種中，幼蟲存在會影響全群碳水／蛋白營養調節與工蟻食物處理策略。這不是「每隻幼蟲每日必須拿Xmg蛋白」定值。
- 各幼體E001/L001/L002實際蛋白需求、發育階段、取食mg、存活閾值null；**工蟻育幼接觸和餵食需有真實事件**。幼體增加可能調整覓食偏好，但工蟻需有局部訊號／營養回饋，不是全巢GPS得知總量。
- 糖／蛋白／水／脂肪各類資源仍只有一份權威來源`foraging_economy`，幼體「攝取」屬消耗帳，不能因新幼體需要而在外界自動刷獵物。

## 4. 高階生殖利益衝突（條件式，不是目前已發生）
- `Formica selysi`具有蟻后與工蟻性別投資衝突 [R114]，某些其他蟻種工蟻可產雄性卵、存在護卵／移除卵；沒有P. megacephala本群的個體卵巢與子代資料，**不在N00自動啟用工蟻產卵、丟棄雄卵或「蟻后派兵」**。
- 狀態`species_supported_worker_policing=null`、`worker_egg_laying_enabled=false`、`sex_allocation_conflict_active=false`；這是保留將來可擴充的模型接口，不代表本巢曾有該行為。

## 5. 長期小群→成熟群
當工蟻／幼體實際增加後，可逐步讓防衛、巢穴空間、領地互動與交通調節更重要；未具物種及區域校準前不把規模14當成熟殖群，也不套其他研究的固定閾值。每次殖群數量增加都必須來自卵→幼蟲→蛹→羽化，外來合群需具實際遷入事件。
