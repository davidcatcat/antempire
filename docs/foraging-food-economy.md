# 螞蟻帝國 v2｜覓食、食物來源與營養消耗模型

**研究日期 2026-11-01；自下一次 Day5→Day6（2026-11-05）起套用。** 這是科學啟發式「文字模擬規則」，不是已寫好可自主運算的生態程式。Day1–Day5 的時間和已發生事件不回溯改寫。

## 一、哪些事情科學上已經知道？
1. **什麼時候出巢**：不同蟻種可晝行、夜行或隨地表溫度和季節變動，不能設定所有工蟻每日07:00必出巢 [R17,R18,R28]。臺中市空氣溫度預報不是花盆地表溫度／巢溫；未知值保持null。
2. **為何出巢**：個體的嗉囊／飢餓狀態、先前接觸回巢者、路線經驗、育幼接觸、局部風險與疲勞可調整出行。收穫蟻研究發現短暫觸角接觸影響離巢決策 [R25]；木匠蟻研究顯示嗉囊負載與外出頻率、巢內接受者飽足度相關 [R22]。**不是蟻后下令，也不是工蟻讀取全巢食品總帳。**
3. **如何搜尋**：感知食物氣味／局部觸碰、舊路線記憶、探索附近未知草根、短程搜尋和回巢導航。不同物種可能有視覺地景、嗅覺、路徑積分等不同策略 [R27,R28,R31]；未知蟻種僅開一般性的局部感知／記憶，不賦予所有特化導航能力。
4. **如何決定招募**：看到食源、自己食用、滿足個體採集閾值、帶回及留下氣味是不同階段。Lasius niger 食物滴量實驗顯示招募與個體想攝取的量有關 [R19,R20]；不代表可把其實驗的3、6µL或90%直接給本蟻種。Pheidole megacephala 的兩種費洛蒙機制也是特定物種，不設為未知蟻種預設 [R21]。
5. **為何選糖或蛋白**：成蟻活動能量常由醣提供，幼蟲與產卵需要蛋白質／胺基酸，食物缺口及幼體存在可改變採食偏好 [R23,R24,R29,R30]。但各種螞蟻偏好不同，不能直接寫死「缺蛋白→全部工蟻找蛋白」。
6. **如何吃與分享**：在適用物種中，液體食物先進入採食者嗉囊，回巢可分給數隻同伴；接收者的嗉囊狀態會影響分享量和採食者下一次外出 [R22]。本蟻種尚未鑑定：`trophallaxis=conditional_unknown`，容量µL保持null；固體昆蟲帶回不等於幼蟲直接吃掉全部重量。
7. **怎麼耗能**：休息基礎代謝、行走時間／路程、搬運、挖土、照護、溫度及水分壓力各有成本；採蜜行為能耗會隨食源盈利程度／活動而變 [R26]。不應預設每蟻每小時固定扣糖或每天固定糖−5。

## 三、每段時間的因果順序（20分鐘僅為檢查窗口，不強制每格發生事件）
1. 外部環境：依臺中市有來源的預報／實測更新背景；巢口地表、土壤、花葉微氣候若無測量就保持null。植物分泌、果實腐敗、舊昆蟲分解和其他蟻群取食都先獨立變動。
2. 工蟻自己的狀態：最近吃／分享的體內負載、飢餓／疲勞、傷勢、回巢採集者的接觸、當前路線與當前局部風險，決定是否出巢。**不依玩家指揮或全局糖量安排工作**。
3. 出巢選擇：熟悉的高收益點、搜尋過卻無收穫點、局部陌生路線和巢內休息互相競爭；時段依物種未校準的日夜偏好及區域微環境定性決定，不硬設早上或正午。
4. **到達→發現→可取得→取食→搬運／自己吃掉→途中損失→回巢**：每一段都可失敗。看見蜜露痕跡而空載，記錄「找到線索但入巢0次」；不能記作新增醣。
5. 招募和回饋：食物大且容易取得、個體收獲好、巢內存在可分享需求時可能留下可追蹤路線；食源枯竭、擁擠、異巢競爭、天敵、負擔與費洛蒙衰退會降低收益 [R07,R19–R21]。
6. 食物回巢：液體依物種可能是個體嗉囊載入／口對口分享；固體殘骸要先處理再成為可吸收的蛋白。**同一份食物不可在「工蟻吃」「帶回」「分給其他工蟻」三個階段重複計入外部總收入**。
7. 消耗與生命週期：成蟻與蟻后維生、移動與繁殖、幼蟲生長都需要資源／水。只有當已知起始庫存、物種、體重、食品組成與負載及能耗參數，才做mg、µL、mJ等真正數值結算；否則報告定性收支與null，不硬判飢餓死亡。

**決策模型是未校準的結構，不是已知機率**：
`P(depart_i) = f(own_crop_i, local_returning_contacts_i, local_temperature_i, day_phase_i, injury_i, fatigue_i, route_memory_i, local_risk_i)`。
`source_stock_next = source_stock_now + production - harvest_ours - harvest_rivals - decay - other_losses`。
缺任一必要物理值時，該通量與期末值保持null，不能擅自以0代入。

## 四、每日帳目：要記什麼？
- **食源層**：是否有人實際目擊、食源類型、是否找到、是否可食、可用庫存（未知null）、別巢競爭／分解與新的來源事件。
- **個體層**：外出時間窗、路線、接觸的線索、搜尋結果、巢外吃掉、載入量、返巢或未歸、傷亡、分享接觸、能耗（未知null）。
- **群體層**：出行事件、空載、實際帶回事件數、分享事件、成蟻攝食、幼體攝食、蟻后攝食、失去／腐敗、儲糧、可用水與凈收支。**事件數0可以確定；mg等物理量不因事件數0就等於0**。
- **幼體與風險**：營養缺口可能改變行為，卻不憑連續兩天沒有新食物就判整巢存糧為0或直接強制死亡。
- **科學分級**：每條文獻記錄研究物種與限度；本遊戲為黑色地棲螞蟻的虛構綜合類型，`species_taxon=null`。

## 六、訊號傳遞與覓食互相制約（2026-11-01）
另參照 [ant-communication.md](ant-communication.md) R32–R48。工蟻是否出巢與招募，必須先有**實際局部接觸、可感知的線索或自己的路線記憶**，而非全局資源餘額。實際採食與回巢才能可能強化路線；沒有采食確認仍可探索，但不得自動產生高收益招募訊號。
觸角接觸可能更新回巢接觸者的出勤傾向（收穫蟻特定研究）；若此未鑑定蟻種沒證實使用路徑化學導航，不能強制畫出高濃度指向F01的費洛蒙線。口對口分食只有在物種相容、兩者接觸與可轉移液體成立時才觸發；**分享不加外部食物入庫**。全日出巢數、空載、招募、警戒與分食應互相對帳，同一事件不可在「接觸／分享／採食」三個帳目重複建立物理收入。
