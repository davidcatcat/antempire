# 《螞蟻帝國》v2｜正式選定物種：熱帶大頭家蟻 Pheidole megacephala

> **由玩家於2026-11-01指定的虛構模擬物種**，不是對現實臺中西屯私人花園採樣／實際觀察的鑑定結果。**自Day6（2026-11-05）起依此物種作為行為模型**，Day1–Day5舊事件只讀、**Day5仍120小時**。即使物種已選定，花盆土丘N00的實測巢室溫度、土壤、工蟻個體體型、營養與行走速度仍未知，不能把其他研究地點的數值視為現場測量。

## 1. 物種分類與外觀
- 中文名：**熱帶大頭家蟻**；學名 **Pheidole megacephala (Fabricius, 1793)**；蟻科Formicidae、家蟻亞科Myrmicinae、大頭家蟻屬Pheidole。
- 臺灣生命大百科記錄此種廣泛分布於臺灣中低海拔，出現於庭院、都市綠地、草地、農地、石塊下、倒木與土中 [R93,R94]。屬入侵性、具生態競爭力的外來種；這裡是**文字遊戲**，不是建議在真實花園引入或放生該物種。
- **已確認物種有大小兩類工蟻**：minor（小型工蟻）與major（大型工蟻／兵蟻），均為雌性工蟻，成年後不互相「升級」；大型有較強大顎與頭部，常參與防衛、拆解獵物與搬運；小型常完成日常覓食等任務，**任務不是絕對固定** [R94,R95,R96,R97]。
- **研究參考外形尺寸**：臺灣生命大百科參考族群小工蟻約2.4–2.5mm，大工蟻約3.9–4.1mm [R93]；2026年廣西研究小工蟻約2.5mm、大工蟻約3.5mm [R94]。這是不同參照族群與測量，不用來反算W004–W017的實際身長。
- **目前14隻W004–W017的個別minor／major狀態依舊全是null**。不能把歷史上負責警戒的W010指定兵蟻，也不能憑14人團體硬套文獻major比例。生物學分類已知雙態 ≠ 已知主巢目前分布。

## 2. 蟻后與蟻群繁殖
- 物種文獻記錄**多蟻后（polygyny）殖群常見**，多巢且有些族群會由蟻后帶工蟻在近處**分巢（budding）** [R94,R97,R100,R101]。2026年廣西研究的樣本每巢2–7位有生殖能力蟻后，**不表示Q001現在需憑空增加蟻后**。
- 2026年研究也整理本物種有**單蟻后獨立創巢的既有報告**，因此「虛構本群目前只確認Q001一位蟻后」可成立 [R94]。未來有新后／分巢必須是事件與個體可追溯，不預設大型成熟多后超級殖群。
- 研究中蟻后可能**成批產卵、間隔停產**；不同地區的繁殖季、婚飛與分巢策略不同 [R94,R95]。Day5沒有產新卵仍合理；**未測實際卵巢、營養與巢溫**，不直接令Q001每月產97–292顆。雄蟻／新后必須經完整幼體與羽化流程，不能憑物種切換瞬間出現。
- **研究溫度發育資料**（以下是廣西實驗室28±1°C、70±5%RH、16L:8D、充分供應食物，不是本巢的天氣或未來固定倒數）[R94]：

| 實驗指標 | 平均±SD（從**產卵那天**計） | 僅限該實驗條件 |
|---|---|---|
| 卵孵成幼蟲 | 7.69 ± 0.63 天 | 溫度／工蟻照護與培養條件特定 |
| 第2齡幼蟲 | 9.54 ± 0.73 天 | 從產卵計累積日 |
| 第3齡幼蟲 | 15.06 ± 0.67 天 | 從產卵計累積日 |
| 非繁殖個體化蛹 | 23.68 ± 2.38 天 | 不把未知生理齡L001/L002硬寫將化蛹 |
| 非繁殖個體（minor/major）羽化 | 28.73 ± 2.83 天 | 當Q001群巢室實際溫度未知，禁止直接套用 |
| 雄蟻／新后等繁殖個體羽化 | 37.60 ± 3.20 天 | 只有確認發育成繁殖個體才可引用 |

- 同研究指出卵發育的時間與同批幼體不同步，工蟻大／小形態在發育期形成。舊UF/IFAS及GISD歸納不同溫度／族群的更長生育時間（卵13–32、幼蟲23–29、蛹10–20+天），可和此28°C新實驗**並存**，但不可將兩份結果拼成同一套完整個體時間表 [R94,R95]。
- 2026年該實驗小工蟻存活時間平均26.25日、major平均56日，仍屬實驗群體環境與取樣估計，**W007等傷蟻或W017的實際壽命不可直接填入** [R94]。

## 3. 覓食、食物來源、社會訊號
- **雜食**：採食蜜露、花蜜／糖液、昆蟲殘骸與可取得的節肢動物／種子；已有F01蚜蟲蜜露、F07/F11舊屍體、F03落果等可作合理潛在來源，但**沒有確認當日新食物入庫**並不會被物種切換改成有。
- **招募（2026-11-01證據修正）**：本物種2009年實驗可由**雙費洛蒙模型**解釋[R96/R21]，但2023年**單費洛蒙＋行為決策模型**亦可重現重要結果[R102]；**尚不能聲稱已化學證實兩種不同招募分子**。從Day6起可以模擬定性招募、保留單／雙模型比較，而不固定兩化學通道，但每條通道的實際分子濃度、維持時間、多少工蟻接收都未測，仍為null；歷史F01弱線索不能追溯成濃度。
- **口對口交換**：UF/IFAS觀察到小工蟻彼此或大、小工蟻間的trophallaxis [R95]，因此物種層次已確認具此能力；必須有真實相遇、液體與事件才能發生，不能自動增加總營養。
- **工蟻分工**：minor通常覓食、育幼、普通巢務；major常防衛、處理大型食物，若小工蟻不足亦可參與其他工作 [R93,R95,R97]；未知個體亞階級仍不影響其已發生歷史工作。
- **接觸／警戒／震動**：同巢辨識仍需要局部感知；沒有本物種實驗就**不**開啟其他蟻種特有的摩擦發聲／可校準警戒濃度。蟻后仍不下達工作指令。

## 4. 築巢、擴張與未知世界
- 台灣資料記錄此種可棲於土中、石下與倒木；2026年廣西野外研究偏好濕潤陰蔽的**現成縫隙／空腔**，不常挖成大型露天土堆 [R93,R94]。N00是**既有故事的花盆下土丘／縫隙複合巢**，保留兩育幼空間、一儲藏空間及外圍泥脊防線，但泥脊是故事歷史工程，**不是把P. megacephala說成普遍築大型土丘**。
- 局部巢室條件與食物、人力、植物根系有關，仍依[nest-construction.md](nest-construction.md)每次從土粒挖掘搬運累積，不因新物種就生成新室或新出入口。
- 具競爭優勢：已有研究觀察本物種可對其他蟻巢攻擊與掠奪幼體 [R100]。但**只有小群14隻工蟻**，不把成熟多巢軍團能力直接套上，不因F03有外蟻就自動開戰或勝利。
- 探索時，形態（minor/major）與已知外界訊號會影響可能的工作類型，但**目前任何個體真實走速／最大覓食距離／體長仍未測**；不把樹棲Cephalotes或其他蟻的速度套入本種。

## 5. 物種已確定，但哪些事情仍然未知？
| 已有物種研究支持 | 本群仍然未知 |
|---|---|
| P. megacephala；有minor/major二態工蟻 | W004–W017誰是minor/major、實際頭幅與體長 |
| 多蟻后常見、也有單蟻后創巢報告 | Q001真實年齡、卵巢／交配狀態；本巢是否存在未記錄其他后（已確認只Q001） |
| 28°C實驗非繁殖約28.73天、繁殖約37.60天 | N00實際巢室溫濕、幼蟲原生理齡、每日食物總量 |
| 可用費洛蒙招募、單/雙通道競爭模型 | 具體分子、現場路線濃度與半衰期／個體是否接收 |
| 口對口液體交換在此種有觀察 | W005是否今天真的與W008交換任何液體及分量 |
| 會利用陰涼土壤、石下與縫隙築巢 | N00幾何、挖土速度、水害、防洪與通風實測 |
| 具有競爭與掠奪潛力 | 花園外圈有無敵巢、14隻小群能否抵抗任何外群 |

## 6. 優先規則與相容性
1. **玩家當前指定的模擬物種**優先於舊README、各通用規格內「物種尚未選定」的原研究假設。舊敘事中「unknown」代表**當時沒有指定物種**或**目前仍缺個體／實測資料**；不能回頭改造Day1–Day5。
2. 主狀態：`saves/main.json#/simulation/species_id`、`#/setting/species`；世界狀態：`saves/world-state.json#/ant_population/taxon`；各子模型`taxon`一致為`Pheidole megacephala`。模型資料實際生效Day6，舊歷史延續。
3. 此物種**存在major形態**、**支援化學招募／分食**，所以應啟用**能力本身**；但14位工蟻的形態、實際訊號事件、巢內食物和發育階段仍需獨立證據，沒有事件不預設發生。
4. 任何新生／傷亡／開新巢／出新食源仍依既有守恆與因果規則；研究資料可能是廣西、非洲、佛羅里達等地，**不得冒充台中花園實地觀測**。
