## 1. 座標系
- **世界 ← 身體 ← 頭部**。身體座標：原點＝身體中心（kinematics2d 的姿態 x, y, θ），x 朝前、y 朝左。頭部座標：原點＝兩個觸角窩（torulus）的中點，位於身體軸上 `head_origin_x_mm`，相對身體轉 `head_yaw_rad`（頭部轉動未建模，候選值 0）。
- 轉換 `toParent`／`fromParent`／`compose` 是精確的剛體轉換；左右觸角基部在頭部座標 (0, ±`torulus_halfspan_mm`)。

## 2. 觸角幾何與活動範圍
- **肘狀兩節**：柄節（scape，長 Ls）＋鞭節（funiculus，長 Lf，視為一根剛體；本種觸角 12 節、3 節棒，R871、R870，節間彎曲未建模）。
- 關節角：柄節角 α（頭部座標，從頭的前方算起，**向外為正**，右觸角鏡射）；肘角 β（鞭節相對柄節，向外為正）。活動範圍 [α_min, α_max]、[β_min, β_max]。
- **平面模型**：真實觸角在三維中運動；平面長度只是投影長度的上限。
- **可達範圍（解析）**：|尖端 − 基部|² = Ls² + Lf² + 2·Ls·Lf·cos β；最遠在肘角最接近 0 處（範圍含 0 時＝Ls + Lf），最近在最接近 ±π 處。
- 接觸用形狀：柄節、鞭節各為一個膠囊（半徑 `antenna_radius_mm`）。

## 3. 擺動（運動學模型，不是畫面動畫、不是知覺）
- α(t) = αc + Aα·sin(2πft + φ側)，β(t) = βc + Aβ·sin(2πft + φ側 + φβ)；t 是模擬時間（秒）。只作為幾何與接觸測試的輸入。
- 速度上限（相對頭部）：|α̇|·Ls + (|α̇| + |β̇|)·Lf，|α̇| ≤ 2πf·Aα、|β̇| ≤ 2πf·Aβ。測試以有限差分確認。
- **與畫面分開**：`web/src/display-motion.ts`（PR #164）的觸角擺動是顯示插值，**不是**知覺事件，也不是這裡的運動學模型；本模組的參數表沒有任何顯示參數，兩者不共用數值（測試檢查）。

## 4. 參數（決策 37）
- **物種模式**（`mode: 'species'`）：每個值都必須有來源、`assumption: false`。本種只找到柄節長度的**標本範圍**，沒有個體值，也沒有鞭節長度、觸角窩位置、半徑、活動範圍、擺動參數，所以 `species_params` 全部是 `null`，物種模式**拒絕執行**（`NULL_PARAMETER`，列出全部 18 項，不預設）。
- **候選模式**（`mode: 'candidate'`，必須明寫）：每個值 `assumption: true` 並註明根據類型；缺任何一項或未標示都拒絕。
- **形態約束**（有來源的量測只用來**約束**候選值，違反就拒絕 `MORPHOLOGY_CONFLICT`）：
  | 約束 | 範圍 | 來源 |
  |---|---|---|
  | 柄節長 SL | 0.61–0.73 mm | R99（Fischer & Fisher 2013，n = 20：0.61–0.72）、R870（n = 5：0.67–0.73） |
  | 觸角窩半間距 | ≤ 0.25 mm（最小頭寬 0.50 mm 的一半） | R99 |
  | 頭部座標原點 | 0.53–1.25 mm（體長 2.5 mm〔R94〕時頭部在 [L/2 − HL_max 0.72, L/2]） | R870、R94 |
- **候選值**（小工蟻）：柄節 0.69 mm（範圍交集 0.67–0.72 內；範圍：文獻支持，取值：遊戲假設）；其他全部是**遊戲假設**：鞭節 0.85 mm、觸角窩半間距 0.10 mm、頭部原點 1.0 mm、半徑 0.02 mm、α ∈ [0.1, 1.6]、β ∈ [−1.8, 0.3]、擺動 αc 0.9 ± 0.3、βc −0.8 ± 0.2、2 Hz、左右反相。
- **禁止**：不得把他種觸角長度當本種數值（R810 只有定性）；**不得由追跡是否成功反推觸角長度**；敏感度分析只看感測點位置與接觸偵測，不與 R133 擬合。

## 5. 觸角接觸（決策 36）
- **三種事件分開**：`geometric_contact`（身體碰撞，kinematics2d `contact_start/end`）、`constraint_active`（求解器約束，kinematics2d `stop_on_contact/repress`）、`antenna_contact`（**本模組**，觸角真正碰到）。`contactKindOf` 對應；身體接觸**永遠不會**變成觸角接觸（測試：後退撞到側面的身體接觸，沒有任何觸角事件）。觸角事件帶 `recognition: null`：只是幾何上碰到，辨識未建模。
- **對象**：靜態物（牆、圓、多邊形邊）、其他個體的身體膠囊、其他個體的觸角（每對只算一次）。同圖層才配對；自己的身體不算。
- **連續偵測（保守前進）**：與 kinematics2d 相同的容差與時間契約：θ = 10⁻⁷ mm、λ = θ/2、ρ = 10⁻⁹ mm。間距用**帶號**膠囊間距（核心交叉時減去穿透深度＝兩線段 Minkowski 差的平行四邊形邊界距離），所以觸角穿過物體時仍可安全步進。速度上限＝身體扭轉（線速度＋角速度 × 觸角最遠半徑）＋擺動上限（＋對方的上限）。**保證**：回報接觸前 g > λ；接觸中、回報分離前 g ≤ θ + 2ρ；接觸時刻以二分法給 `bracket_s`。
- **時間契約**：時間終點 H 是處理過的時刻，H 之後不讀（`max_time_read_s ≤ H`，讀 H 之後會丟 `FUTURE_READ`）；步長不依 H，所以短終點的結果是長終點每一對事件的前綴（被二分回 H₁ 之前、但要到 H₁ 之後的迭代才偵測到的事件只出現在長的那次）。H 之後改計畫不影響 H 之前的結果。
- **觸角是運動學的**：碰到不會彎曲或停止，會穿過物體（回報負間距作為診斷）。觸角與物體的力學、碰到後螞蟻怎麼做，本種無資料，**不建模**。
- **身體運動**先由 kinematics2d 解（身體碰撞會停），觸角接觸在**實際執行的**身體運動上偵測。

感測轉接：契約重算的尖端與精確尖端差 < 10⁻¹² mm（只有捨入）。

- **角度**：柄節中心角與擺幅改變尖端側向範圍，最大可達 −0.24 mm（αc 0.6、Aα 0.3 時**尖端越過身體軸**）。這種姿態無法用現行感測契約表示（見 §7）。
- **取樣點數**：只取尖端（n = 1）漏掉 8 對接觸中的 1 對；n ≥ 2 都找到，但首次接觸會延遲到 18 ms（時間格點 1 ms）；取樣點越多，重心離尖端越遠（感測位置不再等於尖端）。精確的連續偵測不依賴取樣點。

## 7. 與局部感測介面整合（`local-sensing.ts` 未修改）
- 契約只接受「頭前緣（身體中心 + L/2）＋長度 × 方向（θ ± 半角）」的兩個尖端，並自行重算比對。`sensingRequests` 把**每一側**精確尖端換成等效的直線觸角幾何（每側一個請求），交給 `sampleLocal`；重算點與精確尖端的差 < 10⁻¹² mm（只有捨入）。等效長度**不是**形態長度。
- 尖端越過身體軸（左尖端在右側）時無法表示，轉接器**拒絕**（`TIP_NOT_REPRESENTABLE`），不鏡射、不改寫。是否擴充契約（直接接受由觸角幾何算出的點）由 `local-sensing.ts` 的負責方決定。
- 請求帶全部觸角假設標籤；尖端位置用請求時刻 t_s 的擺動關節（不讀其他時刻）。

## 8. 未決與限制
- 鞭節長度、觸角窩位置、活動範圍、擺動模式、觸角直徑：本種**未查到**，全部是遊戲假設；物種模式無法執行。
- 平面投影、鞭節為單一剛體、頭部不轉、觸角不偏折、不碰自己的身體。
- 只有小工蟻的候選值；大工蟻（SI 47–58，柄節相對頭寬短得多）只記錄形態範圍，沒有候選集。
- 觸角接觸尚未連到任何辨識、招募或行為；接上之前需要另外的 Owner 決策與本種證據。
