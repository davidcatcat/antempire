## 2. 天氣來源與優先序
1. **中央氣象署實測（觀測）**：用西屯區或可驗證的鄰近地面氣象／雨量測站；使用其時間戳、站名、站號、是否為整日完整值。檔案／歷史查詢：https://climate.cwa.gov.tw/GroundObservation
2. **中央氣象署鄉鎮預報（未來）**：使用西屯區或臺中市相應預報，註明行政尺度、發布時刻和預測有效時段。官方資料集：https://opendata.cwa.gov.tw/dataset/forecast/F-D0047-093 （全臺鄉鎮預報；資料更新頻率依氣象署公告）。
3. **可追溯的代理頁面**（若官方資料難以直接機器讀取）：需註明是二手轉載，以及原始發布機關，保留資料時間與來源網址；不能聲稱是本模型直接取得測站原始時序。
4. 若某一參數沒有可信資料：數值 **null**，不補造0、不拿臆測常數充當「真實資料」。

## 3. 資料語義禁止混淆
- 「降雨機率0%」**不等於**已觀測「降雨量0mm」；截至當天下午的**累積雨量0mm**也不等於全天降雨0mm。
- 當日尚未結束或無完整觀測時，**日總雨量、實際最低／最高溫 = null**；可以另存截至某時刻的觀測或預報高低溫。
- 鄉鎮預報溫度不是花盆土丘的巢內溫度；土壤濕度、巢穴溫度、遮蔽程度、室內外微氣候需要模型或測量。缺資料保持null。
- 對未來日期：預報必須標 `forecast`；待日後有實測才可更新為 `observation`（但已寫過的敘事不暗中回溯重演）。
- 季節或單日天氣不能自行決定物種，尚未鑑種的螞蟻保持未知。

## 5. 每次續玩的天氣查詢清單
1. 計算該模擬日的**真實曆日與時區**；先檢查日期是否已過、當天或未來。
2. 查官方觀測／預報，註明站名或鄉鎮範圍、來源URL、發布與有效時間、單位、觀測／預報分類。
3. 使用當天氣象**驅動**出巢傾向、巢室水分風險、蜜露可接觸性及捕食者活動；這些生物學轉換仍需物種／環境參數，不能把方向性模型推論說成量測。
4. 對精確量無從推估時保持null；所有模擬事件仍須遵守局部知識、受傷、幼體、資源守恆與隨機種子規則。
5. 先存新v2日誌、世界狀態和主存檔，再從GitHub重讀驗證；不修改任何v1歷史。
