# 觀察器 V5：事件篩選、事件地圖、紀錄路線、每日事件數（Canvas 2D）

> 範圍：唯讀網頁觀察器（`web/`）。不改引擎、參數、存檔、日誌，`web/data/` 不變。不使用 PixiJS。
> 建立在 V3（追蹤、事件跳轉，#106）與 V4（每日統計、推得速度，#110）之上。

## 1. 盤點：V3/V4 已有什麼、V5 補了什麼

## 2. 功能說明
- **事件類別**：類別只依引擎事件的 `type` 查固定對照表（`web/src/model.ts` `EVENT_CATEGORY`），不判斷螞蟻的「意圖」。類別有：覓食與採集、招募與交哺、探索、捕獵、死亡、產卵與發育、育幼接觸、環境生態、其他。目前三個重播中的所有事件類型都有類別，沒有事件落到「其他」（測試檢查）。
- **全部日子**：列出整個 30 日重播的引擎事件，每列前面標 `D<日>`。有時刻的事件顯示分鐘；沒有時刻的事件（死亡、產卵、發育、交哺、卸貨等）顯示「日終（無時刻）」，點選時跳到那一天的日終結算。
- **事件位置**：地點只取自事件記錄的發生地點欄位（V3 `EVENT_PLACE_FIELD`）。以下事件沒有地點欄位，**永遠不畫在地圖上**：死亡、產卵、孵化、化蛹、羽化、招募接觸（`local_recruitment` 的 `site` 是招募的目標，不是接觸發生的地方）。地點沒有方位與距離紀錄時（U00、U01），圓圈畫在「位置未記錄」框內。
- **紀錄路線**：一段＝一次紀錄步行中的一條邊。出發＝活動片段起點或上一個 `route_step` 抵達分鐘；抵達＝引擎的 `route_step` 分鐘。沒有紀錄的抵達顯示「未記錄」，速度也不推算。目前三個重播的 1,626 段全部有紀錄。
- **巢內名冊標示**：引擎沒有巢內空間結構，紅圈只表示「這個 ID 是那筆紀錄提到的個體」，不是位置。

## 3. 資料分類（§8）
| 類別 | 本版內容 |
|---|---|
| 引擎事件（原樣） | 時間軸列、事件跳轉、事件位置的計數、巢內紅圈的 ID、路線的出發／抵達分鐘、每日事件數、昆蟲數、半翅目群數 |
| 推得值（由紀錄計算，標示「推得」） | 路段速度＝長度÷紀錄時間；推得總長＝路段約距離加總；紀錄步行時間加總 |
| 顯示插值（只供畫面） | 兩個紀錄點之間工蟻的位置；路線上「正在走」的虛線終點。不寫回、不產生事件 |
| 示意（非測量） | 地圖座標（方位＋約距離）；路線藍線（只連接紀錄節點的直線，不是實際軌跡） |
| 觀察者視角 | 事件位置、花園昆蟲與半翅目總數、花園食源總量。螞蟻不知道這些 |
| 示範資料 | 無 |

## 4. 限制與尚未模擬
- **育幼接觸：尚未模擬（預設規則）。** 個體育幼接觸（`larva_contact` 等）只存在於預設關閉的 C3a／C4a 巢內回合。這三個重播沒有這類事件，所以地圖與巢內都無法定位育幼。巢內視角會寫出這一點。如果日後的匯出包含這類事件，觀察器會歸到「育幼接觸」。目前它們沒有分鐘（只有巢內回合序號），所以會放在日終結算。
- **沒有分鐘的事件**：死亡、產卵、發育、交哺、卸貨（`food_delivered`）在引擎中都沒有時刻，只出現在日終結算這一格，從不畫在某個分鐘。
- **巢內空間：尚未模擬。** 巢內視角是名冊，不是巢室圖。
- **路線形狀**：引擎只有節點與路段，沒有連續軌跡。路線線段是示意直線。
- **長度**：路段長度是世界設定的約距離（遊戲假設，是實際路徑長度的下限）。所以推得速度與總長都不是量測。
- **手機**：測試用的是 Chromium 的觸控模擬（412×915），不是實體手機。
- **大工蟻**：尚未模擬（物種參數 `major_worker_production_enabled: false`）。

## 5. 測試與截圖
- `tests/web-v5-observer.test.ts`（Node，BLOCKING）檢查：類別涵蓋所有事件類型；全部日子列表＝每日 V3 列表；事件標記＋無地點＝輸入事件；沒有地點欄位的事件從不標記；每段路線的抵達分鐘都是 `route_step`；推得速度＝V4 `walkSpeedAt`；巢內紅圈的 ID 存在於引擎日終狀態；每日昆蟲與半翅目數＝引擎狀態；輸入凍結，結果可重現。
- `tests/browser/web-v5.check.cjs`（CI，Playwright）：桌面 1280×800 滑鼠、412×915 觸控（DPR 2）。檢查畫布上的世界標示、追蹤、路線表、全部日子＋死亡篩選與跨日跳到日終結算、覓食篩選跳到紀錄的分鐘與地點、事件地圖計數、死亡不上地圖、巢內只在日終結算後標示、每日事件表＝引擎日摘要、手機沒有橫向捲動。同時輸出截圖到 `reports/viewer-v5/screenshots/`（每個功能桌面、手機各一張）。
- 本機執行：`npm run web:build && node cli/web-serve.ts 8781 &`，然後 `node tests/browser/web-v5.check.cjs reports/viewer-v5/screenshots http://localhost:8781/`。

## 6. 靜態預覽的路徑假設
`index.html` 用相對路徑載入 `dist/main.js`，資料讀 `data/*.json`（`fetch('data/' + 檔名)`）。所以把 `index.html`、`dist/`、`data/` 放在同一目錄、用任何靜態伺服器提供即可，放在子路徑下也能用。限制：必須透過 HTTP 開啟，直接用 `file://` 開會讀不到資料；不需要任何伺服器端程式。
