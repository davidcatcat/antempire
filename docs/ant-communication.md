# 螞蟻帝國 v2｜螞蟻訊號與資訊傳遞：科學機制規格

> 研究整合日期：**2026-11-01**（現實日期）；**自Day6，2026-11-05的下一次模擬起生效**。此更新不推進已完成的Day5、不倒填既有訊號事件、不改動任何個體數量。世界中的臺中市西屯區別墅為虛構，蟻種未鑑定（`taxon=null`）。機制參照 [references.md](references.md) R03、R04、R07、R21、R22、R25、R32–R48。
>
> **關鍵區別**：有同行評審研究支持的「訊號通道」不等於本蟻群已確認會使用該通道；實驗物種的濃度、秒數、閾值或特定器官**不可**直接搬用。規格是有因果的**科學啟發式文字模擬**，並非已校準的多蟻代理計算引擎。

## 1. 螞蟻傳遞的不是人類文字，而是局部刺激
任何訊號必須依序具備：
`emitter及其當下經驗 → emission（釋放/接觸）→ medium（空氣/基材/身體接觸/液體）→ propagation與loss → receiver在同時同地感知 → 與記憶/生理/風險結合 → 可選的行為反應 → 可能的第二次訊號`。

**沒有接收到訊號的工蟻不會知道**。接收到也不代表百分之百遵從。工蟻可以忽略、反應延遲、誤判或依自己的經驗選不同路線。蟻后不是中央調度者，費洛蒙不是精確地點文字座標與群播指令 [R32,R33,R37]。

## 2. 已有文獻支持的主要訊號

| 通道 | 誰發出／環境媒介 | 可傳的訊息或調節方向 | 限制、適用性 |
|---|---|---|---|
| **覓食／招募路徑費洛蒙** | 某些物種工蟻在實際走過的地面、葉片等基質留化學線索 | 幫助其他同巢工蟻選路、利用食源；可能依收益與擁擠給正/負回饋 | 螞蟻**不全都依賴路徑費洛蒙**；路線與個體記憶並行，不確定的「上一日弱路線」濃度仍null [R32–R36] |
| **局部警戒化學訊號** | 某些物種遇危險釋出揮發性物質，受風／接收環境影響 | 接近、警覺、聚集、退避，具物種與濃度差異 | 不會全巢瞬間得知；特定Ooceraea的高濃度可能驅避，不能普遍寫成「聞到就進攻」[R41,R42] |
| **同巢／異巢辨識** | 工蟻體表碳氫化合物（CHCs）的化學標籤，在近距接觸／感知下比較 | 判斷「像同伴／不同」，影響接受或防衛傾向 | 標籤與學習因物種／飲食／經驗而異；**不是絕對的敵我雷達**，無直接接觸就不能遠知對方巢址 [R39,R40] |
| **觸角接觸** | 遇見其他工蟻時的短接觸，取決於相遇率及個體背景 | 可改變待出巢工蟻的離巢傾向、反映回巢者接觸頻率 | 已由收穫蟻實驗證實，但**不會傳送精確食物重量或遠端地圖**；所有接收者需實際相遇 [R37,R38] |
| **口對口液體交換（trophallaxis）** | 發生相容物種、兩個體相遇且完成實際液體交換時 | 交換養分，也可能轉移辨識線索／訊息及部分內源化學物質 | `trophallaxis=conditional_unknown`，不能為未知蟻種預設一定能口對口交換；不強加Camponotus的調節效果 [R22,R43,R44] |
| **基質震動／摩擦發聲** | 某些有特殊構造的螞蟻透過土、植物或其他基材傳送震動 | 特定物種可傳危險、受困、招募或與採食情境有關的線索 | **不等於一般螞蟻用空氣喊話**；切葉蟻Atta與Crematogaster的實驗**不可套成全蟻種能力** [R45–R47] |
| **蟻后生殖相關化學訊號** | 繁殖個體與巢內接觸／化學環境 | 影響生殖與群體狀態感知，視物種而定 | 不是「蟻后說現在派W005去採蜜」；已知規格R03/R04，未知濃度及受體反應保持null |

### 特別重要的反例
`Pogonomyrmex barbatus` 收穫蟻可主要藉由**回巢工蟻的近距接觸頻率**決定出勤，而不是依賴路徑費洛蒙去找散落種子 [R37,R38]。因此**預設unknown taxon不可以設定所有工蟻一定會鋪設化學路線**。

`Atta`、`Crematogaster scutellaris` 的震動訊號有研究 [R45–R47]，但本花園未知蟻種沒有鳴動器官鑑定。預設為`conditional_unconfirmed`，**不能虛構每次受困就發出專業求救震波**。

## 3. 化學路徑的物理性質與有限傳播
- 訊號只存在於**工蟻確實經過並留下線索的路段**（例如N00↔F01），不是整個花園全圖可讀。沒有實際沉積事件就不能補造今次訊號 [R32,R33]。
- `pheromone_present`、`concentration`、`half_life`、`deposition_rate`、`detection_threshold` 目前都是`null`；記錄過去「可能有弱路線」不等於今日精確量測到高濃度。
- 化學物質可能揮發、降解、受**路面溫度、材質、雨滴和局部澆水**影響 [R35,R36]。臺中市預報30°C**不是**花盆表面30°C，更不能當作計算實際蒸發率。
- 若有校準後數值，可選`signal_next=signal_now+deposition-removal_by_decay-water-rubbing`；缺起始濃度／速率則`signal_next=null`。
- 已知有物種把高濃度路線與個體記憶混合判斷，也有擁擠使釋放減少的負回饋 [R33,R34]。不能把「沿路線走」直接當100%強制跟隨。
- 警戒化學訊號不同於採食路線；短時範圍、散逸與受體反應需要分別記錄。未證實訊號存在時不能當作已釋放一股氣體。

## 4. 巢內社交接觸與資訊／食物是兩份帳
- **觸角接觸**是`contact_event`；需兩隻工蟻在相容的地點與時間窗口真的相遇。接觸可改變外出傾向，不能無憑據改寫該工蟻的全部遠端地圖 [R37,R38]。
- **口對口交換**必須先確認該蟻種具該能力、兩者確實互動、有可傳液體；然後可記`transfer_event`。它是食物轉移不是外部新食物入庫 [R22,R44]。
- **辨識**需有接觸或足夠近的化學感知；異巢蟻與本巢個體在同一F03附近不一定代表已辨識。辨識結果可不確定、會受學習與表面CHC差異影響 [R39,R40]。
- **資訊不等於字串**。例如W005空載回巢、與W008接觸，只能改變W008的局部食物回報刺激；不能直接宣稱W008知道「F01食物0毫克、F05蜘蛛位在73cm」。
- 一次接觸事件的`receiver_ids`只包括當下真的接觸並感知的個體。後續訊息跨螞蟻傳遞需新接觸事件，不允許遞迴瞬時擴散到全殖群。

## 5. 警戒、敵蟻與多訊號衝突
- 一隻工蟻親眼／接觸天敵→可能有警戒反應（停步、迴避、轉向、覓食中止）。**是否會放警戒費洛蒙、何種受體反應**，屬未知物種條件；不得為敘事硬加訊號 [R41,R42]。
- 異巢蟻先要出現在相關位置，接觸或能感測到CHC才可能更新`nestmate_assessment`；接著可能迴避、警戒、忽略或衝突。辨識 ≠ 必然交戰 [R39,R40]。
- 若路線吸引與警戒環境同時存在，工蟻可改變走法或退出；反應取決於各自**真的感知到的**訊號及個體記憶，不是全圖權重比較。
- 不同物種的訊號可能被競爭者「竊聽」，但跨物種理解不是預設 [R48]；外蟻不能憑主巢訊號就精確知道主巢儲糧與每隻工蟻位置。

## 6. 每20分鐘「窗口」中的訊號因果流程
20分鐘是模擬檢查解析度，真實接觸可在**秒**尺度發生 [R37]；不意味每20分鐘必產出一次氣味。

1. 確立每隻工蟻本窗口`location`，並先更新環境、食源、其他動物活動及可能已有訊號的衰退。
2. 依`emitter_location`、行為（找到食物、回巢、遇危險、與同伴接觸）、物種適用性，判斷有無實際**釋放**／接觸事件；可沒有任何新訊號。
3. 只在媒介相通的鄰近路徑／近距接觸／同一物理基材中考慮**傳播與接收**，阻隔、時間、潮濕與未知濃度都可能讓訊號到不了。
4. 只有接收者真的在場並感知，才在其`individual_receiver_state`記錄；不把「世界背景中蜘蛛出現」轉成全巢警報。
5. 工蟻綜合個體局部記憶、饑餓、體力、傷勢與訊號，更新探索／警戒／育幼／休止等傾向；**不可宣稱訊號決定了100%行動**。
6. 新的出行／回巢／資源收穫／巢內接觸產生**新的獨立事件**；不可從結果倒填一條沒有釋放的訊號。
7. 記錄事件`emit→propagate→perceive→respond`與時間、位置、發出者、接收者及未知值，結算當日訊號狀態；沒有數值時定性與null。

**同時對接** [foraging-food-economy.md](foraging-food-economy.md) 的`出巢→搜尋→採食→帶回→巢內傳遞→消耗`；信號不是獨立於覓食和食物流量外的每日新抽獎。

## 7. Day6起的持續資料結構
在`saves/world-state.json#/communication_system`：
- `route_signals`：現有N00↔Fxx每個路段的歷史質性線索、`trail_concentration=null`、物種適用性`unknown`、衰退與下一次實測依據；**不得將舊日誌的「可能有弱訊號」倒填成確定濃度**。
- `individual_receiver_states`：14隻工蟻最後接收到的訊號事件（尚未觀察則null）、局部記憶、受體閾值（null）、與`foraging_economy.worker_states`參照；不要把所有工蟻共享相同即時世界地圖。
- `nest_contact_network`：接觸事件（只有明確被新日誌確認者才記）；`trophallaxis_supported=null`；研究更新不倒填過去觸角或分食次數。
- `alarm_fields`：尚無新確認釋放的警戒訊號；`[]`是「已記錄事件0」，**不等於實際世界沒有任何警戒氣味**。
- `recognition_state`：CHC識別模式、具體化學標籤與比對閾值均`null`；不將異巢蟻的行為標籤寫成可查得真實DNA巢號。
- `vibration_channel`：`conditional_unconfirmed`，未知物種沒有指定發聲器官或振頻；不強制提供受困通訊。
- `day6_event_template`只做欄位模板，`not_simulated=true`；Day5蟻群、食物與時鐘不變。
