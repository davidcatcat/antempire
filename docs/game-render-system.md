# 遊戲畫面分層繪圖系統（V6 美術升級，PR B）

> PR A 的美術資產（`web/src/art-*.ts`、`docs/game-art-style.md`）之上，建立一個可重用的分層繪圖器。**本 PR 不改遊戲畫面**（`web/src/game.ts`、`index.html` 在 PR C 接線），只提供模組、獨立測試頁與量測。
> 原則不變：畫面只呈現引擎狀態；繪圖器不建立事件、不寫入、不匯入引擎；顯示插值與示意場景照 CLAUDE.md §8 標示。

## 1. 模組

| 檔案 | 內容 |
|---|---|
| `web/src/render-scene.ts`（純函式，Node 可測） | 11 層順序 `LAYERS`；仿射相機 `worldToScreen`／`screenToWorld`；引擎物件登錄 `engineRegistry`；紀錄路段 `recordedRoutes`；每 10 cm 格的示意裝飾 `decorCell`（避開地點與路段）；螞蟻規劃 `planAnts`；當日天氣狀態 `weatherState`；畫質階梯 `QUALITY`／`nextQuality` |
| `web/src/render-canvas.ts`（瀏覽器） | `LayeredRenderer`：分塊烘焙地面、引擎物件精靈、螞蟻圖集、光線疊層、畫質自動調整 |
| `prototypes/render-harness/` | 獨立測試頁＋Playwright 量測（`npm run render:bench`），`results.json`、`screenshots/` |

## 2. 圖層（每幀依序）

`ground → decals → shadows → propsLow → routes → antShadows → ants → propsHigh → lighting → weather → ui`

- **ground／decals／shadows**：烘焙進地面分塊（土壤細節磚、世界座標的大尺度地面場、落葉／樹枝等貼花、石子與草的接觸／投影陰影、低層物件）。分塊 256 device px＋每邊 4 px 鄰塊邊帶（重取樣時邊緣用到真實鄰居，無接縫），兩端對齊 device 像素；縮放分桶為 2 的冪（含 DPR），LRU 上限 120 塊，每幀烘焙上限 1–2 塊。
  - **無重複**：土壤細節磚在遠景時世界週期放大（不小於 128 px），再疊一份旋轉 37°、縮放黃金比的副本打散週期；顏色與濕度的大尺度變化來自**世界座標的非週期值雜訊**（週期 0.6–4.5 m），每塊在邊界上取樣，雙線性放大後跨塊連續。
  - **濕日**：每幀在地面層加暗（日值），不重烘分塊，換日不會卡頓。
  - **遠景細節分級**：每 cm 少於 24 device px 時，落葉不畫表面斑點與次級葉脈（看不見且最耗時）。
- **裝飾構圖（示意，以種子決定）**：落葉以「群聚過程」成堆分布，密度由低頻場決定（有裸土區、有厚落葉區），寄主與花附近較密；大小偏小（多數小、少數大）；少數大石頭周圍有碎石圍裙；碎石片區；草叢成簇；潮濕處有苔。
- **propsLow／propsHigh**：引擎物件（巢口、寄主＋半翅目簇、花、屍體）以精靈快取繪製，**中心精確落在引擎座標**；高層（草尖、上層葉、花冠）壓在螞蟻上方。
- **routes**：可選的紀錄路段虛線（玩家視角圖層）。
- **antShadows／ants**：圖集精靈；陰影依光源在螢幕空間偏移；反光以批次圖章繪製。螞蟻超過 300 隻時陰影改為單一批次橢圓路徑（群體 LOD）。
- **lighting／weather**：光源洗色、暗角與（雨日）陰天色調預先合成為一張疊層，每幀一次貼圖。重播只用固定示意光源；**不畫雨絲**（引擎雨量只有日值）。
- **ui**：「螞蟻放大顯示 ×N」；可選的引擎物件標示圈與代號（玩家視角）。

## 3. 資料與誠實性

- **位置**：`planAnts` 回傳 `ex,ey`＝引擎位置的仿射映像（逐點等於 `model.poseAt`）；`sx,sy`＝再加上呼叫者提供的**顯示排列偏移**（車道、地點圍圈）。轉身緩動（≤ 8 rad/s）只是顯示插值。
- **不修改輸入**：輸入幀與前一幀狀態都不被改寫（Node 測試以凍結物件驗證；瀏覽器測試頁每幀比對）。
- **步態**：走／停依呼叫者的 `moving`（引擎紀錄點之間）；轉向步態只在提供權威 ω 時（重播沒有）。
- **裝飾**：每格以種子決定；與引擎地點保持 ≥ 地點半徑＋3 cm，與紀錄路段保持 ≥ 1.5 cm（只影響畫面，不改任何位置）；裝飾只有落葉、樹枝、石子、草、苔、碎屑，不放任何像食物的東西，也不可點選。
- **引擎物件登錄**：只列有紀錄座標的引擎地點與其引擎狀態（群數、寄主存活）；蚜蟲或介殼蟲目前由地點名稱判斷（待 Owner 決定）。

## 4. 效能（Playwright＋headless Chromium，軟體繪圖，暖機 6 秒後量 6 秒；非實機）

| 設定 | 重播（實驗世界 A1，預設視角） | 合成 100 隻 | 合成 1000 隻 |
|---|---|---|---|
| 桌面 1280×800 | **60.0**（品質 0） | 59.8 | 20.9 |
| Pixel 7 | **60.0**（品質 0） | 57.8 | 11.4 |
| Pixel 7＋CPU 4× 降速 | **29.1**（品質 2；p95 33 ms） | 4.7 | 2.2 |

- 目標：桌面 ≥ 55、Pixel 7 ≥ 50、4× 降速 ≥ 30。重播：桌面與 Pixel 7 達標；4× 降速 29.1，**略低於 30**（數值隨執行波動）。下一日的引擎物件精靈與光線疊層在當日 60% 時預先建立（`prepare`），濕日改為每幀加暗，換日不再重烘地面。
- **合成 1000 隻是已知限制**：每隻螞蟻是旋轉貼圖（陰影改為批次橢圓後仍約 1000 次旋轉貼圖），軟體繪圖下遠低於目標。預先旋轉的圖集或 WebGL 需另行決定與量測。
- 地面接縫與週期檢查（同一測試頁、只畫地面）：分塊邊界的亮度跳變不大於一般相鄰欄的第 99 百分位＋0.2，且週期重複的相對振幅 ≤ 0.04；四組（桌面／Pixel 7 × 預設／全景）都通過（`results.json` 的 `seams`）。
- 畫質階梯（只往下、不回升）：1 關反光與小裝飾 → 2 DPR 1 → 3 關螞蟻陰影；依最近 60 幀第 75 百分位 > 20 ms 判斷，烘焙後的幀不計入。
