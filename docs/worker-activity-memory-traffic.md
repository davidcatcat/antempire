# 《螞蟻帝國》v2｜休息、勞動分工、個體學習與蟻道交通

**2026-11-01科學規格，從Day6啟用**；本巢14隻工蟻的個別精確生理年齡、疲勞、活動率、知識範圍和工蟻形態並未量測。不能倒填Day5的行為。

## 1. 閒置與備援工蟻不是永遠無事可做
- `Temnothorax rugatulus`實驗移除活躍工蟻後，一部分原先不活躍工蟻提高活動來補缺 [R106]。這是**其他物種**，不等於本P. megacephala必須固定保留20%工蟻或一週內填補所有工作。
- 各工蟻有`rest_or_inactivity`、`fatigue`、`task_history`、`time_budget`、`local_demands_perceived`，沒有實測時null。巢內W004等可能在育幼、梳理、自我清潔、休止間切換；**沒有當前活動事件的工蟻不必被塞一份新工作**。
- 工蟻工作由體況、傷勢、接觸刺激、育幼需求、食源可得性與巢穴問題形成自組織；「蟻后指派工作」與「為了玩家劇情把所有工蟻用完」都禁止。受傷工蟻若能工作亦不必強制臥床。
- **同一時間窗口只可擁有物理相容的活動**：採食、搬土、處理獵物、梳理、護蚜與休止不能把同一段分鐘數重複計入不同任務。

## 2. 學習與個體經驗
- 工蟻可能保留曾有收穫、曾遭危險、遇到熟悉地標或特定食源氣味的個人記憶，並在重訪時調整探索／迴避 [R109；亦見R79,R88]。記憶`strength`、`decay_rate`、`days_since_event`未校準則null。
- **W006歷史曾在F03附近遇外蟻，W015到過U00草根外緣**，這些只能作**既有質性個人經驗**，不可變成座標地圖或固定回避機率。其他未到場工蟻不自動得知該事件，須有真正接觸或物種適用招募。
- 危險、食物容量、陌生氣味與飢餓可能互相競爭，同一線索在不同時間有不同價值。一次失敗**不是永遠絕不再走**，一次找到食物也不代表那條路永遠有糖。
- 若發生新記憶事件，必記`owner_worker_id`、感官線索、場景`site_id`、時間、當時收益／風險、證據；不可用全局已知事件批次灌給14隻工蟻。

## 3. 交通與搬運／地表遮蔽通道
- `Linepithema humile`大型集體交通實驗能在擁擠時調整走速和接觸以維持流量 [R108]。這是**別的物種、數百至數萬隻實驗族群**，不代表本群14隻工蟻已嚴重交通堵塞或具相同數學流量曲線。
- 本物種大頭家蟻也會使用地表覆蓋覓食通道 [R95]：但建立`covered_gallery`需有既有地形、工蟻實際搬土／遮蔽材料、逐步形成的通道。沒有施工事件就不平空生成。
- `route_capacity_mm`、`flow_ants_per_min`、`speed_mm_s`、`queue_time_s`均null；可以定性描繪窄巷工蟻相遇／讓路／繞行，但不能把交通研究的效能當本巢已量測。
- 若大型獵物搬運卡住狹口，可能拆解、等候或放棄，與[nest-construction.md](nest-construction.md)的洞口實際幾何、[foraging-food-economy.md](foraging-food-economy.md)的運輸食物、[social-immunity-waste.md](social-immunity-waste.md)的清理對帳。
