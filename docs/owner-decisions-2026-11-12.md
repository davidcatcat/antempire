# Owner 正式授權：開發流程調整（2026-11-12）

本檔記錄 Owner 2026-11-12 的正式授權，除非 Owner 日後明確修改，否則持續有效。CLAUDE.md §0 已據此修訂。

## 一、授權內容

Claude 可以：
1. 自主分析需求、研究科學文獻、設計與實作功能。
2. 自主執行 Code Review、測試、修正與驗證。
3. 自主建立、處理與合併符合條件的 PR。
4. 不必逐張 PR 等待 Owner 或 Codex 核准。
5. 自主安排開發順序、拆分工作包與處理技術依賴。
6. 重新審查已存在的 PR，符合條件就直接合併。
7. 不得為了加速合併而跳過必要測試、忽略已知缺陷或降低科學標準。

## 二、角色

| 角色 | 職責 |
|---|---|
| Owner（使用者） | 產品願景、重大功能與方向、重大產品取捨；不逐張審批 PR，也不介入一般技術細節 |
| ChatGPT | PM 層級的提示、Roadmap 與優先順序、科學合理性與產品缺口分析，協助 Owner 判斷方向 |
| Claude | 主要開發與技術執行者：Code Review、測試、修復、整合、Issue、PR 與合併；主動推進已確認的 Roadmap；遇到重大產品決策時向 Owner 提問 |
| Codex | 不再是必要審查者；有特殊技術需求時可選擇性使用，不得形成固定阻塞 |

## 三、合併條件（每張 PR）

1. 程式正確性與架構一致性。
2. 科學模型、數學與物理規則合理。
3. 相關單元、整合測試及適用的 CI 全部通過。
4. 沒有引入已知回歸。
5. 維持可重現性與必要的守恆約束。
6. 沒有把未經驗證的假設寫成科學事實。

可以用獨立審查子代理做第二輪檢查，但不得變成永久等待關卡。未通過的 PR 先修復，不得強制合併。已知的 P1／P2 缺陷與依賴不因取消 Codex 審查而自動解除。

## 五、核心目標（不變）

以真實螞蟻行為、自然生態、數學、物理及化學模型為基礎，建立可視化的即時生態模擬遊戲。

- 環境獨立演化，螞蟻只依自身感知與局部訊號行動。
- 物理、移動、轉向、接觸與化學訊號互相整合。
- 支援持續模擬、存檔、載入、續玩與新開局。
- 交付目標是真正可觀看、持續活動的遊戲畫面。

科學驗證與可視化產品開發並行推進，不長期停留在研究、CLI 或文字報告階段。
