# LANE-FLOW：KIN-2D 身體＋目的地容量帳本的路段交通整合候選（#189、#193）

> **地位**：隔離物理實驗・整合**候選**（非本種行為、非正式）。`engine/physics/lane-flow.ts` 不被每日循環、Day0、`cli/`、`web/` 引用（`tests/physics-isolation.test.ts`）；它只呼叫既有的 KIN-2D（`runKinematics`、`runKinematicsWithContactMode`）與 #162 目的地帳（`runSiteLedger`），**沒有修改任何解算器**。golden 逐位元組相同。沒有推進遊戲日。
> **不宣稱**：本種沒有路段交通、巢口容量、讓路或接觸後反應的資料。所有容量、停留、速度、間隔都是候選邊界值（`assumption: true`、遊戲假設）。結果只說明「若這樣設定，物理與帳目上會發生什麼」。

## 1. 模型（裁示第 4 項：抵達者離開路段並登記目的地容量）

- 路段：x ∈ [0, 長度]，兩側牆 y = ±寬/2（細線段靜態物）。方向 +1 的個體由 x = 0 端進入（朝向 0），−1 由另一端（朝向 π）；s ＝沿自身方向的前進量。
- 運動：已出發、仍在路上的個體以自由速度直行（固定 twist，不轉向）；實際執行由 KIN-2D 接觸反應決定：
  - `stop`：kinematics2d.ts 的凍結反應（自身運動沒有明確拉開間距的身體停下）；沒有決策時鐘時保持到時間終點（KIN-2D 基準）；
  - `slow`：共用接觸約束（kinematics2d-contact.ts `project`）：在縮小間距的一方執行最接近指令的可行速度（跟在慢的前者後面＝前者速度，即 PH-3b 的跟隨規則）。
- 分段（epoch）：時間線切在每個出發時刻、每個抵達時刻與時間終點；段內指令固定、KIN-2D 計算精確。段內發現抵達就把該段重算到抵達時刻為止。接觸段與約束區間跨段縫合（`contact-classification.ts` 的紀錄格式）；KIN-2D 的接觸遲滯在段界重新開始（間距落在 (θ, θ + ρ] 的一對在段界結束，計入 `hysteresis_closes`）。
- **抵達**：s 第一次到達 `goal_s_mm` 的時刻。規則 `leave_to_ledger`：身體**在該時刻離開路段**（之後不再是障礙物），同一時刻向該個體的目的地送出一筆 `arrive`；由目的地帳決定進入／排隊／被拒、停留與釋出。排隊者在**路段外**等候（情境假設：二維平面上的排隊位置尚未決定，`docs/physics-destinations-traffic.md` §8）。因個體離開而結束的接觸記為 `end_is_physical: false`（不是分離，不能當原因）。
- `stay_as_obstacle`：PH-3b／WP4 原本「抵達者留在原地」的基準，**只作對照**。
- 守恆：每隻個體的狀態紀錄（`candidate-metrics.ts` 的 `AGENT_STATES`）由路段與帳目共同產生：在路上 → 排隊／在目的地／被拒 → 釋出。

## 2. 測試（`tests/k189-arrivals-ledger.test.ts`，阻擋性）

- `leave_to_ledger`：每次抵達恰在抵達時刻離開路段（之後沒有樣本、沒有運動），恰有一筆帳的 `arrive`；帳目事件通過 `validateSiteEvents`；每次轉換後守恆（在路上＋排隊＋在目的地＋已釋出＋被拒＝總數、只走允許的轉換）；帳目摘要：抵達＝進入＋被拒＋仍在排隊（沒有漏帳）。容量 1、停留 1 s、等候上限 1：逐筆確認進入／排隊／被拒。
- 慢前者＋快後者（`slow`）：接觸於 1.5 s，後者被約束成前者速度；前者 4 s 抵達離開後，後者自由走完剩下的 2.5 mm（4.25 s）。接觸因前者離開而結束（`end_is_physical: false`）。獨立間距稽核（由執行紀錄的閉式姿態重算）：0 穿透、0 漏接觸。`stop`：後者凍結到終點（KIN-2D 基準，無決策時鐘）。
- **反例** `stay_as_obstacle`：先抵達者留在原地，同目的地的後者撞上它、永遠到不了；同一情境改為 `leave_to_ledger`，後者 3 s 抵達、沒有任何接觸。
- 兩方向同一條線迎面：兩者都停（雙方都在接近時各自移除接近分量），不憑空讓路；守恆仍成立。
- 重跑逐位元相同、輸入順序不影響；起點重疊、容量未知、目的地不存在、體型未知都拒絕。

## 3. 基準情境（裁示第 5 項：依時間流入＋合理的初始空間分布）

- **進場控制**（`input.entry`）：個體在進場前不在路上（不被感知、不是障礙物）。排定時刻若進場姿態空著（與路上每個身體的膠囊間距 > θ）就**恰在排定時刻**進場；被占就在路外等（`waiting_entry`），於排定時刻 + k·`retry_interval_s` 重試（十進位精確）。同一時刻：先抵達離場、再進場；進場依排定時刻、再依 id。沒有 `entry` 時沿用 PH-3b／KIN-2D 慣例（所有身體從 t = 0 在起點姿態上）。
- **正常基準** `timedInflowScenario`（`engine/physics/lane-flow-benchmarks.ts`，參數檔 `scenarios/physics/lane-flow-benchmark.candidates.json`）：
  - 初始空間分布：t = 0 時已在路上的個體，從目的地側往入口排列，前後間距＝0.5 mm＋指數分布（平均 3 mm），橫向 ±0.6 mm 均勻；不重疊、不占入口姿態（放不下就拒絕，不會疊在一起）。
  - 依時間流入：每方向第 k 隻在 t₀ + k·0.5 s 進場（每秒 2 隻；十進位精確，`destinations.timedInflow`）。**流入率是遊戲假設**：本種沒有路線流量量測；與 #158 候選、WP4 K2／K3 相同。
  - 自由速度 17.0 mm/s（R133，本種實驗室沿跡、無相遇，作為輸入不是驗證）；體長 2.5 mm（R94）；碰撞寬 0.8 mm（候選上限）；目的地：巢口容量 2、停留 1 s、等候上限 20（#158 邊界候選值）。
  - 情境族群 `timed_inflow_comparison`：可做**候選之間**的比較（#158），仍不是本種行為。
- **極端／反例** `pointSourceStress`：1,000 隻在同一點、同一時刻（`simultaneous_entry_stress`，不得做行為結論）。有進場控制：一次只進一隻（入口姿態空出才進），1,000 隻全部在帳上；**沒有進場控制**：起點重疊 → 拒絕執行（這就是反例）。
- 測試 `tests/k189-inflow-benchmark.test.ts`（阻擋性）：產生器有種子、可重現、不重疊、時刻精確、每個數值有出處標籤；進場被占時於 0.05 + k·0.1 重試、恰在 0.35 進場，等待中沒有姿態也不是障礙物；正常基準（兩種接觸反應 × 種子 1–3，12 s）：守恆、不瞬移、帳目有效、獨立稽核 0 穿透 0 漏接觸、族群允許候選比較；1,000 隻同點：逐一進場、1,000 隻守恆、族群標示不可做行為結論；無進場控制被拒。
- 觀察：在這個正常基準中所有個體速度相同（本種沒有個體速度差異資料），單向流沒有追撞；跟隨者「減速」與「停下」的差異要在速度有差異的情境才會出現（裁示第 11 項的 A/B 另案，速度差異會明確標為遊戲假設）。

## 4. 決策時刻＝實際進場當下、只用當下局部訊號（裁示第 7 項）

- 決策層 `input.decision`（選用；不開時輸出逐位元組不變，測試以決策層出現前算出的 SHA-256 釘住 5 種設定，含有／無進場控制）。
- **個體時鐘**（#180）：錨點是個體的**實際**出發時刻（無進場控制：`start_t_s`）或**實際**進場時刻（有進場控制）；第一次決策就在錨點，之後在錨點 + k·`interval_s`（十進位精確）。時間終點不做決策（長度為零）。兩條路徑語意相同。
- **只讀當下的局部狀態**：決策函式 `decideGoUnlessOncoming` 是 `LocalView`（該時刻自己的姿態＋感知半徑內各身體的膠囊與朝向）的純函式；沒有歷史、沒有未來、沒有群體量。同一時刻的多個決策是一批，讀同一個狀態（先處理抵達離場、出發、進場，再決策）。
- **候選規則 `go_unless_oncoming`（遊戲假設）**：若一個**反向**行進的身體擋在前方（它的膠囊與「自己的膠囊往前掃過感知半徑」重疊）就等到下一個自身決策時刻，否則以自由速度前進；同向在前的個體不讓（跟隨），接觸後的力學由接觸反應決定。`stop` 搭配決策層時，停下的身體只保持到自己的下一個決策時刻再決定（不再凍結到終點）。本種沒有相遇讓路資料（R380 *Lasius niger* 讓路只作方向，非本種）。
- 測試 `tests/k189-entry-decision.test.ts`（阻擋性）：探針——迎面者在網格時刻 0.2 時在感知半徑外（1.5 mm），0.25 時擋在前方（0.5 mm）；在 0.25 進場（或出發）的個體恰在 0.25 決策、看到它而等待；同一規則若讀 0.2 的狀態會前進。因果：迎面者 0.25 之前的歷史、之後的計畫都不改變這個決策；0.26 才進場的身體在 0.25 看不到；半徑外不感知；後方與同向前方不造成等待。正常基準（雙向、種子 4）：每個決策的感知集合＝該時刻半徑內的身體（獨立重算，0 不符）；決策時刻＝錨點 + k·0.1 精確；守恆、0 穿透、0 漏接觸；輸入順序不影響。

## 5. 接觸後跟隨者 A/B（裁示第 11 項）

`slow`（減速到前者速度）與 `stop`（停下，到下一個自身決策時刻再決定）的比較、結果與已知問題（分段不變性未通過）見 [`physics-follower-ab.md`](physics-follower-ab.md)。輔助選項：`speed_variation`（基準產生器；個體速度差異，遊戲假設）、`chunk_boundaries_s`（只供診斷的額外段界）。

## 6. 尚未驗證／仍是假設

- 排隊者在平面外等候是情境假設；被拒者離開模擬範圍（記為 `turned_away`，不是消失）。
- 本候選不轉向、不讓路；身體只沿路段直行（裁示第 2 項的轉向主候選另案）。
- 段界的遲滯重設可能讓一個持續接觸被拆成兩段（計數公開）。
