## 1. 建置與開啟

**生態觀察器（`web/`，唯讀）**

| 步驟 | 指令 |
|---|---|
| 安裝 | `npm ci` |
| 建置（`web/src` → `web/dist`） | `npm run web:build` |

## 4. 畫面內容分類：引擎事實／顯示插值／模型假設

### 4.1 生態觀察器

| 畫面元素 | 分類 | 說明 |
|---|---|---|
| 事件時間軸的每一筆（採集、卸貨、交哺、招募、探索、發現、捕獵、停止覓食、死亡、產卵、羽化等）及其分鐘 | **引擎事實** | 原樣顯示引擎事件。沒有時刻的日終結算（死亡、羽化、產卵、發育）只放在「日終結算」格，不畫在某個分鐘 |
| 個體所在地點、當日任務摘要、行動序列 | **引擎事實** | 來自引擎的活動時間軸（地點 ID、開始與結束分鐘） |
| 工蟻在兩個紀錄點之間的位置、正在行走的動畫 | **顯示插值** | 只用於畫面，圖例標示「顯示插值」或外圈。不寫回引擎，也不產生事件。**這不是物理運動** |
| 地點的地圖座標、比例尺 | **模型假設（示意）** | 只有方位＋約距離，標示「示意，非測量」。沒有座標的地點放在「位置未記錄」框，不自行產生座標 |
| 費洛蒙路段的粗細 | **引擎事實（遊戲單位）** | 當日開始時的路段強度；不是化學濃度，一天之內不在畫面上衰減 |
| 每日統計（工蟻數、幼體、存糧、花園食源、氣溫與巢溫） | **引擎事實** | 日終紀錄原樣複製，不平滑。氣溫是模型輸入（合成或歷年統計），**不是量測** |
| 推得的行走速度 | **由引擎事實推得** | 路段長度（遊戲假設的約距離）除以引擎紀錄的走完時間；只是整段平均 |
| 「非正式」、「實驗世界」標示 | 標示 | 正式 Day14 與實驗世界不混在同一模式 |

**V5 截圖中看得到的真實引擎活動**（以 A1 種子 20270001 為例）：
- 追蹤 W005：出巢 7 趟、成功 4 趟，「出巢覓食→搜尋→採集→回巢→卸貨→巢內休息」完整序列；
- D13 W008 在 F01 多次採糖，每次份量都是引擎數值；
- 事件類別計數：覓食與採集 398、招募與交哺 254、探索 15、捕獵 6、死亡 5、產卵與發育 20、環境生態 20；
- 地點上的圓圈是當日在該地點發生的事件數。

### 4.2 物理播放

| 畫面元素 | 分類 | 說明 |
|---|---|---|
| 個體位置與動畫 | **引擎事實（解算器運動）** | 每一段是解算器在兩個事件之間的直線等速運動，兩端是解算器記錄的精確姿態；不是取樣插值，沒有平滑。瀏覽器檢查逐時刻比對誤差 ≤ 1e-9 mm |
| 接觸開始／結束、停止、跟隨（減速）、恢復、錯身（pass）、抵達 | **引擎事實（隔離解算器事件）** | 時間精確到微秒；點事件可跳到該時刻 |
| 身體大小（膠囊）、速度 17 mm/s | 規格值 | 速度是本種文獻量級（Vázquez 2020，限研究條件）；身體尺寸與碰撞寬度是模型約定 |
| 橫向位置 u、能否錯身 | **模型假設** | u 整段固定，由情境給定。錯身完全取決於給定的 u 與通道寬度，**不是生物決策** |
| 讓路、側移、掉頭、交叉口先後 | **尚未模擬** | 本種依據未知（null）；PH-3b 走不動就等待，到時間終點回報卡住 |
| 原生 PH-2 的讓路類事件（`native` 對照） | **候選規則（非本種）** | 他種文獻的候選機制，標示「原生的候選規則（非本種）」 |
| 側撞情境的 6,272 筆細碎事件 | 解算器真實輸出 | 側面滑過以分段等速近似，間距每打開 1e-7 mm 就重解，這是已知的數值特性 |

**物理播放不代表正式蟻群已採用這套移動。** 物理層沒有接入正式日循環，觀察器的螞蟻也沒有物理身體。

## 5. 驗收結論與缺口

**可以實際觀看的**：
- 個體追蹤、跨日切換、事件時間軸與跳轉、每日人口／食物／環境統計、手機版；
- 物理播放中的接近、身體接觸、停止、跟隨、等待、障礙阻擋、給定 u 下的錯身、恢復、抵達，以及逐事件重播。

**目前看不到，或不能宣稱的**：

1. **觀察器的時間仍是每日 360 分鐘活動時窗**，沒有日夜與 24 小時（P0-A 仍在進行）。
2. **觀察器的螞蟻沒有連續軌跡**：只有紀錄點之間的直線插值。物理播放與生態觀察器是兩個分開的頁面，物理沒有接入生態世界。
3. **物理播放沒有生物決策**：沒有本種依據的讓路與側移；碰撞不代表交哺、攻擊或招募。
4. **正式 Day14 只有快照**，不能播放。
5. **畫面上的營養與生命史反映現行模型**。現行模型的已知缺陷（C4 營養鏈上限、P0-B 發育與壽命）仍在，畫面忠實呈現這些模型輸出，不代表科學上正確。
