## C. 關鍵架構界線

```text
antempire/engine/              生態、個體、營養、局部決策（權威）
       |
       +--- 原生 PH-1/MV-1/PH-2 事件物理（現有，待事件修正）
       |          |
       |          +--- 合成物理實驗 replay（#96 Native 結果）
       |          |                   |
       |          |          Rapier 2D witness ──> PixiJS 實驗觀察器
       |          |
       |          +--- Rapier 真正獨立運動求解對照（#101，尚未做）
       |
       +--- 選定並科學審核後的 opt-in 實驗物理（#103，尚未做）
                         |
                 統一事件／時間／位置／守恆
                         |
                 web 觀察器（純讀／可替換 Canvas2D/PixiJS）
```

- **Rapier 不是螞蟻大腦**，不決定交哺、攻擊、招募、產卵、幼蟲發育；碰觸不是必然行為事件。
- **PixiJS 不決定生態**，只讀已記錄的 pose、motion interval、event，不創造、修改或重排物理因果。
- **同一單位與時間**：物理 mm、s、mm/s；舊路網 cm、分鐘，明示換算；native 解析事件時間與 Rapier 固定 time-step 不能無條件視為相等。
- **幾何 2.5D**：真實世界位置與通路寬度不明時保持 `unknown`。Rapier 2D 橫向碰撞不等於不同高度層可以互相碰撞；必須明示層間模型與高度來源。
- **原生物理已知新風險**：#98 於修正邊界時間後揭露 88/96 而非先前 96/96，這是反例，不是可以被調參刪除的負面資料。
- **參數完整性**：`null` 不代表 0、不代表可自行填預設值，候選值分清本種直接測量／非本種／一般生理／遊戲假設；任何生理／行為改動獨立 rules PR。
- **正式世界隔離**：Day1–14 歷史不可改、Day14 不變、不推 Day15、不在正式每日循環啟用物理，直到 Owner 在明確的規則更新 PR 授權。

## D. 驗收矩陣

| 測試面 | 檢查 |
|---|---|
| 科學與行為 | 只有個體局部接觸；事件時間因果；不由全巢統計決定個體行為；死亡／餵食不得因畫面添加 |
| 物理正確 | 無穿透、阻擋與等待有記錄；相同初始值／種子重播相同；時間窗／步長改變差異有量化 |
| 數值 | 解析 vs 固定步長；取樣漏判；候選寬度敏感度；2.5D 高度層的反例 |
| 效能 | 100／1000 隻物理 CPU／記憶體／事件數；100／1000／10000 繪圖物件的 GPU 畫面 FPS／p95 幀時間 |
| 遊戲呈現 | 手機／桌面真實瀏覽器測試；可開啟、有螞蟻移動、事件跳轉、個體追蹤、清楚標示實驗/正式/插值 |
| 不變量 | `npm run typecheck`, `npm test`, `npm run test:golden`, `npm run test:naturalism`, `npm run check:saves`，C2 帳本、physics isolation（直到正式規則 PR 調整） |
| 審查 | 每 PR 小範圍，固定 HEAD 的 CI + Codex 科學／工程審查；未通過不合併 |

## E. CI 與交付成本

- 每個 UI／Rapier 子專案以**範圍限定的 CI**完成對照與 screenshot，上傳 Artifact；不要重複安裝瀏覽器於無關任務。
- 現有主 CI／推送與 PR 的雙觸發情況先記錄，另案優化，不能為省錢關閉守恆、自然性及現有 regression checks。
- 先有可下載的靜態網站 artifact；如果要公開 GitHub Pages，需 Owner 明確同意部署範圍、資料公開方式與網址；不能偷偷發布。
- 任何新套件先核對實際版本、授權與依賴鎖定，再批准引入主專案；PR #96 的子專案目前採 `npm install`，應補 lockfile 以確保可重建。

## F. Owner 可看到的完成標準

第一個里程碑（T0）不是「研究完成」，而是 **能看到真正的雙蟻碰撞／等待／讓路錄像、能用手機和電腦打開主觀察器的最新 replay，並能查出每個動畫對應哪一筆引擎事件**。若尚無某種行為，清楚顯示「目前未模擬」，不可用漂亮動畫假裝已有科學機制。

第二個里程碑（T1）才是 **Rapier 自行解算後的證據對照**。只有測試證明它更適合哪些子問題，才分階段抽換。

第三個里程碑（T2）是 **正式生態時間軸之前的隔離 Day0 物理試行**；結果不得混入 Day14／Day15。
