- **零訊號**：在四個場景中，C（零訊號）的計畫與 B **逐位元相同**（75/75）。原因是數學上的：化學項 g_c·(c_L − c_R)/(c_L + c_R + floor) 在 c_L = c_R = 0 時恰為 0，而 C 與 B 用同一條具名亂數流。所以「C 在沒有訊號的場景」＝ B；C 與 B 的任何差別都只來自實際感到的訊號。
- **訊號存在**（人工路線）：75/75 的計畫與 B 不同；平均 |y| 3.50 mm（B 13.80 mm）；感到訊號的控制區間約 81%。這與診斷文件的結論一致（失去訊號時退化成 B）。
- **無訊號**：75/75 拒絕（`model C needs a (synthetic) field`）。
- 障礙場景的觸角接觸轉身是候選反應（模型 A／B／C 共用），不是本種量測；完成率 < 1 的個體在 15 s 內未到終點。
- 這些是**程式與物理結果**，不是生物驗證：本種在無化學訊號或障礙前的行為沒有可比的量測。

## 3. O-R133 觀測報告規則（Owner 決定 41）
- 主設定維持預先固定的 **h = 1 mm 代理**；敏感度 **0.25／0.5／2.5／5 mm** 一併報告。**不得**依模型輸出重新挑選門檻。
- 取樣間隔（C05：0.005 s 解析取樣）與中線死區（0.15 mm）維持不變。
- 每次都分開報告**轉回中線**（toward）、**離開中線**（away）與**越過中線**的次數（`docs/kin2d-model-c-diagnosis.md` §1 的「轉回／轉離／線上」與「越線數」欄）。
- 代理轉向數 **≠** R133 作者的人工判讀計數（判讀規則未公布）；報告一律寫「轉向（代理）」。
- 本分支沒有改任何門檻、取樣或死區；`docs/kin2d-r133-observation-operator.md` 與 `docs/kin2d-model-c-diagnosis.md` 逐位元組不變（測試比對 SHA-256），`docs/physics-kinematics2d.md` §8 的原始失敗紀錄也逐位元組不變（SHA-256）。
