# 螞蟻帝國：科學行為模型 v2
> 2026-10-31。這是**架空住宅花園的機制規格**，不是聲稱已觀測到真實蟻群。以群體行為為核心，參照 `docs/references.md`；物種未定，不得把單一物種的特性套用到所有螞蟻。

## 0. 設計原則
1. 蟻后是繁殖個體，不發布工作指令；玩家是觀察者，可變動環境／研究問題，不會直接控制單一工蟻。
2. 工蟻沒有永久職位。年齡、個體差異、飢餓、局部接觸頻率、探索經驗、傷勢與費洛蒙共同影響某項任務出現的機率。
3. 每個體僅知道自己接觸或感知的局部環境；不能全知「附近絕無敵蟻」。巢穴資訊靠接觸、氣味、帶回食物與活動路線傳遞。
4. 真正隨機的意外可發生，也可以整回合沒事；任何生產、療傷、羽化、交戰都需要前置條件與時間。
5. 研究結論區分「跨蟻種較常見」「特定物種觀察」「遊戲待校準假設」；不捏造精準存活率。

## 1. 蟻后 Q001
- 屬單蟻后、已交配、具繁殖能力之工作假設；實際物種尚未確認。
- 狀態：生命／受傷、營養儲備、體內水分、成熟度、卵巢活動、近期期產卵節律、交配後精子庫是否仍具功能（未知）、所在巢室、干擾／溫濕度暴露、工蟻餵食與梳理接觸。
- 行動：多在較適宜微環境休息、接觸工蟻、進食、產卵；初創期親自育幼可能存在，但已有工蟻後原則上更偏向繁殖。
- 繁殖是帶不確定性的**日尺度**過程，受營養、溫度、季節／物種、負擔及照護影響。禁止預設「每20分鐘產1顆卵」；未具物種參數時產卵率保持未知，依明示校準模型處理。
- 蟻后化學訊號是繁殖與群體狀態訊號，不是發布「去採糖」的命令。蟻后死亡不必立刻全巢死亡，但若無可替代繁殖個體，未來新工蟻補充將停止。

## 2. 幼體：卵、幼蟲、蛹
- 每個幼體需記錄獨立身分、發育階段、階段起算生理時間、營養供應、照料接觸、溫濕度、健康、成活狀態；可能有卵被移動或失敗，不能一顆卵瞬間變工蟻。
- 蛋白質／其他胺基酸對繁殖與幼蟲生長重要；糖類是成年工蟻的重要能源，實際取食比例受物種與資源品質影響。
- 早期分化的工作者與蟻群大小、生長季節、溫度與物種相關。以 `Lasius niger` 2023 實驗作**尺度示例**：首幼蟲約第18天、首蛹第25天、首工蟻到可走約第42天；**不是遊戲所選螞蟻的固定參數**。
- 巢內育幼位置依局部溫濕度與安全刺激改變；不自動假設每間育幼室功能永遠固定。

## 3. 工蟻與自主分工
- 個體資料：存活／齡級（未知可為 null）、體力、體水分、食物負載、可用肢體、傷口／感染風險、接觸刺激、嗅覺路線記憶、位置、當前任務、行動限制。
- 任務池：探索、採食、食物交換、幼體搬運與餵養、巢室清理、挖掘／搬土、屍體／廢棄物處理、巢口警戒、逃避。
- 任務以需求刺激與反應閾值抽樣，不是「W010永遠守衛」；健康工蟻可以在短期內改行，也可能因飢餓、警戒需求出現人力互相排擠。
- 年幼工蟻通常更偏向巢內工作，但不是必然；資源危機可能迫使年輕工蟻冒險。個體經驗與路徑熟悉度影響採集。
- 同伴接觸、食物量、氣味訊號可以產生正回饋招募；路線老化／蒸發、擁擠、危險與資源衰退提供負回饋。不要將費洛蒙當作遠距即時通訊。

## 4. 受傷、疾病及死亡
- 傷勢記錄部位、機制、發生時間、移動能力、開放傷口／感染證據、恢復進程及永久損傷；原本只有「前足擦傷」的敘事紀錄不得補造感染數值。
- 輕傷個體可能仍外出；嚴重受傷可能行動受限、死亡或在某些物種接受同伴照護；**不能統一安排病假／醫療部隊**。
- 成蟻缺肢通常不再生；傷口癒合與活動恢復另算。部分 `Camponotus floridanus` 或 `Megaponera analis` 具有特殊治療行為，**本無名物種預設不具截肢醫療**。
- 死亡原因包含捕食、巢內事故、飢餓／脫水、感染、衰老、爭鬥；須有事件因果，不能每次都保證0死亡，也不強迫每回合死蟻。

## 5. 食物、水與傳遞
- 資源節點分可利用量、實際補充速度、品質、腐敗、競爭者、可達路線、季節性、辨識可信度及搬運上限；不能無限重採已乾涸植物傷口。
- 碳水／蛋白質要分別追蹤**攝入、實際送回、分配與代謝**；需水量、蒸發與可用水源不可永遠省略。腹部貯液／口對口交換只在該類群合理時啟用。
- 採食決策需考慮收穫量與路程、暴露時間、風險、採集個體與留巢個體的能量成本；出巢未必有收穫。
- 既有「糖／蛋白質」是**不可與毫克等同的抽象遊戲單位**；未校準前只用於延續歷史資源，不宣稱有科學實測意義。

## 6. 蟻巢
- 巢室不是功能永久鎖定的建築；應追蹤幾何位置、承重穩定、濕度、溫度、氧氣／氣體交換、擁擠、廢棄物與入水風險。
- 挖掘需要實際工蟻活動及土壤條件，不採用固定「兩蟻每回合+20%」；防線降低部分風險但不能保證安全。
- 幼體可能因溫濕度轉移到不同位置；洪水、蟲害、人類澆水可能迫使巢修或轉移，但遷巢有成本及失敗可能。

## 7. 行為層級與可檢驗性
**外部環境 → 個體局部觀測 → 接觸／氣味互動 → 機率式任務調節 → 採集／育幼／防禦 → 能量與風險結算 → 環境反饋**。
每次模擬日誌需列出：實際觀察、推論、遊戲規則假設、隨機事件、個體狀態及資源收支。未知值使用 `null`，不偷填0。
