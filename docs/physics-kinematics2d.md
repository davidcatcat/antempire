## 1. 模型（只有物理與幾何）
- **身體**：剛性膠囊（與 PH-3a 相同契約）：沿朝向、長 max(0, L − w) 的線段向外膨脹 w/2。L = 2.5 mm（R94，文獻支持），w ∈ {0.5, 0.8} mm（候選範圍兩端，遊戲假設）。尺寸未知就拒絕，不預設。觸角與腳不在碰撞體內。
- **姿態** (x, y, θ)：身體中心與朝向。**碰撞體跟著 θ 轉動**（不是只轉畫面上的圖）。
- **運動**：分段常數的身體座標扭轉（twist）：前進速度 v、側向速度 vl（左正）、角速度 ω。扭轉不變時，中心走**精確的圓弧**，曲率 κ = ω / v；ω = 0 是直線；v = vl = 0 是原地轉身。基本動作：直線、定曲率圓弧、原地轉身、側移、停止、在絕對時刻重新出發。
- **姿態以解析解計算**：p(τ) = p₀ + R(θ₀)·[v·S − vl·C, v·C + vl·S]，S = sin(ωτ)/ω = τ·sinc(ωτ)，C = (1 − cos ωτ)/ω = τ·sin(ωτ/2)·sinc(ωτ/2)；|x| < 10⁻⁴ 時 sinc 用級數，ω → 0 連續、沒有 0/0。不逐步積分。
- **限制**（`checkLimits`）：最大速度、最大角速度、最大曲率、能否原地轉身、加速度、角加速度。值為 `null` 時**回報「未檢查」**，不假設。速度與角速度在分段之間瞬間改變，所以加速度與角加速度「未建模」，一律回報 unchecked。

## 2. 連續碰撞（含轉動）
- 對象：牆（線段，可有厚度）、圓、多邊形（邊＋起點不得在內部），以及其他身體（同一圖層）。
- **保守前進法（conservative advancement）**：在一段扭轉不變的區間內，核心線段上每一點的速度 ≤ M = hypot(v, vl) + |ω|·h（h = 核心半長），所以兩物體間距 g(t) 的變化率 ≤ M_A + M_B。每步前進 (g − λ)/M，**不可能越過水平 λ**。區間端點（任一方的分段時刻）一定停下重算。
- **保證**：回報接觸之前，對所有 t 都有 g(t) > λ = θ/2（θ = 10⁻⁷ mm，與 PH-3b 的 `ACTIVE_TOL_MM` 同大小；浮點捨入只多 M·ulp(t)/2 ≈ 10⁻¹⁴ mm）。回報的時刻 g ≤ θ。沒有時間步、沒有穿隧。
- **接觸時刻**：在最後一步的區間 [前一迭代, 迭代] 以二分法求 g = θ 的穿越（`bracket_s`，右端為 `t_s`）。限制：最後一步之前，若 g 曾進入 (λ, θ]（深度小於 5×10⁻⁸ mm 的擦過）又離開，不記為接觸——這是本方法的解析度，寫明。
- **接觸後的物理約束**（不是行為）：自身運動不明顯拉開間距（自身間距變化率 ≤ 10⁻⁶ mm/s）的身體**停住**，保持姿態到時間終點；明顯遠離的身體照計畫走。接觸中以較低水平 θ/4 繼續保守前進：間距超過 θ + ρ（ρ = 10⁻⁹ mm）記 `contact_end`；再被壓到 3θ/8 記 `repress` 並再套用約束。**螞蟻碰到之後做什麼（等待、後退、轉向、觸角接觸）本種無資料，不建模**；重新出發只能是計畫中明寫的分段。
- **時間契約**（沿用分層時間契約的原則）：時間終點 H 是長度 0 的處理時刻；t ≤ H 的事件處理，H 之後沒有運動；計畫分段時刻落在 (H, H + 8·2⁻⁵²·max(1,H)] 視為在 H（例：0.1 + 0.2）。分段時刻在建立計畫時一次算出，解算器不再累加時間。保守前進的步長與 H 無關，所以算到 H₁ 的結果是算到 H₂ > H₁ 的前綴（測試逐位元檢查）。
- **決定性與輸入順序**：成對以排序後的 ID 為鍵；同一時刻（16 ulp）的接觸一起處理，約束用處理前的速度判定（Jacobi），與陣列順序無關。成對結果快取到任一方改變為止。
- **掃掠占用**（`sweptOccupancy`）：取樣時刻的膠囊各膨脹 δ（δ = M·Δt/2 ≤ 指定誤差）。精確掃掠區 S 滿足 **S ⊆ ∪膠囊 ⊆ S ⊕ δ**（雙邊界）。

## 5. 獨立檢查器（`prototypes/kinematics2d-check/check.ts`）
不匯入 `engine/`；契約數值是複製的（測試確認相等）。只讀執行紀錄（分段起點姿態、扭轉、時刻）、靜態物與事件：
- 連續性（無瞬移、時刻相接、不超過 H）；
- 每一對的間距以區間下界 g ≥ (g(a)+g(b))/2 − M(b−a)/2 證明：接觸區間內 ≥ −10⁻⁹ mm（無穿透），接觸區間外 ≥ θ/4 − 10⁻¹¹ mm（沒有漏記的接觸）；證不出來的區間計為「未證」，不當成通過；
- contact_start 時 g ≤ θ、contact_end 時 g ≥ θ；時間終點時「貼著」必須有未結束的接觸，未結束的接觸不得已分開。

## 6. 文獻（R133）讀取紀錄
- **R133** Vázquez, Koehler & Pereira 2020, *Insects* 11(1):5, DOI 10.3390/insects11010005。2026-11-08 讀 PMC7022549 全文文字（MDPI 回 403）；**圖中數值未讀**。
  - 方法：同種腹部萃取物以沾筆畫在木橋中央；15×4 cm 測試段以 5×5 mm 鉛筆格點標記；錄影 30 分鐘、攝影機高 61 cm、幀率未寫；路徑轉描到方格紙；每物種 5 次試驗（每盒 400 隻工蟻）；每次最多計 15 隻、只計起點離中線 ≤ 5 mm 者。
  - 定義：**速度**＝完成 150 mm 的時間換算；**幅度（amplitude）**＝偏離中線的垂直距離（每隻取幾點、平均或最大**未說明**）；**轉向數**＝修正動作（左右轉離或轉向中線）的總次數；**忠實度**＝在中線 1 mm 內行走的距離百分比；準確度公式另有，文字擷取不完整。
  - 本種數值：速度 17.0 ± 0.39（去 18.5 ± 0.53、回 15.5 ± 0.54）mm/s；幅度 1.4 ± 0.06（去 1.1 ± 0.03、回 1.7 ± 0.11）mm——速度與幅度的 ± 依圖說是 **95% CI**；轉向 12.8 ± 0.25（± 為 **sem**，該句寫「big-headed ants」，未直接寫學名；去回程無顯著差異）；忠實度去程高於回程（數值只在圖中）。
  - 原文機制敘述：「一側觸角離開氣味空間時螞蟻轉回相反方向」、「在路線上呈之字形」——**沒有直接量測**觸角或頭部運動。
  - **限制**：實驗室人工路線 ≠ 自然地面；偏離幅度 ≠ 頭部擺動幅度；轉向數 ≠ 固定轉向頻率；平均值不得變成每隻固定規則；樣本數未逐方向報告。
- **Draft, McGill, Kapoor & Murthy 2018**, *J. Exp. Biol.* 221(22) jeb185124（PMID 30266788），*Camponotus pennsylvanicus*，**非本種**；只讀到摘要層級（bioRxiv 327379 摘要）：沿跡時左右觸角反相擺動、有「正弦」「探測」「沿跡」等取樣策略，左右觸角角色不對稱；去掉一側觸角會降低準確度。只用作模型 C 的**候選感覺運動機制**（雙側比較）。本文不分配 R 編號（避免與並行分支衝突），由協調者併入 `references.md`。
- 本種的觸角、頭部擺動、步態觀察：2026-11-08 搜尋一次，**沒有找到**。

## 7. 自然步行候選模型（`engine/physics/natural-walk.ts`）
控制器只用**局部**資訊：自身朝向與自己記得的行進方向、兩個觸角尖端的合成濃度（模型 C）、觸角尖端是否碰到障礙。不讀地圖、不讀其他螞蟻。控制器產生 KIN-2D 計畫（每個控制間隔是一段精確圓弧），**物理（碰撞、停止）一律由 `runKinematics` 判定**，控制器不能改碰撞紀錄。
- **A**：直線基準（ω = 0、等速）。
- **B**：時間相關的方向控制。ω = ζ − k_h·wrap(θ − θ_goal)，ζ 是 Ornstein–Uhlenbeck 過程（相關時間 τ、穩態標準差 σ），在控制時刻 t_k = t₀ + k·Δc **精確取樣**（ζ_{k+1} = a·ζ_k + σ√(1−a²)·N，a = e^{−Δc/τ}），區間內保持常數。不是每格獨立抽左右，也不是固定正弦波（測試：ω 的落後一格自相關 > 0.8）。k_h = 0 即探索。
- **C**：B ＋ 兩個觸角尖端的雙側比較：ω += g_c·(c_L − c_R)/(c_L + c_R + c_floor)。濃度場是**合成的**高斯脊（`synthetic: true`，不是費洛蒙模型；CHEM 尚未接入）。
- **障礙**：只經由觸角尖端碰觸感知；候選反應＝停止前進、原地往未碰觸的一側轉，直到兩尖端離開。
- **限制**：|ω| ≤ ω_max，前進時 |ω| ≤ κ_max·v（超出就截斷並計數）。測試確認每一段都遵守。
- **亂數**：每隻一條具名亂數流 `rng(hash32("${seed}|kin2d.walk|${id}"))`；起點另一條 `kin2d.start`。相同輸入＋種子＝相同輸出；增減其他螞蟻不影響這一隻。
- 參數（`natural_walk`）全部是遊戲假設，**在產生下列結果之前一次選定，沒有依 R133 調整**（`fixed_before_validation: true`）。

## 9. 姿態串流 `antempire.pose-stream.v1`（給顯示 PR B）
檔案：`prototypes/natural-walk/data/*.json`，由 `node prototypes/natural-walk/export.ts` 產生；`--check` 重新產生並要求逐位元相同（測試也檢查）。標示 **隔離物理實驗・非正式**。
```
{ schema: 'antempire.pose-stream.v1', scenario_id, label: '隔離物理實驗・非正式', seed, model: 'A'|'B'|'C'|'mixed',
  dt_record_s, params: { 名稱: { value, assumption: true, basis } }（mixed 時依模型分組）,
  agents: [{ id, model, samples: [{ t, x_mm, y_mm, theta, v_mm_s, omega_rad_s }],
             events: [{ t, kind, detail }], sensor_samples?: [{ t, left: {x_mm, y_mm, c}, right: {...}, synthetic: true }] }],
  obstacles: [靜態物（KIN-2D 格式）], chem_field: { synthetic: true, kind, polyline, sigma_mm, peak, label } | null, notes: [...] }
```
- `samples` 是引擎解析姿態在 `dt_record_s` 格點上的值（四捨五入到 10⁻⁹）；格點之間的畫面插值**不是物理**。事件時刻是精確值，不對齊格點。
- 事件種類：`start`、`arrive`、`antenna_contact_pivot`、`resume`（控制器），`contact_start`、`contact_end`、`stop_on_contact`、`repress`、`solver_status`（物理）。
- **頭部偏轉、觸角角度、步態不在物理輸出內**（顯示層負責，不得回寫）；`sensor_samples` 只是模型 C 的兩個合成感測點與合成濃度。
- 四個場景：
  1. `straight-vs-natural`：同一隻的 A 與 B 兩種候選，並排（不同圖層，互不碰撞）。
  2. `trail-following-C`：合成路線上的 C，含 `sensor_samples`。
  3. `exploration-B`：探索參數（較寬的相關轉向、無方向回正）的 B，12 s。
  4. `obstacle-turn`：前方有石頭（圓），觸角碰到 → 原地轉 → 繼續，到 x = 60 mm；身體碰撞由連續碰撞檢查，測試另以獨立檢查器確認無穿透。

## 10. 仍是假設、未知與待 Owner 決定
