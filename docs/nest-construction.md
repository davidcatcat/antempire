# 《螞蟻帝國》v2｜蟻巢挖掘、通道建設、育幼室、排水、通風與遷巢

> 科學研究整合日：**2026-11-01**，**Day6起實施**。遊戲場景是臺中市西屯區虛構花園，主巢N00為花盆土丘，舊N01石板下、N02草根高地早已放棄。舊敘事記錄N00 **2處育幼空間、1處儲藏空間、1道外圍泥脊防線**，全部保留；**不是已量過房間長寬或雨季防洪能力**。本次只升級規格，Day5時間120h不動。

## 1. 螞蟻巢穴是逐步形成的物理結構
- 工蟻在土中**實際啃挖、搬土、傳遞與棄置土粒**，才可能形成更長隧道或新巢室；每個挖掘活動消耗時間、活動能量、有限可出勤工蟻與局部空間。不能把「兩隻工蟻工作一天」直接當作新建完成25%。
- 巢穴結構隨工蟻人口與發育需求改變。Camponotus socius的巢穴總面積與工蟻量相關 [R69]；Formica pallidefulva的巢穴體積與工蟻量相關、巢增長可能由加新主軸或延長既有通道 [R70]。**其實測深度、R²及特定擴建形態不能直接當本主巢數值**。
- 2026年的Camponotus fellah研究發現**較年輕工蟻**在正常成長時可能較積極挖掘且傾向斜隧道，較年長工蟻可能挖垂直方向；巢室坍塌時不同年齡群都可能參與修復 [R74]。**現有W016、W017的實際生理年齡未知，僅保留故事幼齡描述，不能設定精確挖土速度**。
- 2023年火蟻狹窄地形研究：碰撞／擁擠可能產生分散式挖掘節律與「活動提高／隨後減少」，不用蟻后派工 [R73]。本蟻種不自動套該數值衰減函數。
- 工蟻工種不等於永久職位；挖土、搬土、育幼、警戒、覓食互相競爭時間，原有六隻傷蟻能力須按已知傷勢限制，不自動全員健康或永遠不能工作。

## 2. 土壤、水分與空間風險
- 太乾的土壤可能難塑形、鬆散，適度水分可增加某些蟻種挖掘能力，但**過濕或靠近積水層可能停止挖掘**：Atta vollenweideri濕度梯度實驗發現挖掘在中等濕度較好，最潮濕材料時反而下降；工蟻在有表面水層的情境中距界面約12mm停止上挖 [R71]。這是該試驗數字，**絕非本花盆必定留12mm**。
- 雨水、屋主澆水、花盆底排水、土粒孔隙、地表坡度、石板與草根，皆可能改變巢口或某巢室的水風險；**城市氣象預報0%降雨機率不能轉成巢內0mm水**。
- **先有近距訊號**：如果土粒確實滑落，工蟻才能接觸或感知；局部防水／補洞／搬卵與幼蟲反應不由全知「已知洪水」觸發。
- 物理變化需符合地圖：`site_id`（N00主巢等）、`from`、`to`、`material`、`worker_ids`、`time_window`、`prior_condition`、`action`、`actual_outcome`、`evidence`。沒有量測時`excavated_soil_mg=null`、`new_volume_mm3=null`、`tunnel_length_mm=null`。

## 3. 育幼室、儲藏室與生物學的「房間用途」
- 工蟻可在巢室內清潔、移動卵幼蟲或移動儲藏物；房間用途不是永遠不可改的建築配置。
- Acromyrmex lundi實驗顯示**先搬幼體到較合適的局部微氣候，之後會提高該處挖掘、形成新巢室** [R72]。但該切葉蟻研究也有真菌農業背景，**本未鑑定花園蟻沒有真菌田，不能複製其真菌室或「育幼必挖新房」確定性**。
- 微氣候必須分**巢外地區天氣**／**巢口表土**／**各育幼空間或儲存空間**：前者可用有來源觀測／預報，後兩者沒有測站時`temp_c=null, humidity_percent=null, free_water_ml=null`。若已知幼體遭水接觸可移動，但不能聲稱觀測到確切濕度或100%排水安全。
- 舊N00有兩育幼空間、一儲藏空間，但它們的**幾何容積、通道連接方式、現有佔用率**都未知；只保存為`legacy_story_known_qualitative`，絕不建立虛構厘米數。

## 4. 通風與氣體交換
- 地下巢穴工蟻與幼體都需O₂並排出CO₂；土壤孔隙、通道連通性、出口和氣體濃度梯度影響交換。
- Acromyrmex某些淺層或覆草結構的巢穴可利用風與熱對流改善通風，與垂直序列型巢穴不同 [R75]；Atta vollenweideri曾研究依巢內CO₂條件修築開口結構 [R76]。這**不能**推論N00主巢已有「自動通風煙囪」，也不能認定本群擁有特殊監測CO₂的行為。
- 可模擬`ventilation_risk_qualitative`，但因巢體深度、土孔隙、CO₂、O₂、氣流都未知，相關物理量應null，不能憑工蟻14隻就宣稱缺氧。

## 5. 建設與維修：先安全、後擴建
每20分鐘只是**狀態採樣窗口**，不是20分鐘自動+1%建築進度：
1. **環境先變**：土壤含水、地表水、土體穩定、溫度梯度、空氣交換、植物根系、外界掠食與其它昆蟲活動；未知值保留null。
2. **有局部可感知的刺激**：幼體附近擁擠、某處土粒鬆動、潮濕危險、可及的待清掃土、損壞坑洞；沒有實際接觸不能全巢知道。
3. **競爭任務**：工蟻依當下體力／年齡／傷勢／局部接觸及覓食需求，選擇清潔、短程修補、正式挖土、搬幼體、外出或休止；不能永久指定W013為「建築兵」。
4. **工序有次序**：找到可挖位置→觸碰與挖取土粒→形成可搬顆粒→搬運棄置→局部通道/巢室幾何有證據地改變→檢查是否安全可供幼體/成蟻使用。**搬了幾粒土≠新育幼室完成**。
5. **維修可以失敗**：土壤不合、工蟻太少、被雨水侵入、土粒坍塌、掠食者或競爭者打斷都可能停止工程。Day4／Day5只是短程巢口整理，不能倒推為正式新隧道。
6. **巢內人口與工程是雙向回饋**：幼體與工蟻增加→可能增加空間／通道需求；但建築投入佔用覓食與育幼人力，故可能降低資源採集或照護。若資源短缺、傷蟻受限，應允許**不擴建**。
7. **大災害**：洞口坍塌／積水→部分工蟻可能修復、緊急移幼體、或尋找替代巢址，但不能假定每次泥脊能防洪或每次能成功搬巢。
8. **遷巢不是瞬移**：需先找到可行新巢點、局部評估路線與天敵、陸續搬運幼體／蟻后和物資，可能死亡或中斷。Pogonomyrmex badius部分研究發現其巢可在較短時間重建，**不是本物種固定工程時限** [R77]。

## 6. 在N00建立可驗證的持續巢穴記帳
- `nest_geometry`：只先記已知**2育幼空間、1儲藏空間、1泥脊防線**，未知`room_volumes_mm3=null, tunnel_lengths_mm=null, entrance_count=null, subsurface_depth_mm=null`。舊N01/N02保留歷史廢棄。
- `chamber_conditions`：各室實際溫濕度、水、CO₂/O₂、地基穩定、可用容積與幼體數，未測量欄位null。位置與已知幼體位置可標`unconfirmed_exact_room`。
- `soil_material`：粒徑、含水率、黏聚性、砂／黏土比例、搬運載重、崩塌概率，全部缺測。
- `construction_activity`：Day5以前已有短程整理；**只設下一日事件模板**，沒有已發生新挖掘的紀錄。每次日誌記工蟻、微刺激、路段、搬運與結果，未知體積不可算完成百分比。
- `brood_room_placement`：可按接觸、微氣候與風險選擇已知安全的現有巢室，但沒有房間測量，**不因日夜溫差就全天自動搬幼蟲**。
- `engineering_resource_cost`：挖掘與搬土需工蟻時間、能耗和水分；與`foraging_economy`避免雙重計算能量，未知物理數量保持null。
- `migration_gate`：先找到候選點並有分散探查，再考慮搬家；原N01、N02是**過去棄巢**，不能因有名字就自動視為現在安全。

## 7. 定性與定量的界線
- **可確認**：誰搬土、從哪到哪、花盆邊曾局部澆水、是否看到新通道開口、是否確有坍塌、哪些幼體被搬進原有巢室。
- **不能確認**：巢土總重、每日挖掘毫克、地下幾公分、房間實際立方毫米、實際排水率、CO₂濃度、通風率、巢內溫度、塌陷機率、完工百分比。
- 若取得地形、土壤與個體體型可做工程量守恆：`removed_soil_mass = in_nest_transfer + outside_deposit + spill`（須同單位且紀錄土在各處的真實去向），`new_void_volume = excavated_volume - backfill - collapse`。現階段至少記**方向性的事件帳**，不是憑空給「升級+20%」。
