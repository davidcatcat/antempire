## 2. 模型選擇與理由

**選擇**：「單位（unit）」＝個體（n = 1，有 ID，精確狀態）或群組格（n 隻狀態相同的成員）。**同一條逐隻規則**驅動兩者：個體抽一次 Bernoulli，群組格抽 Binomial（或多元超幾何）計數。發育採**分布延遲（distributed delay）／boxcar train**：每個齡期 k 個子期，每子期每日前進機率由度日決定，齡期持續時間因此是平均為 `DD_stage` 度日的（離散）Erlang／負二項分布。

**理由**：
1. **精確可合併（lumpability）**：若一格內所有成員對每條規則都處於同一狀態，則以計數表示的馬可夫鏈與逐隻表示**分布相同**（R652 的 lumpability 概念；這裡是依構造成立，§6 以數值驗證）。因此 `exact` 模式的誤差只有蒙地卡羅雜訊；誤差只會來自**刻意的粗化**（合併儲備、加寬年齡格），而且可以量測。
2. **Leslie（R640）**只有年齡、步長固定，無法表達「溫度改變齡期長度」；**Lefkovitch（R641）**的齡期矩陣以幾何分布停留，齡期長度變異過大（k = 1 的特例）；以 k 個子期串接正是 Manetsch／Vansickle（R645、R646）的 Erlang 延遲、Goudriaan 的 boxcar train（R648）處理這個問題的方法。
3. **McKendrick–von Foerster（R642、R643）**是連續、決定性的偏微分方程；本原型以其**離散決定性投影**（`mean-field`：所有抽樣換成期望值）作為**對照參考**，不作帳：它不是整數、沒有 ID、不能升級。
4. **度日**（R650、R651）：線性度日是一般昆蟲生理學的標準近似；本原型只採用其**形式**，門檻與總需求是遊戲假設。非線性高溫抑制未模擬。
5. 群組個體（super-individual，R340）與 escalator boxcar train（R649）是另外兩條路；前者仍逐單位追蹤、後者是連續 i-state 的 cohort 方法，本原型取其「同狀態成員合併」的精神，未實作其數值格式。

## 3. 狀態

```
Unit { region, stage, sub, age (日齡或格號), id|null, n, reserve(總量), rkey(exact 時每隻儲備)|null, age_sum(總量), roster[{id, age}] }
LifeState { seed, day, res{age_bin_days, reserve:'exact'|'pooled', deterministic, newborn}, units, stocks, sinks, corpses, producers, retired }
```
- 單位鍵：個體 `#id`；群組格 `區|齡期|子期|年齡格|rkey或*`。每日結束時相同鍵的匿名格合併；儲存順序不影響結果（K6）。
- 已知 ID 只能留在**日齡格**（寬格拒絕 `ROSTER_NEEDS_DAILY_AGE_BINS`），名冊成員保存精確年齡。
- `pooled` 的分配規則沿用 OD-1：逐隻 floor 份額、最後一隻拿餘數（`shareSum`），整數守恆。

## 4. 每日順序（同一規則用於所有表示；`lifeDay`，原子操作）

0. 命令（依 key）：`promote`／`demote`／`migrate`（都要 `cause.driver_event_ids`）。
1. 流入：情境生產者 `producer:inflow:<區>` → `stock:<區>`（合成輸入）。
2. 進食：取食齡期中「儲備 + 一餐 ≤ 上限」者；餐數 = min(合格數, ⌊存量/一餐⌋)；誰吃到以均勻抽樣（多元超幾何）。
3. 維持代謝：每隻燃燒 `burn` → `sink:respiration`；不足者為「飢餓」。`pooled` 格採**平均分配假設**（全格同飽同餓）。
4. 繁殖：未飢餓且儲備 ≥ `egg_cost` 的成蟲以 `p_lay` 產一卵，儲備 `egg_cost` 轉給卵（`birth` 紀錄附親代）。
5. 發育：§2 的 Erlang 子期；最後一子期前進即齡期轉換（`transition`，質量隨個體轉帳）。
6. 死亡：基礎危險率 + 飢餓 + 成蟲老化（年齡超過起點後線性增加）；屍體質量留在區內（`corpse`），ID 退休。
7. 老化：**所有存活成員**（個體、名冊、匿名）年齡 +1；一筆 `aging` 紀錄寫數量與年齡總和前後值。
8. 合併、排序。

## 5. 稽核（`lifetime-audit.ts`，不呼叫步進程式）

| 不變量 | 內容 |
|---|---|
| L1 形狀 | 數量、儲備、年齡總和為非負整數；個體 n = 1；日齡格 `age_sum = n·age`、名冊年齡＝格年齡；無重複 ID；無「既存活又退休」 |
| L2 數量 | 每（區×齡期）：期初 + B − D + I − E + Ti − To = 期末 |
| L3 質量 | 每個帳戶（存量、各區各齡期體內、呼吸、屍體、生產者）期初 + 紀錄轉帳 = 期末；全世界總量不變 |
| L4 生命時間 | 每日**恰好一筆** `aging`；其數量 = 期末存活數；年齡總和增加 = 數量；老化前總和 = 期初 − 死者年齡總和；期末總和 = 紀錄值 |
| L5 身分 | 新 ID 只來自出生或抽樣升級（且從未出現、未退休）；名冊升級保留 ID；死亡才退休；不復活 |
| L6 逐 ID | 每個已知 ID 一天正好老一天；齡期與子期不倒退 |

故意破壞的版本全被抓到（K2、K4）：格子不老化（＝把 PR #126 行為移植過來）、偽造 `aging` 紀錄去配合凍結的格子、刪掉 `aging` 紀錄、名冊年齡凍結、復活、重複 ID、成員無紀錄消失、無紀錄出生、儲備漏失、發育倒退。

食物消耗在 rich／scarce 兩個情境中，所有表示都把每日流入吃光（14 400、3 600），**這個指標分辨不出表示的差異**；差異出現在食物如何分到個體（呼吸量 pooled +1～3%，z 5～25）。

**何時群組模式會偏離（模型結果）**：
1. `cohort-exact`（日齡格＋精確儲備）：45 個比較中 |z| 最大 2.4，與逐隻**分布一致**（符合可合併性）；K7 以 8 個種子、30 日再檢查（|z| < 4）。
2. `cohort-pooled`：偏離出現在**食物限制**下。scarce 從前 30 日就偏離（K7）；rich 的前 30 日（族群仍小）誤差在雜訊內（K7），60 日時偏離；出生 −13～−14%、飢餓死亡 −14～−18%。原因：飢餓門檻、進食上限、產卵門檻都是**非線性門檻**，平均分配假設把「有些吃飽、有些挨餓」換成「全格同一個平均值」（Jensen 不等式）。
3. `cohort-coarse`（7 日格）：再加上老化的類別轉移擴散，老化死亡年齡偏早（rich −2%，z −3.4）、小族群偏差最大。
4. `mixed`（1/3 個體＋pooled 格＋每 5 日升降級）：偏差與其中 pooled 成員比例相當；升降級本身守恆（K3），但升級時 pooled 儲備只能以平均（floor 份額）恢復。
5. `mean-field`：小族群（tiny）最差（期末卵 −71%），各情境都低估族群；決定性投影不能代表人口隨機性與離散的分配。
6. 結論（模型層次）：要讓背景生物群組與逐隻**分布一致**，對規則有門檻作用的生理變數（此處是儲備）必須是格鍵的一部分；只存總量是可量測的近似，偏差在食物限制下達 10～20%。

- **相機不改命運**只做到「升降級觸發不讀相機」；不同表示的**亂數路徑不同**（個體以 ID 為鍵、格以格鍵為鍵），所以同一個種子下升級與否會改變具體實現，只保證**分布**一致（`exact`）。若要求路徑層級不變，需要每隻都有可推導的亂數鍵（等於放棄匿名），請 Owner 裁示。
- 寬年齡格不能保存已知 ID；是否允許「降級即放棄 ID」（目前不允許）。

**需要文獻或資料**
- 任何真實背景物種（蚜蟲、介殼蟲、其他昆蟲）的度日門檻、齡期度日、k（或齡期長度變異）、危險率、繁殖：都是 `null`／遊戲假設，必須逐物種查文獻並標**非本種**。
- 高溫下發育率下降（非線性度日）未模擬。
- 屍體帳 `corpse:<區>` 只累積，分解與食腐者沿用 OD-1 §5 的候選（`decay.ts`），速率未定，未在本原型套用。
- `pooled` 的「平均分配假設」可換成保存儲備直方圖（每格分幾個儲備級）；其誤差與成本尚未量測。
