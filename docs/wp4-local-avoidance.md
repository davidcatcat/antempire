# WP4：局部避障與讓路——候選行為模型隔離比較

> **地位**：隔離物理實驗・候選行為規則（非本種/假設）。`engine/physics/local-steer.ts` 不被每日生態循環、Day0、`cli/`、`web/` 引用（`tests/physics-isolation.test.ts`、`tests/wp4-local-steer.test.ts`）；`engine/physics/solver2d.ts`（PH-3b）沒有任何修改；沒有推進遊戲日、沒有改存檔或日誌。所有情境都是合成世界（`synthetic: true`）。
> **不宣稱**：大頭家蟻屬沒有任何窄道交通、迎面相遇、讓路或側移研究（見 `scenarios/physics/pheidole-megacephala.interaction-candidates.json`）。下列候選都**不是本種行為**，比較結果只說明「若螞蟻這樣決策，物理上會發生什麼」。抵達率**不是**選擇標準；由 Owner 決定。

## 1. 候選

| id | 名稱 | 規則（只用局部訊號） |
|---|---|---|
| `none` | 基準 | 直接呼叫 PH-3b `solve2D`，輸出原樣（u 固定、沒有決策）。測試確認與 PH-3b 逐項相同 |
| `A_free_direction` | A：選擇可通行方向 | 每個決策時刻，在候選方向（0、±15…±90°）中挑「感知半徑內走得通」且最朝前的方向；左右都通時以命名亂數決定；都不通就等。無記憶，不後退 |
| `B_contact_decision` | B：接觸後等／退／繞 | 前方沒有阻擋就前進；同向同伴在前就跟隨；碰到（感知到）擋路的同伴時，抽一次：等待 `wait_s`、後退 `back_distance_mm`、或繞行（最多 `reroute_max_s`）；靜態障礙物一律繞行 |
| `C_sidestep` | C：有空間就側移錯身 | 前方被擋且旁邊有空間時，選一側（命名亂數，整個相遇維持同一側，該側封閉才換邊）斜向／側向平移，直到前方通了；沒有空間就等；同向同伴在前就跟隨 |
| 規則 D（A–C 共用） | 幾何不可通過：停下或回報 | 在 `stall_window_s` 內前進 < `stall_progress_mm` 就發出 `blocked_report`，附局部診斷：`too_narrow_for_two`（兩側牆都在感知範圍內、局部寬度 < 兩隻寬度和）、`blocked_by_nestmates`、`static_ahead`、`way_ahead_free`（停是自己的等待／後退）、`static_closed`（靜態幾何封閉所有方向 → 永久停下）。B 在 `too_narrow_for_two` 時不繞行 |

**不預設**靠左／靠右，也不預設一定有一方讓路：左右由每隻自己的命名亂數決定；B 兩隻各自獨立抽，可能都等、都退或都繞。

## 2. 共同設定

- **感知（局部）**：只看自己身體間距 ≤ 感知半徑的身體（膠囊與身體軸方向；**不含**對方速度、目標或意圖）與靜態幾何（牆、障礙物），以及身體接觸。「方向 d 走得通」＝把自己的膠囊沿 d 平移一個感知半徑，對**原地不動**的已感知身體與牆做精確連續碰撞，沒有碰到。沒有全圖、沒有群體量。
- **決策時刻**：共同網格 k·`decision_interval_s`（加上各自的出發時刻）。決策只讀該時刻的狀態與命名亂數（種子、規則、個體 id、決策序號），與陣列順序無關。
- **物理**：沿用 PH-3b 的膠囊（體長 2.5 mm：R94 文獻支持；碰撞寬 0.8 mm：候選上限，遊戲假設）與精確連續碰撞（`pairFirstHit`）。兩個決策時刻之間每隻直線等速平移；遇到靜態幾何、目標或另一身體（**朝對方移動**的那隻，法向判斷）就在接觸時刻停下，Jacobi 反覆到停止時刻不再改變（與順序無關）；不收斂就該區間全員不動（安全退路，計數 `fallback_intervals`）。已接觸、相對速度極小的滑動以 `boundedHit` 判斷「本區間內是否真的穿透超過 1e-10 mm」，避免把無限遠的穿透當成立即碰撞。
- **抵達與時間終點（與 PH-3b 一致）**：PH-3b 處理所有 t ≤ `horizon_s` 的事件，所以抵達的定義是「前進座標到達目標的第一個時刻 t ≤ 終點」，只記一次：區間內、恰在決策區間終點（含恰在時間終點）、或出發時就在目標上（剩餘距離 0，於出發時刻抵達）都算；超過終點才到達則不算。已知差異：出發時刻恰好等於 `horizon_s` 的個體在候選中不出發（PH-3b 會在終點時刻出發）。區間終點的判斷容許 `GOAL_TOL_MM` = 1e-12 mm 的浮點捨入（時間格 k·dt 有捨入）。（R13-05 修正：原本恰在區間終點到達時永遠漏記。）
- **接觸的開始與結束**：接觸在某隻被另一身體擋停、且停下時刻兩者間距 ≤ `CONTACT_TOL_MM`（= PH-3b `ACTIVE_TOL_MM` = 1e-7 mm）時開始；停止時刻若是依對方「原本計畫」路徑算出、而對方自己更早停下，兩者其實沒碰到，不記接觸。接觸結束＝間距**第一次超過** `CONTACT_TOL_MM` 的時刻，由兩隻在該區間內的分段等速運動精確求解（每一段上間距對時間是凸函數，二分法），因此結束時刻不會早於拉開間距的那段運動開始。（R13-06 修正：原本把結束時刻倒填到區間起點或接觸開始時刻。）
- **幾何約定（遊戲假設）**：身體軸維持與通道平行；選的方向是平移（前、斜、側、後），速度＝自由速度。不建模轉身。只處理直線通道（有轉折的通道拒絕）。通道兩端也當牆（候選可以後退）。抵達的個體留在原地成為障礙物（與 PH-3b 相同）。

## 5. 失敗情境（保留，不隱藏）

1. **窄道迎面（head-on-2、corridor-8）**：A、C 都正確回報 `too_narrow_for_two` 並停下等待，到終點互卡（沒有後退規則就不可能解開）。B 靠隨機後退有時解開（5 個種子中 3 個有抵達），但也常出現兩隻輪流後退、再相遇的來回（`way_ahead_free` 回報多數來自這種自己後退的停頓）。corridor-8 的 B 連一隻都沒抵達：可能原因（未逐一驗證）：後退的那隻很快碰到背後同向的同伴而停，鏈狀後退沒有建模。
2. **交叉口同時抵達（crossing）**：A、C 兩隻都選了「相同的絕對方向」（E 往左、N 往右，都往東北），貼在一起斜走直到碰到各自的通道邊，在角落互卡（5 個種子都一樣，因為兩隻對稱，第一次就同時決定）。這是無記憶、無後退規則的結構性失敗，不是數值問題。
3. **100 隻交叉口**：A 抵達最多（45–73），但互卡群仍有 19–52 隻；C 因為「跟隨同向同伴、不超車」，被擋住的整列一起停，互卡最多（60–71）；B 抵達最少但互卡較少，有不少個體在等／退的循環中（仍在移動）。
4. **1000 隻交叉口**：四個候選全部 0 抵達、1000 卡住。格狀起點（橫向 1.2 mm、縱向 3.0 mm、距交叉點 20 mm、四個方向各 250 隻）在交叉口完全塞住；任何只靠局部側移／等待／後退的候選都解不開。與 PH-3b 相同，**這是情境密度的結果，不是生物學結論**。CPU 是 PH-3b 的 30–60 倍（A 170 s）：探測方向數 × 感知到的鄰居數 × 精確連續碰撞。
5. **石頭**：沒有其他個體時 A 一定繞過；B、C 有 2–3 個種子中一隻在石頭邊被另一隻擋住而卡住（`blocked_by_nestmates`）。
6. **滑動事件**：PH-3b crossing-flank 的 6,272 個細碎滑動事件，在候選中只剩 9–15 個（決策時刻是共同網格，接觸是非彈性停止）——但這是以「接觸後停到下一個決策時刻」換來的，碰到的個體最多會停 `decision_interval_s`。

## 6. 驗證

## 7. 需要本種證據或 Owner 決定

1. **本種證據（全部缺）**：大頭家蟻工蟻是否側移、讓路、後退，相遇時的反應機率與等待時間，觸角感知距離，決策頻率，轉身與倒退行走——全部 null。要能選候選，至少需要本種在窄道（< 2 體寬）與寬道迎面相遇的錄影計數（反應類別與比例），以及同向跟隨是否超車。
2. **Owner 決定**：(a) 是否接受「身體軸平行通道、側移是平移」這個幾何約定，或先做轉身／曲線行走模型；(b) 後退時撞到背後同伴的鏈狀後退要不要做（interaction-candidates 的 `chain_back_out` 是遊戲假設）；(c) 抵達的個體是否該離開通道（現在與 PH-3b 一樣留在原地擋路）；(d) 1000 隻的格狀起點是否是有意義的測試（目前四個候選都 0 抵達），或換成依時間流入的情境；(e) 候選之間比較時看哪些指標（抵達、互卡、事件數、CPU、可解釋性），本文件不做選擇。
3. **未解缺陷**：A、C 在對稱相遇（crossing）結構性互卡；1000 隻 CPU 90–170 s；同一決策網格讓所有個體同時決策（同步是數值選擇，不是觀測）；共同裁判 1000 隻未跑（只跑獨立驗證器）。
