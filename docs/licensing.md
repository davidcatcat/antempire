# 授權狀態與第三方程式碼使用規範（2026-11-02）

> 本文件不是法律意見；只記錄專案的現況與工作規則。授權的最終決定由 Owner 做（統一需求 §10 D6）。

## 1. AntEmpire 自身的授權狀態
- **目前沒有授權檔**（repo 沒有 `LICENSE`；`package.json` 標 `"private": true`，沒有 `license` 欄位）。
- 依著作權法的預設，**所有權利由著作權人（Owner）保留**：他人未經授權不得複製、修改或散布本專案的程式與文件。
- 選擇授權會影響可以借用哪些第三方程式（§3）。常見選項（由 Owner 決定，Claude 不自行加入授權檔）：
  | 選項 | 意義 | 對第三方程式的影響 |
  |---|---|---|
  | 維持未授權（保留所有權利） | 他人不能重用 | 只能使用寬鬆授權（MIT、BSD、Apache-2.0 等）的程式，並保留其聲明；不能納入 GPL 程式後再散布 |
  | 寬鬆授權（MIT、Apache-2.0） | 他人可自由重用 | 同上 |
  | GPL-3.0（或相容的 copyleft） | 散布的衍生作品須以 GPL 釋出原始碼 | 可以納入 GPL-3.0 程式 |
- 文獻資料、科學數值與演算法概念不是程式碼；引用方式見 §4。

## 3. 第三方程式碼使用規範
1. **先查授權，再看程式**：沒有授權聲明的專案（例如 docxology/ant-pheromone、SimulAnt）只能閱讀與學習概念，**不得複製程式**。
2. **寬鬆授權（MIT、BSD、Apache-2.0、ISC）**：可以使用，但要保留原著作權與授權聲明；Apache-2.0 另須保留 NOTICE 並註明修改。
3. **GPL／AGPL／LGPL**：GPL-3.0 **允許**重用、修改與散布（含商業用途），條件是散布衍生作品時整體以相容授權釋出原始碼。在 Owner 決定授權前，**不把 GPL 程式碼納入 repo**；概念與演算法可以自行重新實作並在文件中註明出處（例如 anthill 的圖層開關、檢視器想法）。
4. **CC BY-NC／NC-SA**（例如 NetLogo 模型庫的部分模型）：限非商業、須標示、NC-SA 須相同方式分享；在用途未定前不納入程式。
5. **紀錄**：任何第三方程式、資產或資料加入 repo 時，在本文件 §2 新增一列（名稱、版本、授權、來源網址、用途），並在同一個 PR 說明。
6. **依賴版本固定**：`package-lock.json` 固定版本；新依賴要說明理由。引擎維持無執行期依賴（平台純度測試）。
7. **美術與字型資產**：只使用授權明確允許的資產，並記錄來源；不使用來源不明的圖片。
