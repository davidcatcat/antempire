# 《螞蟻帝國》｜熱帶大頭家蟻覓食招募費洛蒙的證據更正

**更正日期：2026-11-01，適用下一次Day6。** 這是科學推論的更正，**不是**修改Day1–Day5既有敘事事件。

## 實驗和模型要嚴格分層
- 2009年Dussutour等 [R96/R21] 對本物種覓食的實驗資料**符合**一個由「探索招募訊號」與「食物採集招募訊號」構成的**雙費洛蒙模型**。**符合模型 ≠ 已經證實兩種不同化學訊號分子各自存在**。
- 2023年[R102]在`Cognitive Systems Research`發表另一**單一費洛蒙＋感知決策機制**的模型，能重現先前某些關鍵Y型迷宮經驗資料；研究強調應比較**可競爭的模型**。**這也不等於單一模型被唯一確證**。
- 模擬中的確定事實：**Pheidole megacephala有費洛蒙參與覓食招募的行為證據**；可分辨「探索／收益高」等行為情境，但**特定的招募費洛蒙物質種類數量、化學組成、濃度、時間衰退與受體門檻仍未知**。
- 本回合**不強行固定兩個化學channel**：`competing_hypotheses=["single_pheromone_plus_decision","dual_pheromone"]`，`confirmed_distinct_recruitment_chemical_count=null`，`selected_chemical_component_hypothesis="undetermined"`。
- 引擎可模擬**定性、局部、會衰退的招募線索**，是否產生必須有該工蟻真實行動和收益／地點、物理媒介／接收者。不可因R96就固定生成一條「長時探索」和一條「短時食物」線。
- **警戒費洛蒙是另一個行為情境**；本種捕獵研究[R98]支持與大型獵物相關的局部警戒招募，但不能將警戒與路徑化學成分強制設成相同或完全不同化學分子，除非已有分子鑑定。
- 既存Day5的F01弱訊號都是質性歷史線索，沒有精準濃度，不能倒填「雙訊號已經發出」。
- 對先前物種文件、訊號文件、覓食文件或README裡用「已確認雙費洛蒙」的句子，**本更正為最新權威**。專屬配置應同步調整，舊研究記事仍保存為當時的決策史。
