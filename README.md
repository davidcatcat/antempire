# 螞蟻帝國｜Ant Empire

這個 Repository 專門保存文字模擬遊戲《螞蟻帝國》的**遊玩進度**，不是程式碼開發倉庫。

## 目前進度

- 場景：住宅花園 → 石板底下築巢
- 蟻群：黑色地棲型螞蟻
- 第一章：午後雷雨，育幼區成功遷至高處，四隻初代工蟻誕生
- 第二章：玩家已選擇「優先尋找食物」，等待後續事件推演

## 存檔檔案

- [主存檔](saves/main.json) — 最新狀態與待續內容
- [遊戲紀事](journal/chronicle.md) — 按章節記錄的故事
- [存檔規則](docs/save-rules.md) — 更新流程、資料可信度及版本回溯

## 續玩方式

在聊天中說「繼續螞蟻帝國」，先讀取 `saves/main.json` 及 `journal/chronicle.md`，從尚未結束的事件接續。玩家做出選擇、劇情結算後，將新結果寫回本 repo。

**玩家決定關鍵行動；敘事可隨機演化，但尚未發生的結果不可預先記為歷史。**
