# 螞蟻帝國｜Ant Empire
**臺灣臺中市西屯區的一棟虛構獨棟花園別墅裡，一個小型地棲螞蟻群體的科學啟發式生態模擬。年月日與地區天氣引用真實資料。**

本 Repository 是**遊戲世界與進度資料庫**，不是程式碼專案。

## 2026-10-31：全世界模擬 v2 上線（規格／存檔架構）
由舊版「玩家控制W005、每20分鐘抽到事件A/B/C/D」轉型為**蟻群自主運作、環境先行、物種未知參數誠實標註**的觀察式模擬。

- 蟻后負責生殖，不指揮工蟻；工蟻工作由局部訊號與個體狀態自發調節。
- 幼體按生物尺度（日／週）發育，不再每20分鐘孵化／羽化。
- 蟻巢、植物與蜜露、掠食者、競爭蟻、腐屑、土壤、微氣候、人類干擾成為同一個動態生態世界。
- 受傷工蟻可能持續工作、恢復或死亡；不自動變成「固定護理兵」。
- 不再強迫每回合四選一；玩家可純觀察，也可提出環境干預或研究目標。
- **重要限制**：蟻種尚未鑑定，模擬是基於研究的機制設計，**不是已校準的科學定量預測**。

## 如何繼續
在 ChatGPT 說**「繼續螞蟻帝國」**或**「模擬一天，觀察蟻群自然發展」**：
1. 先讀 `saves/main.json`、`saves/world-state.json`、`docs/weather-data-policy.md` 和 v2 規格；每次推進重新查該日西屯真實氣象資料。
2. 從目前科學世界 Day5 繼續推進，**預設一次1個生態日**，短期採食與慢速幼體發育分開計算；不要求使用者逐隻指定工蟻。
3. 依最新食物、訊號、階級、**蟻后產卵與逐階段幼體發育、巢穴實際挖土／微氣候**規格產生有因果的模擬，允許零事件／死亡／找不到食物，未知量維持null。
4. 寫當日紀事、更新兩份狀態並核對。**不會在聊天之外自動執行。**

若只想觀察：「檢查蟻后」、「查看傷蟻」、「列出根際蜜露點的競爭者」，可不推進時間直接閱讀狀態與分析。
