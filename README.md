# 螞蟻帝國｜Ant Empire
**臺灣臺中市西屯區的一棟虛構獨棟花園別墅裡，以熱帶大頭家蟻（Pheidole megacephala）作主角的小型蟻群科學啟發式生態模擬。年月日與地區天氣引用真實資料。**

本 Repository 是**遊戲世界與進度資料庫**，不是程式碼專案。

## 2026-10-31：全世界模擬 v2 上線（規格／存檔架構）
由舊版「玩家控制W005、每20分鐘抽到事件A/B/C/D」轉型為**蟻群自主運作、環境先行、物種未知參數誠實標註**的觀察式模擬。

- 蟻后負責生殖，不指揮工蟻；工蟻工作由局部訊號與個體狀態自發調節。
- 幼體按生物尺度（日／週）發育，不再每20分鐘孵化／羽化。
- 蟻巢、植物與蜜露、掠食者、競爭蟻、腐屑、土壤、微氣候、人類干擾成為同一個動態生態世界。
- 受傷工蟻可能持續工作、恢復或死亡；不自動變成「固定護理兵」。
- 不再強迫每回合四選一；玩家可純觀察，也可提出環境干預或研究目標。
- **重要限制**：蟻種尚未鑑定，模擬是基於研究的機制設計，**不是已校準的科學定量預測**。
